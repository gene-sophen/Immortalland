# 《三乂川》MLP 可玩原型

这是一个面向 PC 浏览器、以手机竖屏为目标布局的数据驱动可玩原型。它不是核心文档的替代品，而是用于验证 v0.10 主循环、战斗节拍与界面层级的运行载体。

## 运行

```bash
npm install
npm run dev
```

然后打开 `http://127.0.0.1:4173`。项目无第三方运行依赖，`npm install` 不会下载框架。

## 验证命令

```bash
npm run check
npm test
npm run build
```

`npm run build` 将静态版本输出至 `dist/`。

## 当前纵切范围

- 九个身份、九个伙伴、九域、三域完整推进与 48 兵。
- 每域“选伙伴—四节点—精英—四节点—精英—四节点—Boss”。
- 六类节点、品质骰子、商店、营地、事件、宝藏、战后奖励与存档。
- 实时 1v1 战斗：命潮回能、抽三打一弃二、敌方意图、快慢速、拖牌子弹时间、减速/打断、护盾/恢复、毒/火与 30/60 秒诅咒风暴。
- 27 张公共基础代表牌及衍生牌、伙伴技能与绝技、九件代表饰品。核心文档中的 99 张完整牌数据保持为源数据，原型先用每类一张三级牌验证系统。

## 实现原则

- 纯 HTML/CSS/JavaScript ES Modules，无重引擎、无框架绑定。
- `src/data.js` 存放可调数据，`src/engine.js` 存放无界面的战斗/成长规则，`src/app.js` 负责流程和呈现。
- 视觉资产暂用 CSS 剪影、矿石符号与纸本纹理代替，可在不改规则层的情况下逐步替换正式美术。
