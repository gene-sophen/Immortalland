# 《三乂川》公共卡池 v0.6

> 清单文档：9张一级底卡、9张二级底卡、81张三级分支及通用衍生牌。所有可调数值由数值策划阶段确定；本文件只规定机制、分类、名称和源神石归属。

## 一、一级与二级底卡

| 底卡 | 一级卡面 | 二级卡面 |
|------|----------|----------|
| 打击 | 1费，造成伤害 | 1费，造成更高伤害 |
| 重击 | 高费，造成高额伤害 | 高费，造成更高伤害 |
| 防御 | 1费，获得护盾 | 1费，获得更多护盾 |
| 虚弱 | 1费，施加虚弱 | 1费，施加持续更久的虚弱 |
| 鼓舞 | 1费，获得鼓舞 | 1费，获得持续更久的鼓舞 |
| 易伤 | 1费，施加易伤 | 1费，施加持续更久的易伤 |
| 能量 | 加快自然获得下一点命潮的速度，获得后结束加速 | 立即获得1点命潮 |
| 整备 | 0费、消耗，无额外效果；通过正常出牌流程刷新手牌 | 0费、提高消耗次数，无额外效果 |
| 锻造 | 1费，在抽牌堆生成匕首 | 1费，铸造5 |

## 二、三级卡总规则

- 九类各9张，共81张；每类分别归属9颗源神石，每颗源神石拥有九类各1张。
- 所有三级名称严格为三个汉字。
- 类别限定基础语言，不禁止跨类别联动。
- 卡面中的高额、少量、持续时间、费用和状态施加量由数值策划阶段定值。

## 六、数量校验

- 9类 × 9张三级卡 = 81张。
- 9颗源神石 × 每颗9类各1张 = 81张。
- 81个三级名称均为三个汉字且互不重复。
- 一级/二级共18张；公共阶梯牌合计99张，不含衍生牌与伙伴技能牌。
