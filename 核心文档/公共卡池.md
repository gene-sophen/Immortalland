# 《三乂川》公共卡池

> 本文件是公共卡池的完整初始数值表，覆盖9张一级卡、9张二级卡、81张三级分支与9张通用衍生牌。
> 数值以初始共享生命100、一级打击30、一级防御25为基准；统一数值配置以标准敌人和完整Build反测结果校准，不改变本文件的卡牌结构与机制职责。

## 零、统一价值尺

### 0.1 费用与基础效果

| 费用 | 一级无条件基准 | 二/三级无条件基准 | 设计说明 |
|------|----------------|-------------------|----------|
| 0费 | 10—15点直接价值 | 15—20点直接价值 | 仍占据候选位并触发抽三打一弃二，不等于完全免费 |
| 1费 | 30伤害 / 25护盾 | 45伤害 / 38护盾 / 30治疗 | 二级基础效果为一级的150%，最终统一四舍五入 |
| 2费 | 70伤害 | 105伤害 | 额外补偿等待2点命潮和卡手风险 |
| 3费 | — | 125—135伤害 | 满潮爆发档，允许高于线性三倍但必须承担等待风险 |
| 4费以上 | — | 不按费用线性换算 | 属于“虚拟费用”：命潮上限仍为3，必须先通过卡面成长或其他减费降至可支付范围 |
| X费 | — | 每点命潮约42伤害 | 以伸缩性、多段和体系联动换取略低的满潮上限 |

- 三级卡不直接取得等级面板加成，以二级面板为起点，用独特机制形成价值。
- 无条件纯面板牌可以高于同费基准；带跨战成长、永久能力或强联动的牌必须降低即时面板。
- 卡面费用可以高于3。当前费用高于命潮上限时不能正常主动打出，但可以继续被减费；“费用降低”与“免费打出”默认都能作用于虚拟费用，卡面另有限制时除外。
- 所有小数只在内部公式中保留，卡面与最终结算统一四舍五入为整数。

### 0.2 词条预算

| 词条/条件 | 数值处理 |
|-----------|----------|
| 轻盈 | 1费直接伤害相对45基准降低约10；保留另外两张牌和补1张本身就是高价值运转 |
| 固有 | 以稳定首抽为代价降低即时数值或限制适用次数 |
| 保留 | 小幅降低即时数值；它减少错过时机的风险但持续占据手牌位 |
| 虚无 | 未打出即消耗是负面代价，允许比同类高约20%即时价值 |
| 消耗 | 一次性牌允许高于同费循环牌；永久成长牌的初始面板必须低于基准 |
| 能力 | 以整场累计收益定价；触发频繁者设置门槛、冷却或单次上限 |
| 生命代价 | 失去8—12生命允许增加约15—30点即时价值，同时计算掉血流联动收益 |
| 强条件 | 空抽牌堆、满潮、破盾等不稳定条件允许约20%—35%回报溢价 |

### 0.3 状态数值

| 状态 | 标准效果 | 层数规则 |
|------|----------|----------|
| 力量 | 每1点令每段常规直接攻击基础值+1 | 永久，标准单次获得量为5点 |
| 鼓舞 | 常规直接伤害+25% | 时限型；1层=4秒，叠层只延长时间 |
| 易伤 | 目标受到的常规直接伤害+25% | 时限型；1层=4秒，叠层只延长时间 |
| 激昂 | 下一张主动直接伤害牌的全部直接伤害+25% | 次数型；多层加算，整张牌结算后清空 |
| 脆弱 | 目标受到的下一张主动直接伤害牌全部直接伤害+25% | 次数型；多层加算，整张牌结算后清空 |
| 虚弱 | 目标造成的常规直接伤害-25% | 时限型；1层=4秒，叠层只延长时间 |
| 减速 | 敌方行动充能速度-30% | 时限型；1层=4秒，总减速上限80% |
| 毒伤 | 每次结算造成“当前层数×5”穿盾伤害 | 每3秒结算，结算后-1层，上限9 |
| 火伤 | 每次结算造成“当前层数×5”伤害，先由护盾承担 | 每2秒结算，结算后减半并向下取整，无层数上限 |
| 重伤 | 治疗效果降低50% | 最近一次施加火伤时刷新为对应层数，每2秒-1层 |

- 毒伤与火伤不读取力量、鼓舞、激昂、易伤或脆弱，只读取专属放大和“全部伤害”效果。
- 护盾不再自然衰减，战斗结束时清空。
- 同一张多段牌的每一段都读取力量；激昂和脆弱覆盖整张牌后统一消耗，避免只强化第一段。

### 0.4 资源与时间

- 命潮上限3，基础自然恢复为2秒/点。
- “下一点命潮充能进度+50%”等同于立即填充该点的一半进度；达到上限时溢出丢失。
- 打断1次可打断行动按约20点即时价值计，但会随敌方行动强度波动。
- 净化1种可净化负面战斗状态按约10—15点价值计。
- 自动打出的卡牌无需再次支付费用，但仍结算卡牌效果与触发；不能自动选择负面状态牌。

## 二、三级总规则

- 普通公共卡及其通用衍生牌不使用**永恒**。永恒只用于伙伴牌、身份关联牌和明确的轮回诅咒等必须保护其永久存在的内容。
- 普通卡可以使用固有、消耗、保留、虚无、奇巧、激发、轻盈与能力；是否能被删除仍由普通卡牌规则决定，不因三级品质获得额外保护。

- 九类各9张，共81张；每颗源神石拥有九类各1张。
- 类别只限定卡牌的基础语言方向，不禁止跨类别联动。
- 一级或二级卡使用锤子时，在同等级9种基础类型中随机展示3种并横向变化；三级锤子仍在本类别9个分支中随机展示3个。
- 所有三级名称均为三个汉字。普通三级卡没有额外等级面板，只使用下列独立卡面。
