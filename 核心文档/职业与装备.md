# 《三乂川》职业定位与装备体系 v0.6

> 装备系统采用6件散件、36种主副系成装和饰品格结构。装备战斗效果围绕共享生命、护盾、命潮、卡牌和状态表达，不使用前中后排、射程、独立角色生命、普攻速度或位置互动。

## 一、六条装备轴

| 装备轴 | 散件 | v0.6功能方向 |
|--------|------|---------------|
| 生命 | 磐石带 | 提高共享生命、恢复或生命代价回收 |
| 护盾 | 玄武盾 | 护盾生成、衰减控制与防杀 |
| 连段 | 追月弓 | 多段、抽牌动作或连续出牌收益 |
| 爆发 | 断罪刃 | 直接伤害、脆弱与单次高伤 |
| 状态 | 星辰杖 | 毒火、易伤/虚弱与其他状态效果 |
| 命潮 | 女神泪 | 自然恢复速度、即时命潮与伙伴绝技蓄势 |

“职业”只作为装备轴名称和伙伴人设参考，不再决定战斗位置、射程或自动普攻。

## 二、携带与合成

| 槽位 | 数量 | 规则 |
|------|------|------|
| 主系 | 1 | 决定成装的主要功能轴 |
| 副系 | 1 | 为主系增加第二条修饰语言 |
| 饰品 | 1 | 放置特殊饰品或源神石，不参与主副系合成 |

- 主系+副系合成二级成装；有序组合共6×6=36种。
- 同系合成是该轴的纯强化版本。
- 装备不生成棋盘单位，不读取前后排、距离、位置或指定角色血量。
- 装备提供的费用、伤害、恢复、护盾、比例和触发间隔由数值策划阶段确定。

## 三、二级成装语言

二级成装使用“主系定本体、副系定修饰”的语法：

| 副系 | 修饰语言 |
|------|----------|
| 磐石带 | 共享生命、持续恢复、损血回收 |
| 玄武盾 | 护盾、减伤、护盾保留 |
| 追月弓 | 多段、连续出牌、抽牌触发 |
| 断罪刃 | 单次高伤、脆弱、生命吸取 |
| 星辰杖 | 毒火、状态延长、状态转伤害 |
| 女神泪 | 命潮恢复、减费、绝技蓄势效率 |

成装效果不得涉及射程、范围、相邻友军、普攻、攻击间隔或独立角色生命，只能使用上表的v0.6修饰语言。

## 四、命名

- 一级散件使用三个汉字：磐石带、玄武盾、追月弓、断罪刃、星辰杖、女神泪。
- 二级成装使用六字名称，由主系确定名根，副系确定修饰语。
- 36件成装由上述6×6语法生成；本文件不列单件数值清单。

## 五、饰品格与源神石

- 饰品格与主副系成装隔离，不参与合成。
- 源神石决定流派方向，使用《源神石.md》的九套新语言。
- 源神石饰品按《源神石.md》的九套语言提供构筑倾向，不使用双石共鸣。
- 身份专属饰品作为主角身份差异的主要接口，其战斗效果遵守共享生命与卡牌规则。

## 六、获取节奏

- 散件：战斗奖励、Boss、事件与商店。
- 二级成装：主副系合成，并在中后段提高投放权重。
- 源神石：Boss和领域内容提供，进入饰品格开启流派。
- 特殊饰品：事件、成就和商店稀有内容。
