# 《三乂川》职业定位与装备体系 v0.4

> 装备体系：**6件散件 + 36件二级成装（6主×6副）**；成装只提供附加效果词条，装备是战斗数值的修饰层。
> **饰品格**与二级体系隔离：放特殊装备或源神石，**源神石决定携带者流派**——石头是卡牌与技能内容的枝干，不再是装备矩阵的乘数。

---

## 一、六职业：2-2-2 段位划分

| 段位 | 职业 | 战斗位置 | 对应散件 |
|------|------|---------|---------|
| **前排** | 战士、骑士 | 近战承伤位（射程1，站桥口） | 腰带、盾牌 |
| **中段** | 猎人、刺客 | 输出位（射程1-3，游走/狙杀） | 弓、利刃 |
| **后段** | 法师、牧师 | 远程支援位（射程2-3，站底排） | 法杖、水滴 |

> 职业只约束伙伴；**主角不做职业画像**——主角的战斗定位由玩家在对局中自行构筑，身份只影响初始卡组与特化流派（见§五、主角.md）。

## 二、六散件（一级，统一三字命名）

| 散件 | 属性 | 对应职业 | 设计逻辑 |
|------|------|---------|---------|
| **磐石带** | 生命+15；每秒回复1 | 战士 | 生命属性归前排——"生命对后排增益不大"的修正 |
| **玄武盾** | 减伤+10% | 骑士 | 纯坦度（不设防御力属性，统一走减伤机制） |
| **追月弓** | 攻速+25% | 猎人 | 持续输出（攻速按25%档减攻击间隔tick数，战斗.md §2.1） |
| **断罪刃** | 攻击+4；暴击率+15% | 刺客 | 攻击+暴击合并到中段爆发轴 |
| **星辰杖** | 技能效果+25% | 法师 | 技能爆发 |
| **女神泪** | 命潮回复速率+25% | 牧师 | 回蓝轴：能量转得更快=出牌频率 |

- 命名统一三字、去"大XX"口水化
- 掉落：杂兵/一域关底/商店，稀有度浮动（冒险系统.md §2.1）

## 三、携带规则：主系 + 副系 + 饰品

| 槽位 | 数量 | 规则 |
|------|------|------|
| **主系** | 1 | 决定基础定位（六职业轴归属） |
| **副系** | 1 | 决定附加效果（与主系合成二级成装） |
| **饰品** | 1 | 放特殊装备或源神石；**源神石决定流派**；与二级体系隔离 |

- 主系+副系 → 合成**二级成装**（有序：主A副B ≠ 主B副A，故 6×6=**36种**）
- 两槽也可不合成（散件裸带，过渡期）
- **槽位互动**：主系槽装备可影响副系槽（如光荣进化核心：副系槽效果+25%）；伙伴被动可位置敏感——装备摆放从"塞进去"变成"摆位置"

## 四、二级成装：附加效果

**二级成装 = 主系散件基底数值 + 副系修饰的附加效果词条**，不产生卡牌；带卡职能移交少数特殊饰品（见卡牌系统.md §六）。

### 4.1 核心规则

- 附加效果词库：吸血、造成灼烧（灼烧自带重伤、压治疗）、增伤、反伤、护盾强化、中毒附层、斩杀线、移速、**射程+1**、**绝技蓄能需求-1**
- 数值走统一纪律：系数50/100/150/200%档，增益25/50%档，向下取整

### 4.2 生成语法：主系定本体 × 副系定修饰

| | 副磐石带<br>（附治疗/生命） | 副玄武盾<br>（附护盾/减伤） | 副追月弓<br>（附多段/提速） | 副断罪刃<br>（附吸血/斩杀） | 副星辰杖<br>（附源流/扩围） | 副女神泪<br>（附回费/充能/绝技蓄能减免） |
|---|---|---|---|---|---|---|
| **主磐石带**<br>守护型（治疗/增益友军） | | | | | | |
| **主玄武盾**<br>防御型（减伤/嘲讽/反伤） | | | | | | |
| **主追月弓**<br>速射型（多段伤害/攻速增益） | | | | | | |
| **主断罪刃**<br>爆发型（单体大伤害） | | | | | | |
| **主星辰杖**<br>咒术型（范围伤害/源流） | | | | | | |
| **主女神泪**<br>充能型（命潮/蓄能/换牌/绝技向） | | | | | | |

- 设计成本 = **6种本体行为 + 6条修饰语言 + 36格审校**，与卡牌矩阵同一纪律
- 同件合成（主A副A）= 本体纯强化版
- 女神泪系成装方向示例：绝技蓄能需求-1（散件回蓝、成装催绝技）

### 4.3 命名：一级三字 / 二级六字（名根由主系定）

示例——主星辰杖一整行：

| 组合 | 成装名 | 附加效果 |

| 星辰杖+断罪刃 | **噬星蚀月之咒** | 技能效果+25%；技能伤害的25%转为自身生命 |
| 星辰杖+星辰杖 | **灭世终焉之爆** | 技能效果+50%（纯强化） |

> 其余5行30格同法填充，建议按主系分批交付（每批6件）。

## 五、饰品格与源神石流派

- 饰品格与二级体系**完全隔离**：不参与合成、不提供技能卡
- 可放：**源神石**（决定携带者流派，提供流派被动）或**特殊装备**（唯一饰品，功能性小效果，**数量不限**，随内容扩展逐步增加，单局获取保持稀缺）
- 九流派被动语言 = 九石机制方向（调和/献祭/混沌/处决/降解/进化/金刚/巨力/温润，见源神石.md），随领域解锁逐批细化
- **主角身份特化挂点**：主角不定职业画像；九身份影响**初始卡组构成 + 特化流派倾向**，以**身份专属饰品**形式落地（如葛朗台=纽币向饰品、普朗克=骰子向饰品，见主角.md）
- 流派是全局构筑轴心：影响卡牌注入倾向、技能共鸣、Boss掉落——具体挂载点在卡牌设计中展开

## 六、获取节奏

- 散件：杂兵/一域关底/商店
- 二级成装：合成台（主+副合成），二阶（4-6域）投放权重上升（冒险系统.md §三）
- 源神石：Boss掉落 → 入饰品格开流派，三阶（7-9域）投放权重上升
- 特殊饰品：领域事件/综合商店
