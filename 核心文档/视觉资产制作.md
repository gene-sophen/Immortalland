## 七、卡牌画芯提示词体系

### 九类动作模板

| 类别 | 画面动词 |
|------|----------|
| 打击 | 一道明确、迅速、低成本的向前命中动作，刃口纹方向单一 |
| 重击 | 重物或力量在命中前形成蓄势弧，主体压低重心，冲击占画面中心 |
| 防御 | 瓷片、岩壁、心壁或治疗流形成包覆与承托，不默认附带攻击动作 |
| 虚弱 | 敌方行动线被锁链、雾、卸力掌或迟滞纹削弱，强调“难以完成攻击” |
| 鼓舞 | 旗、呼吸、心火或姿态使自身气势增长，焦点朝内汇聚再向外放大 |
| 易伤 | 裂纹、标记或熔蚀打开敌方防线，焦点是暴露的破口而非直接命中 |
