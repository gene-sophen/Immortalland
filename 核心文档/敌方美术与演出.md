# 《三乂川》敌方美术与战斗演出

> 本文件覆盖v0.10新增公共怪、领域特产、领域Boss、48兵、潮律与风暴。整体沿用“新国风志怪+矿石媒介+纸本肌理”，不使用通用西式魔物、霓虹赛博或写实血浆。

## 一、公共敌人的视觉系统

公共敌人来自源海异物、流徙者、旧兵器与跨域商旅。每个模板只制作一套主剪影和动作骨架，在不同领域叠加轻量环境附着层：

| 领域 | 附着层 | 限制 |
|------|--------|------|
| 镜晶 | 晶白碎屑、边缘折光 | 不整只变成水晶怪 |
| 荒脊 | 玄灰岩尘、铁锈红裂纹 | 不加恶魔角与蛮族图腾 |
| 火尽 | 黑玉灰、血红幕光 | 不变成普通火元素 |
| 皮安 | 冰蓝铆片、细齿轮投影 | 不使用霓虹电路皮肤 |
| 松三 | 陶赭粉、玉青松针 | 保留怪异感，不做可爱田园宠物 |
| 过明 | 盐碱白侵蚀、尘金边 | 轮廓仍需清楚，不能融成纯白 |
| 啼亡 | 青金墨迹、悬书纸屑 | 不给所有敌人穿儒服 |
| 潮王 | 紫橙潮膜、局部形变 | 形变只影响材质，不改变受击轮廓 |
| 平安 | 昼暖夜冷双色投光 | 不简单左右切半贴图 |

环境附着不改变命中框、动作时长与机制。品质使用意图环而非换色：普通单环，稀有双环，传说在环外增加缓慢转动的源纹缺口。

## 七、48兵

### 1. 造型

48兵不是四十八个独立敌人。主体为一座由四十八块人形甲片围成的空心兵阵，中央第49位始终空缺。远看像一名持戈巨人，近看每块甲片都有不同磨损和姓名刻痕。三条本轮领域回响以三种材质沿兵阵经络流动，未探索领域保持暗色。

### 2. 行动

| 行动 | 演出 |
|------|------|
| 问 | 一块甲片离阵，以戈尖在地上刻出下一领域图标 |
| 承 | 甲片向中心合拢成盾、净化潮或蓄力阵，三种结果轮廓完全不同 |
| 证 | 对应领域材质只沿一条经络点亮，不让三域特效同时铺满屏幕 |
| 决 | 单式由一柄巨戈下劈；众式由四个方向的甲片先后穿过中心空位 |
| 复起 | 四十八甲片落地后由第49个空位产生吸力重新聚合，原三域回响保持不变 |

剩余命源石越少，兵阵中央空位越亮；绝境石档位显示红黑逆潮，但不改变基本剪影。第九重复起不增加新颜色，只让甲片排列从圆阵收紧为竖直碑形。

## 八、意图、潮律与风暴UI

| 信息 | 表现 |
|------|------|
| 可打断 | 意图条左端开口，进度光可从缺口泄出；打断图标使用断开的木榫 |
| 不可打断 | 意图条闭环并加一枚压纹石锁；仍显示减速后的预计秒数 |
| 单段/多段 | 刀痕一条/并列短痕，旁边明确显示总伤与段数 |
| 毒火 | 毒为盐绿滴、火为朱砂裂；灾蚀使用两者套环但不占普通状态层 |
| 领域潮律 | 战场顶部细长石纹条，只显示当前规则、计数和下一触发方 |
| 30秒风暴 | 25秒开始边缘倒计时；红黑风纹从四角向中间推进，不遮牌面 |
| 60秒灾蚀 | 55秒倒计时；毒金和火红双环收紧，生命条显示穿盾刻度与减疗封印 |

伤害数字只用三档：普通白、增幅金、穿盾盐绿；暴击式夸张字号只用于源神石终端、Boss破相和48兵决，不让每次攻击都震屏。

## 九、音频与触觉节拍

- 公共小怪每个只需要待机循环、标准行动、机制行动、受击、败北5组声音；领域附着由环境总线处理，不重复录制九套。
- 精英增加机制充满和终端预警两组；Boss每阶段增加一层乐器而不是切换整首曲目。
- 打断在动作完成前80毫秒先静音环境，再落一声干脆木榫断裂；减速不拉低全部音高，只放慢意图节拍。
- 30秒风暴用共同敌我的风纹脉冲；60秒后旋律停止完整收束，只保留越来越密的潮脉冲。
- 网页端无触觉设备时用2像素短位移代替震动；启用减少动态效果时关闭震屏、视差和大面积闪白。
