# 《三乂川》卡牌系统 v0.4

> 卡牌总纲。底层规则：**抽三打一弃二**（抽3张→打1张→弃其余2张→补新组）。
> 牌池两层结构：**公共池**（12底卡三级阶梯）+ **角色技能卡**（绑定角色，①②绝技+分支）。

---

## 一、卡牌六分类

| 类别 | 定义 | 归属 | 备注 |
|------|------|------|------|
| **攻击** | 造成伤害，吃施放者攻击/技能系数 | 公共池 | 单体/AOE/高费高伤三种形态；不区分近战远程，射程弹道随施放者 |
| **buff** | 护盾、增益、治疗统一归此类 | 公共池 | |
| **debuff** | 对敌减益（中毒/灼烧/虚弱/易伤…） | 公共池 | |
| **战术** | **过牌回能 / 释放法术 / 生成卡牌**三类 | 公共池 | 法术=三格范围投放式效果（皇室式） |
| **技能** | 角色与伙伴的自带卡（含绝技） | 角色绑定 | 见§三 |
| **诅咒** | 敌方/事件注入的负面卡 | 对局临时 | 占抽牌位，可删除；垃圾属性为诅咒/退化卡固有 |

- **移动不做公共卡**：自动战斗下位移是刺客型英雄的技能特质

## 二、公共池：三级阶梯结构

### 2.1 升级规则

- **一级卡**：基础效果，朴素数值（打击、护盾、治疗、毒镖……）。**一级卡不做独特机制**——毒药水和狂暴药水这种辨识度效果是三级的分支产物，绝不出现在一级
- **二级卡**：同一底卡的**数值提升版**（25%/50%档，向下取整），无新机制
- **三级卡**：底卡内核 × 源神石关键词 → **分支为一张新的独特卡**（新名字、新机制、新构筑指向）
- 升级=**替换**（一级升二级、二级升三级都是原卡替换），卡组厚度不因此膨胀——这是抑制后期膨胀的闸门
- **三级分支获取=三选一**：二级升三级时，从该底卡9条分支中**随机给出3条候选，三选一**确定分支（保持三选一语言，不做9选1）
- **命名口径**：一/二级卡二字名即可；**仅三级卡必须三字**——独特、无歧义、名实相符

### 2.2 三级分支设计纪律

- **每张底卡做满9条三级分支**（九石全覆盖，一石一条），分支挂石头关键词
- 三级卡 = 底卡内核保留 + 石头机制变异，玩家能认出"它是谁变的"
- **设计纪律**：设计9种石头关键词语言，而非108个孤立句子；数值继承底卡二级版，只有效果独特
- **机制错位选词**：每条分支从石头关键词库中选与底卡最贴切的一个，不强制标志性词；跨底卡形成网状覆盖，**同石不同面**
- **三级卡可跨类别**（攻击底卡的分支可变为buff/战术等，内核保留即可）；跨类型转换与特殊词条赋予是可选调味而非硬性指标
- **形状纪律**：战场=23232六边形格，无"一列"；形状库=三格小范围/七格大范围/横排/斜排/邻格传导
- **随机一律前置结算**：随机效果在抓取/入手时定型并牌面明示；**暴击概率属战斗核心概率机制，不受此纪律约束**
- **局外联动**：分支可与纽币、装备等战斗外元素联动，每石限1-2张；伙伴联动留给角色技能卡
- 示例（打击 × 9石取3）：

| 底卡（一级→二级） | 三级分支示例A | 三级分支示例B | 三级分支示例C |
|------------------|----------|----------|----------|
| 打击：单体伤害 | **两仪击**（阴阳石：目标生命高于50%伤害+50%，低于50%则伤害量25%转治疗） | **蚀骨击**（降解石：伤害+中毒3层） | **熔岩击**（大理石：伤害+灼烧） |

> 108条三级分支全表见 公共卡池.md（12批×9石全量清单，含覆盖校验）。

### 2.3 公共池规模与12底卡

一级底卡 **12张**（攻击3 / buff3 / debuff3 / 战术3），×2级数值版 + 每卡9条三级分支：
**12底卡 + 12二级 + 108三级 ≈ 首版可玩池 132张**，按域分批交付。
数值为方向性锚，数值阶段校准。

| # | 底卡 | 类别 | 费 | 一级效果（方向性） | 备注 |
|---|------|------|----|-------------------|------|

## 三、角色技能卡：分层+分支

### 3.1 结构（主角与伙伴同一规则）

| 层级 | 内容 | 解锁 |
|------|------|------|
| **基础技能卡** | 技能①、技能②：角色立绘级的招牌行为 | 加入即有①；3级解锁② |
| **绝技卡** | 大招，蓄能满后可打出（见§4.2） | 6级解锁 |
| **分支变体** | 技能①②各有**固定3个分支版本**（细微效果差异：数值形态/附词缀/目标逻辑） | 获得/转型时三选一 |

**技能卡解锁节奏（1/3/6/9级）**：

| 等级 | 解锁 | 定位 |
|------|------|------|
| 1级（入队） | 技能①入卡组 | 身份名片 |
| 3级 | 技能②入卡组 | 机制核心（联动源流/棋盘/命定石） |
| 6级 | 绝技卡入卡组（蓄能制，0命潮，战斗.md §六） | 人设顶点 |
| 9级 | **圆满：专属涂装 + ①②各开放第4个「圆满分支」**（独特奖励，非数值放大） | 羁绊终极奖励 |

- **分支的意义 = 流派适配**：同一个技能①，灼烧分支进大理石体系、传导分支进陶玉体系、直伤分支通用——一个角色因此能搭多个体系，后期内容扩展=新角色×新分支
- 主角按加深设计：基础卡3张+独特卡若干（主角是固定养成位，卡位可多于伙伴）

### 3.2 技能卡与公共卡的边界

- 技能卡**绑定角色**，不进公共池，不可删除；角色阵亡→其技能卡变垃圾卡
- 技能卡吃**绑定角色**的属性系数（不选施放者）；公共卡沿用"选择施放者"规则

## 四、能量系统：命潮

### 4.1 参数

| 参数 | 值 | 说明 |
|------|--------|------|
| 上限 | **3** | 每一点能量都有存在感；重炮牌=2-3费的"梭哈"决策 |
| 起始 | **2** | 开局即可行动 |
| 回复速率 | **1点/3秒**，三幕 3s → 2s → 1.5s | 30秒战斗≈12命潮≈**8-12次出牌** |
| 费用档 | **1费为基准**，重牌2-3费 | 1费=标准牌；2费=重效；3费=全槽梭哈（多为绝技/重炮） |
| 战术时刻 | 命潮打满（3点）：0.4x慢速+往抽牌堆加入1张一级整备 | |

- 双闸门：**出牌频率由命潮滴流节流，抽牌组由打一弃二节流**
- 上限3的隐藏收益：降费机制有明确地板（0费），UI上能量只需3个刻度
- **手牌调度靠卡牌**：无换组按钮；一切"免费换组"效果统一落地为"往抽牌堆加入1张一级整备"

### 4.2 绝技与条件卡：降费/充能双机制

**绝技卡直接加入卡组**，不设任何独立资源轨——厚度+可见性双收益：在卡组里就能直接看到费用/充能状态。

**绝技统一用「蓄能X」范式**（计数器直接印在卡面）：
- 卡面印「蓄能X」：**阈值X与触发条件均按角色个性化设计，不做统一数值**（如：打出技能卡+1 / 牧师=施放buff+1 / 刺客=暴击+1 / 骑士=承伤按比例），充满解锁打出；卡在手牌/卡组中实时可见进度

**降费词「蓄势」给其他卡**：
- 牌面印高费用（2-3费）；每满足一次触发条件费用-1，最低0
- 适用：重炮攻击卡、高费战术卡、条件型公共卡（如"每有1友军受伤费用-1"）
- 触发条件按卡设计：打出技能卡/打出攻击卡/友军受伤/击杀……同一体系内触发与玩法自洽

- **女神泪**（牧师散件）：**命潮回复速率+25%**；其二级成装方向做绝技向特效（如"绝技蓄能需求-1"）——散件回蓝、成装催绝技

## 五、卡组构成（目标12-18，建议15±3；无硬上限）

| 来源 | 数量 | 说明 |
|------|------|------|
| 主角技能卡 | 3 | 基础①②+绝技（蓄能封印） |
| 伙伴技能卡×2 | 4-6 | 各2技能+1绝技，按解锁等级逐步入组 |
| 初始公共基础卡 | 3-4 | 打击/硬壳术/治疗术 + 身份倾向第4张（主角.md） |
| 冒险获得卡 | 若干 | 公共池一/二/三级卡，主题掉落（精英掉领域牌、Boss掉统治者牌），**常规获得制直接入组** |
| 诅咒卡 | 0-3 | Boss/事件注入，占抽牌位 |
| 饰品卡 | 0-1 | 特殊饰品带入（如"多兰盾"：获得一张略高于常规数值的 buff 卡） |

- 普攻由自动战斗承担，卡组只含玩家构筑的干预牌
- **常规获得制，无硬上限**：获得新卡直接入组，不强制替换
- **厚度纪律 = 软自律**：目标厚度12-18（建议15±3）；超厚不自删，循环效率下降自负——删卡服务在商店/事件；诅咒不入组则污染抽牌循环——"降级未删完的卡"自然成为构筑负债
- 卡组12-18张 + 抽三打一弃二：约4-6组循环一遍，与单场8-12次出牌匹配（一场战斗大约见卡组1.5-2遍）

## 六、装备与卡牌的接口

- **一级散件**：只提供基础数值
- **二级成装**：只提供**附加效果**——吸血、造成灼烧、增伤、反伤、护盾强化等常规词条，不带卡
- **特殊饰品**：少数设计可带卡入组（多兰盾式：一张略高于曲线的卡），作为卡组第"0-1"张浮动卡位
- 卡牌构建的重心：公共池三级分支 + 角色技能分支

---

## 七、数值纪律

- 系数仅50/100/150/200%档；增益仅25/50%档；衰减独立印在牌面；向下取整
- 公共卡=选施放者（攻击牌吃攻击、功能牌吃技能轴）；技能卡=绑定角色
- 同名触发每tick限1次/每秒限3次（防循环）
- **防贬值**：翻倍类效果必带"消耗"限制；0费卡必带消耗或为生成物（防0费无限循环）
- **现阶段数值可大胆，效果设计优先**，统一数值阶段再校准

## 八、卡牌设计规范

### 8.1 端口化词库

所有卡牌/关键词归入五个端口，**设计新卡先定端口再定效果**：

| 端口 | 内容 | 备注 |
|------|------|------|
| 输出端 | 攻击牌、灼烧、中毒、暴击 | |
| 防御端 | 护盾、治疗、减伤 | |
| 运转端 | 充能、专注、连击、回收、迟缓/禁足 | 作用于能量轴与敌方行动轴 |
| 经济端 | 纽币相关 | 降解石系 |
| **空间端**（独有） | 法术投放、地形、嘲讽操控、射程 | 棋盘赋予的第四维度，核心卖点 |

配套纪律：绝技/技能卡按"终端牌"设计——**需求端口而非需求固定牌**（如金克斯绝技需求"移动次数"这一运转端口）；9种源流各自归属端口，注入即改变卡牌端口角色。

### 8.2 通用词条库（9个）

> **词条入选标准**：只收"改变卡的使用规则"的词——何时能用、能用几次、打完去哪（对标StS：固有/消耗/保留/虚无一类）。纯效果修饰**不词条化**，直接写成卡面普通描述（如"生成1张利剑加入抽牌堆""选择三格范围释放""结算2次"）。

| 词条 | 定义 | 备注 |
|------|------|------|
| 固有 | 每场战斗初始手牌必含 | 构筑稳定性的锚；公共池启用例：聚核炉/索盾令 |
| 消耗X | 每场战斗限X次（省略X=限1次） | 防贬值纪律的配套闸；整备/利剑在用 |
| 连击 | 队友施放技能牌时触发（每秒≤3次兜底） | 卡面必须写全触发条件，与多段描述严格区分 |
| 回收X | 打出后回到待抽区而非弃牌堆，限X次 | **次数为硬约束**，无次数不得印回收 |
| 蓄势 | 每满足一次触发条件费用−1，最低0 | 给高费牌节奏感 |
| 蓄能X | 绝技计数器，充满解锁可打出 | 绝技唯一范式 |
| 成长 | 本场战斗内累积增益，卡面句式"成长：……" | 与永久成长组成双轴 |
| 保留 | 因"弃二"被弃时，**保留至下一组手牌**（主动打出则正常结算） | 留着等时机的卡；自平衡=持续占用1/3手牌位 |
| 奇巧 | 因"弃二"被弃时，**触发卡面效果**（不视为打出、不消耗次数） | 抽三打一弃二的天然适配：每次弃二都是触发窗口 |

**纪律**：通用词条贵精不贵多（现9个，呼应九数）；新机制优先用现有词条+普通描述组合表达，确属"使用规则"才新增词条。
