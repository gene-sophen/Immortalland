# 《三乂川》卡牌系统 v0.6

> 卡牌系统围绕命潮自然恢复与“抽三打一弃二”构建。公共卡池采用9张底卡、18张一级/二级基础卡和81张三级分支；伙伴技能与绝技使用本文件规定的统一接口。

## 一、九类公共卡

| 类别 | 基础语言 | 所属端 |
|------|----------|--------|
| 打击 | 常规直接输出 | 输出端 |
| 重击 | 高费、高额输出 | 输出端 |
| 鼓舞 | 我方力量、鼓舞、激昂等自身增伤 | 增伤端 |
| 易伤 | 易伤、脆弱及敌方承伤窗口 | 增伤端 |
| 防御 | 护盾、恢复、净化等自身生存 | 生存端 |
| 虚弱 | 虚弱、失去力量、减速与打断 | 生存端 |
| 能量 | 即时命潮、自然恢复速度与减费 | 运转端 |
| 整备 | 洗牌、选牌、抽牌动作与连续出牌 | 运转端 |
| 锻造 | 通过生成和铸造连接前8类 | 运转端 |

类别只限定玩家对卡牌基础作用的预期，不禁止跨类别联动。所有构筑最终都需要形成伤害闭环。

## 二、三级阶梯

- 每张底卡拥有一级、二级和9张三级分支。
- 升级采用替换：一级升二级、二级升三级均替换原牌，不增加卡组厚度。
- 二级升三级时，从该类别的9张分支中随机给出3张，玩家三选一确定分支。
- 一级/二级使用二字底卡名；三级使用三个汉字的专属名称。
- 公共池规模为 **9张一级 + 9张二级 + 81张三级 = 99张**，另有衍生牌。
- 具体卡面与九源神石分配见《公共卡池.md》；数值统一由数值策划阶段确定。

## 三、一级与二级基础卡

| 底卡 | 一级 | 二级 |
|------|------|------|
| 打击 | 1费，造成伤害 | 1费，造成更高伤害 |
| 重击 | 高费，造成高额伤害 | 高费，造成更高伤害 |
| 防御 | 1费，获得护盾 | 1费，获得更多护盾 |
| 虚弱 | 1费，施加虚弱 | 1费，施加持续更久的虚弱 |
| 鼓舞 | 1费，获得鼓舞 | 1费，获得持续更久的鼓舞 |
| 易伤 | 1费，施加易伤 | 1费，施加持续更久的易伤 |
| 能量 | 加快自然获得下一点命潮的速度，获得后结束加速 | 立即获得1点命潮 |
| 整备 | 0费、消耗，无额外效果；通过正常出牌流程主动刷新手牌 | 0费、提高消耗次数，无额外效果 |
| 锻造 | 1费，在抽牌堆生成匕首 | 1费，铸造5 |

表内费用与数值保留设计结构，最终平衡值由数值策划确定。

## 四、手牌与牌区

- 常态手牌为3张；主动打出1张，弃置另外2张，再补足3张。
- 抽牌触发按抽牌动作计数，不按单次获得张数计数。
- 轻盈、绝时域等效果可改变当前一次换组，但必须明确写出牌区去向。
- 抽牌堆为空时将弃牌堆洗回；消耗区、能力区和绝技蓄势区不参与重洗。
- 重启只重组手牌、抽牌堆和弃牌堆中的未消耗卡。
- 倾泻跳过负面状态牌，不替玩家自动处理污染。

## 五、特殊词条

| 词条 | 规则 |
|------|------|
| 固有 | 在抽牌堆中优先于非固有牌进入下一组手牌；多个固有按进入抽牌堆的先后排列，超出空位的继续留在抽牌堆顶 |
| 消耗 | 结算后进入消耗区；消耗X共有X次额度，前X−1次结算后进入弃牌堆，最后一次才进入消耗区 |
| 保留 | 因常规弃二本应弃置时留在手牌，并占据下一组的一个位置 |
| 虚无 | 未主动打出而被弃置时按消耗处理并触发消耗联动 |
| 奇巧 | 因常规弃二被弃置时额外触发奇巧效果，随后仍进弃牌堆；主动打出只结算普通卡面。奇巧可重复触发，激发则从主动/弃置两种完整效果中二选一 |
| 激发 | 主动打出和被弃置分别结算卡面上的两种效果 |
| 轻盈 | 打出时保留另外两张牌，只补抽1张 |
| 能力 | 打出后进入能力区，持续至战斗结束；默认可叠加，卡面注明不可叠加的除外 |
| 蓄势X | 伙伴绝技专属；条件充能至X后绝技置顶并获得固有，使用后清零重新蓄势 |

## 六、能力、虚无与消耗

- 永久持续增益统一使用能力，不用普通持续时间状态冒充永久增益。
- 能力牌主动打出时发生一次消耗事件，随后进入能力区。
- 虚无牌的平均质量高于同类；未打出时消失是其代价，同时也是消耗构筑的收益接口。
- 同名能力默认叠加；壁垒明确不可叠加。
- 消耗X的前X−1次结算按普通循环牌进入弃牌堆，只在第X次结算后最终离开本场牌组。
- 永久成长卡可以在本场被消耗，同时把成长保留到本局冒险后续战斗。

## 七、衍生牌与铸造

| 衍生牌 | 规则 |
|--------|------|
| 巨石 | 1费，造成高额伤害；不消耗，正常循环 |
| 利剑 | 固有、1费，造成伤害；不消耗；可被铸造永久提高本场基础伤害 |
| 匕首 | 0费、消耗，造成伤害 |
| 火焰匕首 | 0费、消耗，造成伤害并施加火伤 |
| 混沌球 | 0费、消耗、激发；主动打出造成伤害，弃置造成较低伤害 |
| 能量球 | 0费、消耗、激发；主动获得命潮，弃置短时加快自然恢复 |
| 再生球 | 0费、消耗、激发；主动恢复较多生命，弃置恢复较少生命 |
| 燃料 | 0费、消耗、轻盈；命潮+1 |

**铸造X**：若利剑不存在，在抽牌堆生成利剑并使其基础伤害增加X；若利剑已经存在，则使现有利剑基础伤害增加X。利剑的成长持续至本场战斗结束。

球类统一为0费、消耗、激发；主动与弃置任一效果结算后均进入消耗区，不使用奇巧。

## 八、负面状态牌

| 类别 | 规则 |
|------|------|
| 一次性惩罚 | 被弃置时触发惩罚并消耗 |
| 永久惩罚 | 不能主动打出，弃置后继续循环 |
| 处理型 | 主动打出才会处理并消耗，弃置后继续循环 |

**虚空**：处理型负面状态牌。进入手牌后降低命潮自然恢复速度；主动打出时无正面效果，随后消耗；若被弃置则进入弃牌堆继续循环。

压缩等变化效果可将负面状态牌变为燃料。变化不是弃置，不触发弃置惩罚。

## 九、伙伴绝技接口

- 每名伙伴的绝技位于绝技蓄势区，使用蓄势X。
- 满足该绝技卡面条件时逐次充能；蓄满后置于抽牌堆顶并获得固有。
- 绝技进入牌组后暂停蓄势；主动使用后返回蓄势区并重新充能。
- 伙伴卡与公共卡共用费用、牌区和词条规则；绝技的蓄势条件与X值写在各自卡面。

## 十、构筑体系

公共池支持以下主构筑：常规攻杀、防杀、掉血击杀、运转击杀、毒杀、火杀、多段伤害、单次高伤、虚无和消耗。

主要次级模块包括：自然回能速度、污染净化、能力成长、生成/铸造、减速/打断和抽牌动作触发。分类允许交叉，但每套构筑都应具备启动、资源引擎、生存支持和伤害终端。

## 十一、设计与数值边界

- 卡牌机制、牌区、词条和构筑接口属于玩法设计。
- 费用、伤害、恢复、护盾、状态施加量、持续时间、间隔、速率、比例、抗性数值和取整由数值策划阶段确定。
- 手牌3张、命潮上限3、毒伤上限9、火伤结算后减半等已拍板结构常数不属于自由调参项。
- 处理型负面牌可被绝时域降为0费；自动出牌与复制效果不能选择负面状态牌。
