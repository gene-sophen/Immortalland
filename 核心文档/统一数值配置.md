# 《三乂川》统一成长、经济与物品数值

> 本文件统一配置冒险等级、经济、奖励、饰品、源神石、伙伴饰品、身份解锁、九重轮回与局外成长数值。

## 一、冒险等级与生命

| 项目 | 数值 |
|------|------|
| 基础共享生命 | 100 |
| 升级经验 | 每3经验1级，溢出保留 |
| 每级生命 | 本轮回共享生命上限+4，并恢复4生命 |
| 每3级奖励 | `30+10×已触发次数`纽币，即40/50/60…… |
| 每6级奖励 | 二级普通卡三选一或二级常规饰品三选一，两组中选一 |
| 每9级奖励 | 后续品质骰最终点数+1，最多累计2次、最高仍为6 |
| 常规冒险经验 | 完成探索、精英或Boss各1经验 |
| 进入新领域 | 额外3经验 |
| 营地 | 节点本身2经验；选择温存时总计3经验 |

标准路线在第一、第二、第三领域末约为6、12、18级，对应生命124、148、172。额外营地和成长效果允许超过18级。

## 二、品质与阶段收益

### 1. 品质骰

| 最终骰点 | 品质 |
|----------|------|
| 1—3 | 普通 |
| 4—5 | 稀有 |
| 6 | 传说 |

随机节点的品质骰结算前+1。冒险等级9/18分别再+1；所有加值合计后最高为6。普朗克最后再+1，同样封顶6。

### 2. 节点价值倍率

| 项目 | 第一领域 | 第二领域 | 第三领域 |
|------|----------|----------|----------|
| 基础纽币倍率 | ×1.00 | ×1.55 | ×2.20 |
| 卡牌二级基础概率 | 20% | 40% | 60% |
| 饰品高一级权重 | 0 | +10个百分点 | +20个百分点 |

品质对节点收益使用普通×1.00、稀有×1.35、传说×1.80。卡牌二级概率再由稀有+15、传说+30个百分点，最高90%。
