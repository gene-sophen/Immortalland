# 《三乂川》伙伴设定 v0.7

> 九名伙伴与九颗源神石一一对应。伙伴不作为棋盘单位；其战斗内容通过共享生命、专属饰品、技能牌和蓄势3绝技牌表达。

## 一、伙伴系统框架

- 队伍最终由主角+3名伙伴组成，四人共享一条局内生命值。
- 伙伴不拥有独立血条、站位、射程、索敌、普攻或位移；卡牌直接作用于我方共享状态或唯一敌方。
- 每名伙伴自带1件专属饰品、1张专属技能牌和1张专属绝技牌。
- 伙伴加入时，专属饰品占用该伙伴1个饰品槽；技能牌接入普通牌组，绝技牌进入绝技蓄势区。
- 伙伴技能牌与绝技牌不能删除、复制、通过同名卡合成升级或使用锤子重选。
- 每次伙伴加入及每次伙伴升级，都会提高队伍后续战斗的共享生命上限；每场战斗仍以当前生命上限满血开始。

## 二、加入节奏

| 时机 | 事件 | 队伍变化 |
|------|------|----------|
| 开局 | 从3名候选伙伴中选择1名 | 主角+1名伙伴 |
| 第一领域结束后 | 从新的候选伙伴中选择1名加入 | 主角+2名伙伴 |
| 第二领域结束后 | 从新的候选伙伴中选择1名加入；不再发生伙伴牺牲 | 主角+3名伙伴，形成四人队 |

加入队伍的伙伴不会因后续领域推进离队，其专属卡和专属饰品持续留在对应系统中。

## 三、成长与分支

- 伙伴共同参战可以升级；营地“温存”可以直接提升一名伙伴的等级。
- 伙伴升级同时接入三项成长：提高共享生命上限、提高专属饰品品质、在对应等级解锁专属卡分支。
- 每张技能牌拥有3个互斥分支，每张绝技牌也拥有3个互斥分支。
- 达到对应等级时立即三选一；选定后固定，不能切换、重选或降级。
- 专属饰品视为伙伴被动，但仍占用饰品槽并允许卸下；饰品增益默认全队共享，卡面可限定携带者。

## 四、绝技接口

- 所有伙伴绝技统一使用蓄势3。
- 每名伙伴使用符合自身体系、稳定可达成的专属事件作为蓄势条件；每次满足条件蓄势+1。
- 累计3次后，绝技置于抽牌堆顶并获得固有；主动使用后返回绝技蓄势区并清零。
- 绝技进入牌组后暂停蓄势，避免同名绝技同时存在多张。

## 六、专属卡方向

| 伙伴 | 专属技能牌 | 专属绝技牌 |
|------|------------|------------|
| 查莉娅 | 获得充能护盾；受到伤害后提高查莉娅相关效果的伤害 | 打断敌方当前可打断行动，并降低其后续行动充能速度 |
| 奥丽莎 | 获得金身，并恢复共享生命、净化我方负面战斗状态 | 进入蓄力，蓄力完成或提前释放时造成伤害 |
| 乐芙兰 | 以锁链造成持续伤害；若敌方未在限时内完成行动，则打断当前可打断行动 | 强化乐芙兰的专属技能效果 |
| 拉克丝 | 我方获得护盾，并使敌方减速 | 释放高伤害激光 |
| 拉露恩 | 在高伤、吸血、减速三种武器状态之间切换 | 依据当前武器状态释放对应强化效果 |
| 倪克斯 | 造成多段伤害或治疗，并在伤害/治疗两种形态间切换 | 依据当前形态造成伤害或治疗；共享生命越低，效果越强 |
| 朱庇特 | 对敌方施加火伤 | 获得鼓舞；持续期间每主动打出一张攻击牌便延长鼓舞时间 |
| 芙宁娜 | 提高命潮自然充能速度，并提供持续治疗 | 获得增伤与命潮充能加速 |
| 纳西妲 | 对敌方施加毒伤 | 立即额外结算战场上全部单位的毒伤与持续治疗，包括我方自身状态 |

“查莉娅相关效果的伤害”只读取她的专属卡及分支明确标注的效果，不建立伙伴独立普攻。纳西妲绝技对敌我双方统一结算：我方若带有毒伤也会受伤，我方持续治疗也会被提前结算。

## 七、内容约束

- 技能与绝技必须服从命定石在《源神石.md》中的战斗语言，同时允许借公共卡形成跨石联动。
- 卡面不得依赖位置、范围、指定友军、指定敌人、位移、召唤棋盘单位或独立角色生命。
- 卡面可以读取共享生命、护盾、命潮、敌方意图与进度、卡牌类别、牌区、状态和生成事件。
- 美术采用双层规格：局外剧情与收集使用精美海报；局内使用角色头像、卡面插画与状态表现。
