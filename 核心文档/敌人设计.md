# 《三乂川》敌人设计 v0.7

> 敌方以单一战斗实体和行动池参与战斗。本文件规定所有敌人的统一行为接口与内容层级。

## 一、敌方单位结构

- 每场战斗只存在一个敌方战斗实体和一条敌方生命值。
- 不再使用2—4单位阵容、前后排、站位、射程、索敌、移动、位移、召唤单位或范围红区。
- 敌方可以拥有护盾、力量、增益、毒伤、火伤、易伤、脆弱、虚弱和减速等状态。
- 敌方生命归零时战斗胜利。

## 二、行动池接口

- 每个敌人拥有一个行动池，行动可包含攻击、护盾、增幅、施加状态、污染牌组等类型。
- 敌人选择一项行动后，立即公开行动名称、类型、主要结果及行动进度条。
- 进度条蓄满时自动结算该行动，再选择下一项行动。
- 减速只降低进度填充速度，不回退已有进度。
- 打断取消当前可打断行动并使敌人重新选择行动。
- 每项行动自身标明能否被打断；不可打断行动仍可被减速。行动池的选择逻辑、具体行动和控制抗性由各敌人内容定义。

## 三、行动设计原则

- 行动意图必须让玩家能够使用输出、护盾、治疗、净化、减速或打断作出回应。
- 行动池需要同时包含压力行为和节奏行为，避免只用不同数值的普通攻击填充。
- 牌组污染应使用一次性惩罚、永久惩罚或处理型负面状态牌，并给玩家留出压缩、净愈术等处理接口。
- 毒伤穿盾，火伤受盾且附带重伤；敌人若使用毒火，必须遵守与玩家一致的底层状态规则。
- 敌方行动、持续状态和进度均使用0.1秒tick。
- 所有伤害、进度速度、状态量、抗性和行为权重在数值策划阶段确定。

## 四、内容层级接口

| 层级 | 行动池要求 |
|------|--------------|
| 普通战 | 小型行动池，突出一个清晰教学主题 |
| 稀有战 | 组合两条机制，并加入污染、控制抗性或构筑检验 |
| 传说战 | 高强度组合行动池，提供相应的高档战斗奖励 |
| 九域Boss | 使用所属九域与源神石语言，拥有阶段转换或行动池升级；玩家战败扣石后不重试 |
| 最终Boss | “48兵”；位于九域之后，战败直接结束本次轮回 |

九域名称、统治者与源神石归属见《世界观.md》。Boss行动使用所属源神石语言，且不依赖棋盘空间规则。普通、稀有、传说三档战斗的品质越高，敌人难度越高、胜利奖励越多。
