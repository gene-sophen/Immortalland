# 《三乂川》敌人设计总纲

## 一、敌方统一结构

- 每场战斗只有一个敌方实体、一条生命、一条护盾和一套状态。
- 不使用多单位阵容、前后排、站位、射程、索敌、移动、位移、召唤单位或范围红区。
- 敌方可以使用攻击、护盾、恢复、增幅、减益、毒伤、火伤、冰冻、污染、卡牌限制与阶段转换。
- 敌方与玩家共享毒火、虚弱、易伤、脆弱、减速、打断、护盾和实时tick底层规则。

## 二、行动池接口

- 每个敌人拥有独立行动池。选择行动后立即公开名称、类型、主要数值、状态结果、预计完成时间及是否可打断。
- 进度条蓄满时自动结算，再依据顺序、权重、条件或阶段选择下一项。
- 减速只降低进度填充速度，不回退已有进度；打断取消当前可打断行动并重新选取。
- 不可打断行动仍可减速。控制抗性、阶段免疫和类型限制必须在行动开始前公开。
- 敌人死亡后取消未结算行动；同tick与玩家同时死亡时判玩家胜利。

## 三、机制标签

| 标签 | 战斗职责 | 玩家主要回应 |
|------|----------|--------------|
| 火伤 | 叠加不穿盾伤害并刷新重伤 | 护盾、快速击杀、火伤反制 |
| 毒伤 | 上限9层的穿盾持续伤害 | 净化、恢复、缩短战斗 |
| 高恢复 | 延长战斗并检验持续输出 | 爆发、易伤/脆弱、减疗 |
| 高护盾 | 周期性建立厚盾 | 破盾、毒伤、敌盾反制饰品 |
| 冰冻 | 限制出牌或降低命潮节奏 | 净化、预留命潮、抗性饰品 |
| 快速启动 | 短进度行动连续施压 | 开场资源、减速、打断 |
| 攻击削减 | 降低力量或直接伤害质量 | 状态处理、毒火、能力成长 |
| 负面牌 | 注入一次性、循环或主动处理牌 | 净化、变化、消耗和运转 |
| 后期增伤 | 随行动次数或时间成长 | 快攻、打断关键增幅、防杀竞速 |
| 卡牌限制 | 临时限制类别、费用或主动出牌方式 | 跨类牌组、牌序调整、窗口规划 |

## 四、怪池架构

非Boss敌人采用“公共池为主、少量领域特产为辅”的结构，不为九域分别制作对称怪池。

| 池 | 数量 | 出现范围 | 职责 |
|----|------|----------|------|
| 公共小怪 | 12 | 九域全部 | 基础攻防、毒火、恢复、命潮、污染、控制与成长教学 |
| 公共精英 | 12 | 九域全部 | 检验成熟Build的输出、生存、增伤与运转 |
| 领域特产小怪 | 5 | 指定领域 | 地方生态、特殊遭遇或关联掉落，不设每域配额 |
| 领域机制精英 | 5 | 指定领域 | 深度使用某条潮律，不设每域配额 |
| 领域Boss | 9 | 各领域固定1名 | 完整演绎潮律与叙事主题 |
| 48兵 | 1 | 终战 | 读取本轮三个领域和剩余命源石 |

- 常规战默认从公共小怪池生成；当前领域有特产小怪时，20%概率改从领域池生成。
- 精英节点默认从公共精英无重复展示3名；当前领域有领域精英时，35%概率替换其中1名。
- 本轮已击败的同名精英在仍有未击败模板时不再出现；第二个精英位置提高中后期标签权重。
- 特定掉落只是额外获取接口，不垄断对应饰品来源，也不要求每个领域存在。
- 普通、稀有、传说品质决定同进度难度和奖励，不等同于普通怪、精英或Boss层级。
- 公共战依据角色等级、领域序位和品质缩放；Boss只读取领域序位；48兵额外读取命源石档位。

### 公共小怪

路劫客、铁壳兽、双刃偶、吮血蛭、灰烬犬、毒囊虫、霜齿兽、漏潮机、抄写鬼、伤口傀、断脉客、守岁像。

### 领域特产小怪

镜晶境采晶客、荒脊岭拾骸犬、火尽山拾票人、皮安城拾件工、过明氹采露人。松三原、啼亡堆、潮王原和平安京不强制配置特产小怪。

### 公共精英

破城槌、铁壁匠、饮伤者、焚血祭司、降解兽、逆频塔、禁书灵、三相兽、双面役、复制机、百啄鸟、扛山鬼。

### 领域机制精英

镜晶境叠壁匠、火尽山三幕伶、皮安城总闸卫、啼亡堆九科官、潮王原万声体。其余领域由公共精英叠加潮律承担。

## 五、九域潮律接口

潮律是进入战斗前公开的敌我共享规则，不是隐藏惩罚。双方遵守同一底层，域主通过行动池与其形成更高效率的组合。

| 领域 | 源神石 | 潮律 |
|------|--------|------|
| 镜晶境 | 金刚石 | **破镜**：任一方护盾被完全击破时，击破者获得4秒裂光；环境风暴不触发 |
| 荒脊岭 | 大理石 | **血火秤**：任一方每累计实际失去20%最大生命，获得1次烬势；下一主动直接伤害提高并附加火伤 |
| 火尽山 | 戏命石 | **终幕拍**：玩家第3张主动牌、敌人第3次完成行动的主效果提高25%，随后独立清零 |
| 皮安城 | 海克石 | **过载律**：玩家累计自然恢复3命潮、敌人完成3次行动后，下一主动效果提高25%，结算后自身减速1秒 |
| 松三原 | 陶玉石 | **流势**：同一方3秒内连续造成伤害时，从第2段起每段+5%，最高+25%；断连清零 |
| 过明氹 | 降解石 | **净蚀**：任一方主动净化自身负面状态时，对方获得1层毒；一次净化事件只触发一次 |
| 啼亡堆 | 科目石 | **进阶**：玩家连续3张同类别牌、敌人连续3个同标签行动时，第3次主效果+25%；换类清零 |
| 潮王原 | 卡厄石 | **异变潮**：双方首次同时具有3种可计数状态时，下一主动行动取得开战公开的对应异变 |
| 平安京 | 阴阳石 | **昼夜轮**：每10秒昼夜交替；昼使常规直接伤害+15%，夜使护盾与治疗+15% |

- 潮律必须允许玩家反向利用，不能只给敌方收益。
- 领域特产怪用潮律表现生态，精英用潮律构成构筑检验，域主用潮律建立阶段核心。
- 潮律效果、敌方行动数值、品质倍率、Boss三套序位数值和48兵档位统一见 `敌方数值表.md`。

## 六、负面牌投放

- 普通怪主要使用茫然、黏液和少量灼痕；稀有战可加入裂创、伤口与虚空；精英可围绕催命符或重复污染形成机制。
- 敌人不投放永恒轮回诅咒绊脚石和扫把星。
- 高伤害与重污染不能同时达到同档最高值；污染行动必须给出处理窗口。
- 自动出牌不能替玩家处理负面牌，敌人设计必须考虑主动处理所需的命潮和换组机会。

## 七、Boss与48兵边界

- 领域Boss每次阶段转换必须更新视觉、行动池或行动选择逻辑，不能只提高数值。
- Boss失败按所在领域损伤1/2/3颗命源石，结算后继续，不允许重试。
- 48兵不属于九域，不掉源神石；战败直接结束轮回。
- 48兵强度读取进入战斗时剩余命源石，形成“绝境石补偿更强、终战也更危险”的背水路线。
- 第九重复起是同一场战斗的第二阶段；最终状态、风暴计时与行动池以48兵专表裁决。

## 八、制作与表现

- 公共敌人只制作一套主剪影和动作骨架，在不同领域加载轻量环境附着层，不以换色伪装新怪。
- 品质通过意图环层数表达，不能依靠敌人主体换色影响状态识别。
- Boss换相暂停模拟时间0.8秒，更新视觉和行动池后再登记下一意图；演出期间不得隐藏状态与风暴预警。
- 完整剪影、动作、音效、意图图标、Boss换相与48兵复起规格见 `敌方美术与演出.md`。
