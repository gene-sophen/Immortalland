# 《三乂川》敌人设计 v0.4（行为框架）

> 敌方与玩家同构：**自动普攻 + 释放常规卡（攻击/buff/debuff）+ 蓄能绝技**——玩家会的敌人都会，只是卡组更薄、节奏更电报化。
> 三档敌人：杂兵 / 精英 / 关底Boss；Boss走独特机制。

---

## 一、敌方阵容规则

| 项目 | 规则 |
|------|------|
| 规模 | **杂兵/精英战2-4名；Boss战1名+增援**（增援计入召唤上限2） |
| 站位 | 敌方区5格自动布阵，射程规则与玩家一致（近1/中2/远3） |
| 职业 | 敌单位同用六职业六轴（敌版面板，数值锚见战斗.md §八） |

## 二、敌方行为结构：与玩家同构的"薄卡组"

每名敌单位 = 普攻（自动）+ **行为卡组2-3张**（循环）+ **绝技1张**（蓄能，精英以上）：

```
行为循环：普攻…普攻…(CD到)打行为卡A…普攻…(CD到)打行为卡B…绝技蓄满→绝技
```

- **行为卡**：从"敌方版常规卡池"配置——攻击卡（重击/连射/AOE）、buff卡（加攻/护盾/治疗）、debuff卡（中毒/虚弱/灼烧），与玩家公共卡同一词库，效果走敌方面板
- **释放节流**：**纯独立CD**（每张行为卡独立冷却6-12s，到点即打）——不做敌版命潮费用轨，简单且电报清晰
- **绝技**：精英与Boss持有；蓄能条**对玩家可见**（充能进度头顶显示）——给玩家"打断窗口"的博弈
- **电报化铁律**：所有高伤害行为卡/绝技带前摇红区（15tick），可预判、可应对（战斗.md §八）；前摇中的技能可被「打断」类效果取消
- **过明氹特例**：该域敌方技能无前摇提示（只能看到位置，数值与意图未知，冒险系统.md §2.2）

## 三、三档敌人

### 3.1 杂兵

- 行为卡1-2张，**无绝技**
- 职能模板6种：**近战莽夫/远程射手/毒虫/盾卫/小奶妈/召唤师**——各域换皮+挂本域石头词缀（火域杂兵普攻附灼烧）
- 定位：测构筑下限、给连胜节奏

### 3.2 精英

- 行为卡2-3张 + **绝技1张**（精英起持有，玩家提前预习打断博弈）
- 在杂兵模板上加**精英词条**（1-2条；词条池12-18条）：吸血/反伤/分裂召唤/免控/狂暴……词条池与石头关键词呼应
- 掉领域主题牌+散件（主题掉落规则不变）

### 3.3 关底Boss：九域镜像全表

- **独特机制个体**，不用模板：机制 = 该域源神石关键词的**敌方镜像**（源神石.md §一）
- 结构基准：**全Boss统一2阶段**（半血转阶段，转阶段=清debuff+机制切换+增援召唤）
- 绝技至少1个，多为"全场级"（AOE/全场debuff/强制机制），电报更长更华丽
- 召唤上限2（**含Boss增援**；防铺场失控，战斗.md §八）

| 领域 | Boss | 镜像机制方向 |
|------|------|------------|
| 镜晶境 | 欧金金 | **反伤**：阶段二全身反震，逼玩家换目标/控伤害节奏 |
| 荒脊岭 | 沃夫冈 | **碾压**：大体型高生命，周期性全屏灼烧波+深红矿脉地皮扩散（电报化逐行推进） |
| 火尽山 | 异画师 | **处刑**：标记血量最低者，第4次攻击必暴处决 |
| 皮安城 | 维克托 | **进化**：战斗中持续自我强化，周期性"升级"一件自身装备词条，拖久必败 |
| 松三原 | 食欲饕 | **吞噬传导**：吞噬我方增益并沿敌方队伍传导扩散；阶段二开始吞噬我方召唤物/护盾 |
| 过明氹 | 张学良 | **降解**：玩家装备效果随战斗时间衰减，逼速杀；阶段二"优势在我"：自身减伤随时间上升，与玩家装备衰减对冲 |
| 啼亡堆 | 板蓝根 | **献祭**：周期性献祭自方小怪，自身叠攻——杀小怪反而养Boss |
| 潮王原 | 赵元任 | **混沌**：每20s随机换一套行为卡组；潮汐机制放大：涨潮期其伤害+50% |
| 平安京 | 妖刀姬 | **阴阳轮转**：昼形态高攻速斩杀、夜形态高减伤回复，转阶段=昼夜倒转，逼玩家错节律输出 |

> Boss具体机制细则（技能数值/节拍/增援配置）为内容填充项，制作阶段展开。
