# 《三乂川》事件系统

> 事件、营地与特殊战斗共同承担局内主要剧情演绎。事件不是奖励菜单套一层文案，而是让玩家用构筑、资源、身份与骰子回答九域问题的短篇场景。

## 一、事件体验目标

每个事件至少完成三件事中的两件：

1. 改变本轮回资源、牌组或饰品结构。
2. 留下一次可在营地、特殊战斗或后续事件中回响的选择。
3. 揭示一条九域、伙伴、身份、48兵或川灵的信息。

事件固定三项入口，但入口后的结构可以不同：立即结算、挑选目标、公开投骰、取得任务事印、进入特殊战斗或在后续节点兑现。禁止把三个选项长期固化成“小奖/中奖/赌大奖”的同一模板。

## 二、三选一结构库

| 结构 | 三项关系 | 适用场景 |
|------|----------|----------|
| **稳—改—赌** | 稳定收益、可控结构调整、公开骰面高波动 | 初见事件、资源事件 |
| **同源异路** | 三项价值接近，但分别服务输出、生存、运转或不同叙事立场 | 领域文化、构筑检测 |
| **即得—延期—挑战** | 立即小收益、携带事印后兑现、进入特殊战斗换高收益 | 中后期事件 |
| **献一得一** | 三项分别要求卡牌、饰品、生命/纽币等不同代价 | 交易、祭祀、审判 |
| **三种回答** | 机械收益相近，身份、伙伴和后续文本不同 | 主线与角色事件 |
| **三档特殊战** | 进入战斗前公开敌方机制、限制与奖励 | 竞技、试炼、域主前兆 |

事件生成时必须保证至少一项合法。若某项因没有卡牌、饰品或足够资源而锁定，锁定原因直接显示；不得暗中替换目标或先扣款再发现无法执行。

## 三、骰子系统深化

### 3.1 公开顺序

选择骰子入口前，界面必须展示：投入、1—6点全部结果、是否允许追掷、铅骰子等修正后的结算顺序。流程固定为：

```text
选择骰子入口与筹码
→ 生成原始点数
→ 决定是否使用事件提供的追掷
→ 应用重掷后的最终原始点数
→ 应用铅骰子等点数修正
→ 限制在1—6
→ 原子结算代价、奖励与事印
```

### 3.2 三种骰局

| 骰局 | 规则 | 深度来源 |
|------|------|----------|
| **直投** | 一次投掷，高点不低于低点 | 读清收益分布，决定是否接受波动 |
| **追投** | 第一次结果公开后，可支付事件写明的追加代价重投一次；必须接受新结果 | 用资源购买第二次机会，不保证变好 |
| **定契** | 投前从两份公开契约中选一份，如“低点保底”或“高点加码”，再用同一骰面结算 | 先决定风险形状，再接受随机 |

- 所有事件的总体价值随点数不下降，点数可能改变奖励类型，但高点不能比低点更差，确保铅骰子的+1始终是正面效果。
- 传说事件不偷偷提高骰点，而是增加一项追投权、提高高点结果的独特性，或让6点产生剧情后续。
- 骰子结果可以检查身份、伙伴、饰品或事印，但只能增加叙事变体或把同价值奖励变得更适配，不得隐藏扣除。
- 骰面中的源神石机会只在对应领域的传说事件且最终为6点时生效；普通与稀有版本的同格结果改为三级常规饰品。若本轮回已经取得或失去过该源神石，也改为三级常规饰品三选一，不重掷。

## 四、品质与事件深度

| 品质 | 内容变化 | 奖励变化 |
|------|----------|----------|
| **普通** | 完成一个自足场景，通常一次选择结算 | 基础收益，代价可恢复 |
| **稀有** | 增加构筑检测、伙伴/身份反应或一个后续事印 | 更适配当前Build，允许二级卡或二级饰品 |
| **传说** | 形成跨节点回响、特殊战斗或领域真相片段 | 允许三级常规饰品、源神石机会或改变路线规划的收益 |

同一事件的普通、稀有、传说版本可以使用同一底座，但必须至少改变一项选项内容或后续，而不是只把纽币乘一个倍率。

## 五、事印与跨节点回响

- **事印**是事件产生的临时任务标记，不是卡牌或饰品，不占槽位；最多同时持有2枚。
- 新事印超过上限时，玩家选择放弃旧事印或放弃新事印；放弃不会追加隐藏惩罚。
- 事印必须公开触发地点、成功条件、失败/过期条件和奖励类型。
- 营地可以为当前事印播放一段短回应；特殊战斗可以把事印转成公开的额外机制或奖励。
- 事印在轮回结束时失效，不进入继承。

## 六、九个通用事件

### 1. 三悬礼

三只悬在枯树上的礼篮分别盛着昨日、今日与明日。川灵不解释哪一只属于谁。

| 选项 | 内容 |
|------|------|
| **取今日** | 获得经验并恢复当前局外冒险进度对应的成长收益；若因此升级，礼篮留下身份对应短句。 |
| **借明日** | 提高本轮回共享生命上限，但下一个非营地节点的基础经验延迟到再下一个节点一并结算。 |
| **问昨日·直投** | 1：少量纽币；2：纽币+一级卡；3：经验+一级卡；4：二级卡；5：一级饰品+纽币；6：二级饰品并解锁一条失败世界残语。 |

稀有版本会根据当前生命、牌组厚度和饰品槽状态，让固定选项自动选择更适配的收益类型；传说版本的6点留下“昨日签”事印，下一次营地可以在三项营务后额外回看一段川灵记忆，不增加机械收益。

### 2. 活墙三问

一堵会呼吸的石墙问：“你要忘掉、改写，还是让同一句话被说第二遍？”

| 选项 | 内容 |
|------|------|
| **忘掉** | 删除1张可删除普通卡。 |
| **改写** | 选择1张一级或二级普通卡，再从同等级、不同类别的3张随机卡中选择1张变化。 |
| **复述** | 选择1张非满级普通卡，获得一张同名新卡，并正常选择加入或升级；同时令下一次商店删卡涨价。 |

稀有版本会根据被处理卡牌所属源神石留下对应壁画；传说版本若处理的是初始牌，会在图鉴记录一条该身份“没有走过的开局”，但不改变身份永久初始牌组。

### 3. 偶藏室

房间里没有主人，只有三只不断交换位置的木偶手。每只手都在模仿队伍中一人的动作。

| 选项 | 内容 |
|------|------|
| **拿走掌中物** | 从3件一级常规饰品中选择1件。 |
| **为木偶换装** | 支付纽币，从2件二级常规饰品中选择1件；当前空槽越少，价格越低，鼓励主动替换。 |
| **拉动暗线·定契** | “收手”：1—3一级、4—5二级、6三级；“深取”：支付额外纽币，1无饰品但返还部分投入、2—4二级、5—6三级。所有结果均从合法来源池生成。 |

当前伙伴会评论模仿自己的木偶。传说版本6点可以生成一件当前伙伴体系相关的三级常规饰品，但不能生成伙伴专属饰品或源神石。

### 4. 识命之颅

石颅每回答一个问题就少一颗牙。它拒绝谈论死亡，只愿意谈代价。

| 选项 | 内容 |
|------|------|
| **问身** | 降低少量本轮回生命上限，获得大量经验；若正处于低生命上限Build，改为提供二级防御或虚弱卡。 |
| **问财** | 加入一张非永恒负面牌，获得大量纽币；负面牌从当前构筑最能处理的两种与随机一种中三选一。 |
| **问命·追投** | 先支付少量纽币。1：返还部分；2：一级卡；3：经验；4：二级卡；5：二级饰品；6：提高生命上限并取得一件二级饰品。第一次不高于3可追加支付生命上限追投。 |

第六重以后，石颅的牙齿会与48兵姓名产生对应，事件文本从怪谈切入真相层。

### 5. 蒙面换客

换客不问物件值多少钱，只问它陪你走过多少路。

| 选项 | 内容 |
|------|------|
| **换旧物** | 展示持有时间最长的3件可交易常规饰品，选择1件换取同品质、不同主要端的饰品。 |
| **换同路** | 选择1件常规饰品，换取同品质且与当前最高占比卡牌类别联动的饰品。 |
| **换未知·直投** | 献出1件常规饰品。1—2：同品质随机；3—4：同品质定向二选一；5：高一品质随机；6：高一品质三选一。三级不会继续升阶，而是三选一三级。 |

稀有以上会记住被换走的饰品；之后若在商店再次看见同名物，描述增加旧主批注，但不改变价格。

### 6. 诅咒古卷

古卷不是一本书，而是一段拒绝结束的弃牌动作。每翻一页，手里都会多出一张不属于你的牌。

| 选项 | 内容 |
|------|------|
| **浅读** | 从3张一级卡中选1张，并查看一种负面牌的图鉴信息。 |
| **深读** | 从3张二级卡中选1张，同时从3张基础负面牌中选择1张加入局内牌组。 |
| **通读·追投** | 先公开将加入的负面牌。1：一级卡；2：二级卡；3：删除另一张可删除负面牌；4：二级卡+纽币；5：三级常规饰品；6：三级常规饰品并把本次负面牌变为本场可处理版本。可支付纽币追投一次。 |

传说版本通读6点解锁一则48兵留下的批注；批注只改变叙事，不提前揭露完整真相。

### 7. 沉没宝库

宝库半浸在源海里。每拿走一件东西，水面都会升高一点。

| 选项 | 内容 |
|------|------|
| **取浮箱** | 获得稳定纽币，不产生后续。 |
| **潜入中层** | 获得大量纽币并取得“潮债”事印；完成下一场战斗胜利即可清除，失败则加入一张非永恒负面牌。 |
| **摸向底层·定契** | “系绳”：低点给纽币、高点给饰品；“断绳”：投入生命上限，1—2大量纽币，3—4二级饰品+纽币，5三级饰品，6三级饰品+高额纽币。 |

若纳西妲或芙宁娜同行，会提供不同的水下叙事视角，但不替玩家消除潮债。

### 8. 心念盛放

花不读取愿望，只把牌组中最常重复的行为开成颜色。

| 选项 | 内容 |
|------|------|
| **剪下一瓣** | 根据牌组最高占比端，从输出、生存、运转对应的3张二级卡中选择1张。 |
| **连根移植** | 提高生命上限并取得一张能力牌，同时加入一种与当前Build可互动的非永恒负面牌。 |
| **让它结果** | 进入公开的特殊战斗：敌人复制玩家最常用类别的一项优势；胜利获得三级饰品三选一，失败不碎命源石且只获得纽币。 |

传说版本的特殊敌人会说出当前身份的一条反事实人生。胜利后这条文本进入图鉴身份支链。

### 9. 远行委托

委托人永远背对队伍，只把三枚事印放在路边。

| 选项 | 内容 |
|------|------|
| **战印** | 下一场普通或精英战胜利时，按战斗难度获得卡牌与战利池饰品选择；普通战失败则事印失效。 |
| **商印** | 下一次商店完成付费购买、删卡或回收后，返还部分价值并额外刷新一次；离开两个领域仍未完成则失效。 |
| **营印** | 下一次营地完成指定营务后，额外获得经验，并让该营务产生一段伙伴剧情。 |

稀有版本允许查看每枚事印的具体奖励候选；传说版本完成事印后，委托人会在本领域第二场精英战前出现并提供一次不占冒险次数的补给。

## 七、九域专属事件

### 1. 镜晶境·镜中三身

三面镜分别映出曾经的你、现在的你和从未存在的你。

| 选项 | 内容 |
|------|------|
| **向过去致意** | 复制1张普通卡；复制品可以正常用于同名升级。 |
| **与现在争辩** | 选择1张一级或二级卡，从同等级不同类别3张中选择变化，并获得少量护盾型冒险补给。 |
| **触碰未生者·直投** | 1：随机同级变化1张；2：定向变化1张；3：变化2张；4：取得二级卡；5：取得镜晶境二级饰品；6：从三级常规饰品与金刚石机会中按合法唯一规则生成三选一。 |

镜面台词读取当前身份；若艾德明携带钥匙，第三面镜始终没有倒影，只增加真结局伏笔。

### 2. 荒脊岭·骨火献礼

骨火不烧尸骨，只烧“还想带走什么”的念头。

| 选项 | 内容 |
|------|------|
| **献攻击牌** | 从3张合法攻击牌中选1张删除，获得力量向二级卡或战斗饰品。 |
| **献非攻击牌** | 从3张合法非攻击牌中选1张删除，获得生命上限、恢复或防御向二级卡。 |
| **献旧物** | 选择1件常规饰品焚化，根据品质获得荒脊岭域产饰品选择；三级旧物会附加一段域主真相。 |

如果没有合法卡牌或饰品，对应火盆熄灭。查莉娅同行时会阻止骨火把“承受伤害”误解为献祭，并提供额外对白。

### 3. 火尽山·终幕偶戏

三具木偶分别扮演英雄、观众与纵火者，戏词会根据本轮回最常使用的攻击方式改变。

| 选项 | 内容 |
|------|------|
| **接过英雄偶** | 取得火伤或虚无方向二级卡，并使下一场战斗开场获得短时鼓舞。 |
| **坐进观众席** | 交换1件常规饰品，换取火尽山域产饰品；交换前完整展示结果。 |
| **剪断提线·追投** | 1—2：获得纽币并承受一场短时负面；3—4：二级饰品；5：三级火伤/虚无饰品；6：获得戏命石机会。第一次不高于3可进入一场特殊战，胜利后按原点数+2结算。 |

朱庇特同行时，木偶会把“纵火者”改称“报幕人”；第六重以后揭示偶戏台词来自一名48兵。

### 4. 皮安城·无尽流水线

流水线制造的不是商品，而是“下一张应该被抽到的牌”。三条传送带分别追求一致、效率与意外。

| 选项 | 内容 |
|------|------|
| **制式线** | 选择1张非满级普通卡，获得同名新卡并正常选择加入或升级。 |
| **拆解线** | 消耗或删除1张合法普通卡，换取若干生成牌相关补给与一件一级/二级机造饰品。 |
| **越权线·定契** | “稳产”保证二级卡或二级饰品；“超产”可能加入虚空，4点以上生成三级机造饰品，6点提供海克石机会。 |

芙宁娜与奥丽莎同行时拥有不同的总闸对白；玩家此前持有“工票”类事印时可以让流水线在下一次营地追加一段机械维护剧情。

### 5. 松三原·彩石辩庭

三位石民并不争论谁正确，而是争论一种生活应当怎样支付代价。

| 选项 | 内容 |
|------|------|
| **主张锋利** | 从打击、重击、鼓舞方向的3张卡中选1张；下一场战斗敌方生命略高、金币提高。 |
| **主张长存** | 从防御、虚弱、治疗方向的3张卡中选1张；提高生命上限或取得恢复饰品。 |
| **主张流通** | 从能量、整备、锻造方向的3张卡中选1张；下一家商店第一次刷新免费。 |

三项价值接近，按当前牌组缺口调整展示卡，不强迫玩家选择已有最高占比端。葛朗台在场时，辩庭会追问“价值是否必须能出售”。

### 6. 过明氹·纯白泉眼

泉水能洗去污染，也能洗去与污染一同留下的记忆。

| 选项 | 内容 |
|------|------|
| **只洗伤口** | 删除1张可删除负面牌，或在没有合法目标时净化下一场开局的一种负面状态。 |
| **洗到无名** | 将1张负面牌变化为同等级投放的一张普通牌；若目标为永恒诅咒，则不能变化，改为获得处理它的临时能力。 |
| **饮下泉眼·直投** | 1：加入伤口并恢复成长资源；2：恢复；3：提高生命上限；4：二级净化卡；5：毒/净化饰品；6：降解石机会并解锁泉眼记忆。 |

纳西妲同行时会指出泉水同时在净化自己；该对白是她绝技“毒与治疗同时结算”的叙事根源。

### 7. 啼亡堆·亡者书库

书库按死者最后一次出牌分类，而不是按姓名分类。

| 选项 | 内容 |
|------|------|
| **翻锋卷** | 从输出端公开5张一级/二级卡，选择1张。 |
| **翻守卷** | 从生存端公开5张一级/二级卡，选择1张。 |
| **翻流卷** | 从增伤与运转端公开5张一级/二级卡，选择1张。 |

稀有版本会在每卷中插入一页与当前伙伴对应的轶闻；传说版本选牌后可以把其页签变成“亡页”事印，在下一次该牌升级为三级时解锁一条48兵生前记录。

### 8. 潮王原·混沌香圃

每朵花都把一种结果的气味传给另一朵。改变一张牌时，远处某件东西也会改变。

| 选项 | 内容 |
|------|------|
| **移栽牌花** | 选择1张一级/二级普通卡进行同级三选一变化；变化后获得与新类别对应的小额资源。 |

拉露恩同行时会为三种武器状态分别闻出不同气味；卡厄石已经取得时，骰子高点不额外增值，而是将奖励改成更适配当前异相的类型。

### 9. 平安京·明暗双门

明门承认代价，暗门承认欲望，中门只承认骰子落地的声音。

倪克斯同行时，明暗门不会使用善恶词汇。第九重携带钥匙与绝境石时，门后文本会补全《定川》前最后一段线索，但不跳过48兵战斗。

## 八、营地与特殊战斗的剧情承接

### 营地

- 每次营地进入时，从当前伙伴、本领域事件回响、当前事印和命源石状态中选择一个主题播放短场景。
- **温存**优先播放人物关系和生命成长；**锤子**优先播放身份、卡牌与选择的讨论；**挖掘**优先播放领域历史和器物来历。
- 三务帐篷执行三项营务时，三段短场景按玩家选择顺序连接成一段，不重复开场和收束。

### 特殊战斗

- 特殊战斗进入前展示其来源事件、额外机制、胜败奖励和是否损伤命源石；默认失败不碎石，事件明确标注时除外。
- 事件特殊敌人使用现有敌人标签的变体，不创建只出现一次却需要全新规则教学的复杂系统。
- 胜败都必须推进该事件的故事，只改变奖励和角色判断，不能失败后像事件从未发生。

## 九、文本生产规格

每个正式事件至少需要：

- 普通开场1组、稀有追加1组、传说追加1组。
- 三项按钮短文案与完整说明各1套。
- 每项结算文本1组；骰子至少按1—2、3—4、5、6四档写反馈。
- 九身份反应不要求全覆盖，但每个事件至少配置2个身份钩子或2名伙伴钩子。
- 第一至第五重使用世传/裂隙层文本，第六重后允许替换真相层文本。
- 事印取得、即将过期、成功、失败各1条系统文案。

文本资产使用 `EVT_<事件>_<品质>_<阶段>_<分支>` 命名；机制参数读取配置表，不把具体纽币、生命、经验和概率写死在剧情正文中。

## 十、拍板边界

1. 正式事件池固定为9个通用事件与九域各1个专属事件，共18个基础事件；品质、身份、伙伴、轮回层和事印让同一底座产生不同内容。
2. 事件仍固定三项入口，允许入口后出现选目标、契约选择、追投或特殊战斗。
3. 普通公共卡不使用永恒；事件不能删除、变化或复制永恒牌。
4. 事件不直接产出普通三级卡；三级普通卡仍只能由同名卡升级。事件可以产出三级常规饰品或源神石机会。
5. 事件奖励量与特殊敌人属性读取经济和敌人数值表；本文件固定事件结构、剧情功能、选项关系与合法性。
