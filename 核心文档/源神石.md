# 《三乂川》源神石体系 v0.5

> 定位：源神石是**全游戏体系的上游枝干**——九域主题、卡牌注入、流派（饰品格）、Boss设计、事件全部从这张表辐射。
> 九石关键词**织成联动网**而非九个孤岛；覆盖游戏全部系统维度，无遗漏、不撞车。

---

## 一、九石关联体系

| 源神石 | 核心意象 | 关联体系 | 一句话机制方向 |
|--------|----------------|---------------|---------------|
| **阴阳石** | 反转调和，昼夜变换 | **循环 · 增益 · 抑制** | 周期性在"增益己方/抑制敌方"间切换，昼夜节律 |
| **科目石** | 阶级分明，科目四 | **献祭 · 成长 · 增益** | 以献祭换阶级跃升，击杀/牺牲滚雪球 |
| **卡厄石** | 拥抱不可预测 | **随机 · 变异 · 循环** | 效果随机变异，但循环回归（混沌中有节律） |
| **戏命石** | 优雅杀戮艺术，烬 | **暴击 · 处决 · 远程** | 计次艺术（每第N次必暴/强化），斩杀低血目标 |
| **降解石** | 依旧优势在我 | **装备 · 献祭 · 衰减** | 降解装备换短期爆发；让敌方随时间降解变弱 |
| **海克石** | 加入光荣进化 | **能量 · 进化 · 装备** | 命潮/蓄能运转轴，装备随战斗进化强化 |
| **金刚石** | 最坚硬，炫目闪光 | **防御 · 经济 · 反伤** | 金刚不坏+纽币生财，挨打反震 |
| **大理石** | 大力士，深红纹理 | **生命 · 力量 · 灼烧** | 大体型高生命，力量碾压，岩火dot |
| **陶玉石** | 温润如肌肤 | **群伤 · 多段 · 传导** | 温润传导：效果在敌我间扩散，多段快速 |

- **装备分工**：海克=造装/强化（正向）；降解=腐蚀/拆解（负向）
- **戏命"远程"**落地形态=斜排贯穿/任意目标
- **科目"召唤"**留待召唤物系统上线启用，现阶段以献祭/成长/增益三面运营

**不碰清单（负面清单，与关键词互为表里）**：

| 源神石 | 不碰 |
|--------|------|
| 阴阳石 | 直伤爆发 |
| 科目石 | 回复 |
| 卡厄石 | 稳定数值线 |
| 戏命石 | 回复/治疗 |
| 降解石 | 永久增益 |
| 海克石 | 伤害词（已有纪律：无源流伤害词） |

## 二、九石视觉设定

> 设计原则：①不走色环，色泽从石头自身的材质与光学特征出发；②每石 = **主材质 + 色泽 + 形态 + 动态光效**四要素，辨识度做到"遮住名字能认出是哪颗石头"；③本表为九石唯一视觉标准。

| 源神石 | 视觉设定（材质/形态/光效） |
|--------|---------------------------|
| **阴阳石** | 浑圆球体，一半玄墨一半素白，两半如双鱼互抱，边界缓缓流转。昼时白半涨、夜时黑半涨，交界线溢出极细的金线光。光效=呼吸式明灭，像一枚缓缓转动的活太极。 |
| **科目石** | 细长竖棱柱，如一根笔直竖指，九道环纹自上而下等距排布（阶级分明），越靠顶端环纹越亮。通体琉璃质感的青金色，内有光自底部逐环向上"品阶式"点亮，到顶后回落循环。 |
| **卡厄石** | 不规则多面碎块，表面色彩每时每刻都在缓慢流动重组——青紫橙红彼此侵染，没有两秒相同。棱面之间偶尔闪过纯黑裂隙。光效=无规律脉冲，全场唯一一颗"永远静不下来"的石头。 |
| **戏命石** | 正四边形的黑玉薄片，四边锋利如刃，边缘镀一线冷银。表面极光滑，只在持有者完成击杀的瞬间掠过一道血色微光——像舞台大幕拉开的一瞬。静置时收敛、克制、优雅。 |
| **降解石** | 一尊风化的老者头像石雕，面部细节已被磨平大半，只余轮廓与紧抿的嘴角。石质枯白如盐碱地，表面持续剥落极细的金色尘屑（逸尘的视觉源头），落地即消。越"旧"光越沉，像在缓慢赢得什么。 |
| **海克石** | 标准八面体，切割精度非天然可及，明显是人工产物。内部悬浮一枚微型齿轮组结构，恒速自转；通体透出冷蓝色辉光，光沿棱线流动如电流走线。充能/增幅时蓝光大盛，是九石中唯一"亮得像灯"的。 |
| **金刚石** | 致密多晶簇，大小晶面拥挤堆叠，每一面都极硬、极亮。受光即炸开刺目的全彩火彩，晃得人睁不开眼；自身无色，却把一切光加倍奉还（呼应镜晶境强光反射）。 |
| **大理石** | 不规则巨岩块，沉重感九石第一。岩体深灰近黑，表面深红纹理蜿蜒如铁锈渗入裂缝，纹理随持有者生命起伏微微明灭，像岩石里封着未冷的血。无光自华，压迫感来自体量与质地。 |
| **陶玉石** | 饱满圆润的一颗羊脂白玉，无任何棱角，白色中带一点体温般的暖。光进入石内不散射，而是温润地在内部缓慢流转，多段细光首尾相衔（呼应"传导"）。触之如肌肤，九石中唯一让人想握在手心的。 |

## 三、联动网：关键词不是孤岛

每个关键词至少被**两颗石头**共享，形成天然的"双石构筑"接口：

```
增益 ── 阴阳石 ═══ 科目石 ── 献祭 ══ 降解石
循环 ── 阴阳石 ═══ 卡厄石              ║
随机 ── 卡厄石 ═══ 戏命石             装备 ══ 海克石
灼烧 ── 大理石 ═══ 戏命石(火伤脉络)    ║
多段 ── 陶玉石 ═══ 戏命石(计次频率)   生成(能量造物)
防御 ── 金刚石 ═══ 大理石(生命向)     能量/进化(海克独有轴)
传导 ── 陶玉石 ═══ 阴阳石(增减益扩散)
经济 ── 金刚石 ═══ 降解石(变卖装备)
召唤 ── 科目石(祭品供应链，献祭上游)
```

- **双石共鸣**：一颗石头入饰品格定流派后，第二颗石头（卡牌注入/事件/Boss）与之共享关键词时产生**共鸣加成**——共鸣是选域与选卡的构筑结果，自动触发，不单设决策点
- 示例共鸣对：
  - 阴阳×科目（增益网）：献祭获得的增益额外+25%
  - 降解×海克（装备网）：降解装备时额外返还进化能量
  - 大理石×戏命（杀戮网）：灼烧目标被处决时引爆剩余dot

## 四、系统覆盖校验（无遗漏）

| 游戏系统 | 认领石头 |
|---------|---------|
| 普攻/暴击输出 | 戏命石 |
| 技能/变异输出 | 卡厄石 |
| 持续dot | 大理石（灼烧）、陶玉石（传导扩散） |
| 多段/攻速 | 陶玉石（多段） |
| 防御/承伤 | 金刚石、大理石（生命） |
| 能量运转（命潮/蓄能） | 海克石 |
| 增益/减益 | 阴阳石、科目石 |
| 成长/滚雪球 | 科目石、海克石（进化） |
| 装备互动 | 降解石（负向拆解）、海克石（正向造装） |
| 经济（纽币） | 金刚石、降解石（变卖装备） |
| 随机/骰子 | 卡厄石 |
| 回复/循环 | 阴阳石 |
| 生成（能量造物） | 海克石 |
| 召唤（献祭上游） | 科目石 |

**状态词×石头归属**：灼烧+重伤→大理石/戏命（火）；中毒→降解（剧毒）；冰冻→阴阳（霜冻）；金身→金刚（金刚不坏）；再生→陶玉（温润）；增伤→科目/大理石（力量）；虚弱/易伤/迟缓/禁足=通用减益，各石头分支皆可调用。

## 五、辐射挂点（下游系统怎么接）

| 下游系统 | 接法 |
|---------|------|
| **流派（饰品格）** | 石头入饰品格→携带者获得流派被动，九流派语言=本表机制方向（职业与装备.md §五） |
| **卡牌注入** | 三级分支卡的源流附魔沿用九源流；源流与石头的对应：嗜血→科目、壁垒→金刚、灼烧→大理石、剧毒→降解、连锁→陶玉、疾风→陶玉（语义=多段/攻速）、狙击→戏命、混沌→卡厄、霜冻→阴阳（海克无源流——它管能量与装备，不走伤害词） |
| **九域主题** | 每域统治者/地皮/事件围绕该域石头的3关键词设计（冒险系统.md §2.2） |
| **装备** | 六散件与石头无强制绑定；海克/降解两石提供装备互动玩法 |
| **Boss** | Boss机制=该域石头关键词的敌方镜像（如科目石Boss=献祭小怪滚雪球，敌人设计.md §3.3） |
