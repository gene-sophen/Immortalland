# 《三乂川》源神石体系 v0.6

> 九颗源神石具有固定的名称、颜色、材质、形态与美术人设，并由公共卡池定义各自的战斗语言与构筑方向。

## 一、九石体系

| 源神石 | 核心战斗语言 | 体系说明 |
|--------|--------------|----------|
| 阴阳石 | 转换与时序 | 攻防互换、延时收益、双状态联动、牌组归一与时间借贷 |
| 科目石 | 累计与进阶 | 同名成长、永久成长、分类计数、长期能力与预先编排 |
| 卡厄石 | 异变与代价 | 多状态、污染、形态变化、条件反转与不稳定收益 |
| 戏命石 | 决断与虚无 | 虚无高质牌、精确打断、空牌堆终结、限时爆发与主动/弃置抉择 |
| 降解石 | 毒蚀与净化 | 毒伤、减速、负面状态、资源回收与污染处理 |
| 海克石 | 命潮与机造 | 自然回能、制式卡、自动运转、生成牌、铸造与效率检验 |
| 金刚石 | 护盾与固守 | 护盾生成、护盾转伤、护盾保留、反制敌盾与稳定能力 |
| 大理石 | 血火与力量 | 生命代价、损血计数、力量成长、火伤与火伤终端 |
| 陶玉石 | 流转与连段 | 轻盈、多段、抽牌触发、连续出牌、恢复与状态传导 |

每颗源神石集中表达一个主体系，但不形成封闭职业。跨石接口让玩家通过选牌构成混合构筑。

## 四、体系闭环

- **大理石血火**：生命代价产生损血计数与力量，火伤由熔火拳提前结算；治疗和护盾需要借用其他石头完成代价回收。
- **降解石毒蚀**：毒伤启动、堆层、额外结算与抽牌联动集中于一石，同时拥有净化接口，形成施加侵蚀与处理侵蚀的双面语言。
- **金刚石护盾**：生成、保留、转伤和反制敌盾齐全；稳定生存时间可交给毒火等慢速体系使用。
- **海克石机造**：命潮恢复、生成物、铸造、自动出牌和回能质量转伤共同构成机械运转链。
- **陶玉石流转**：多段、轻盈、抽牌动作与连续出牌集中，向鼓舞持续和火伤转脆弱提供传导桥梁。
- **戏命石决断**：虚无覆盖输出、生存、增伤和运转；开场、收尾、打断与限时免费窗口强化时机判断。
- **阴阳石转换**：伤害转护盾、护盾转治疗、敌方易伤转我方鼓舞，并处理时间与牌组循环。
- **科目石进阶**：同名、永久攻防成长、分类计数和秩序化抽牌构成长线累积。
- **卡厄石异变**：污染、多状态、消耗和反转收益制造高波动资源，再与降解净化和海克过载相连。

## 五、跨石关系

- 大理石火伤可由陶玉石流火痕转为脆弱，接入直接攻击。
- 卡厄石制造的污染由降解石净化并转为燃料。
- 海克石提供命潮和生成物，供陶玉石高频出牌、科目石累计成长。
- 金刚石争取的生存时间可交给降解石毒杀或大理石火杀终结。
- 阴阳石承担资源之间的转换桥，戏命石承担爆发时机，二者共同连接慢速积累与终端输出。

毒伤与火伤本体不吃力量、激昂、鼓舞、易伤或脆弱，只通过卡面明确写出的催毒质、熔火拳、流火痕等专属接口与其他体系连接。

## 六、下游接口

- **公共卡池**：九石各拥有九类各1张三级卡。
- **伙伴**：九名伙伴与九石一一对应；技能、绝技和职能使用对应石头的战斗语言。
- **九域**：领域名称、源神石归属、视觉设定与统治者保持一致；领域不附加独立战斗效果。
- **敌人**：Boss及普通敌人的行动池使用对应源神石语言，并遵守统一状态与控制规则。
- **装备**：源神石占用饰品格并表达流派方向；装备效果不得使用空间站位规则。
