# 《三乂川》音频设计

> 音频服务于“择、川、石、尘”四个母题，并与统一模拟时钟、倍速、子弹时间和顿帧同步。本文不定义伤害、状态或敌方行动数值。

## 一、声音总纲

**一句话定义：水负责时间，石负责重量，人声负责选择，尘负责记忆。**

- **川**：水滴、潮声、低频流动构成持续时间感；命潮、敌方行动与加时都从同一“流”中变化。
- **石**：磬、石击、瓷裂、金属矿鸣承担命中和状态确认；不同石性改变材质，不改变功能声音的可读性。
- **择**：三选一使用三次由散到定的短音，最终确认是一声干净钤印；随机骰子与玩家定夺必须听起来不同。
- **尘**：高频风铃碎响、逆向尾音和渐弱呼吸用于死亡、结算、命纹与剧情记忆。

音乐不追求“古风乐器大全”。每个领域限定2件主音色、1件节奏材质和1种环境声，避免同曲堆满笛、筝、鼓、二胡、钟磬。

## 二、自适应音乐结构

每首战斗曲拆为可无缝循环的五层：

| 层 | 进入条件 | 音乐职责 |
|----|----------|----------|
| 环境层 | 进入场景 | 域的空间与气候，无明确节拍 |
| 基础层 | 战斗开始 | 低密度脉冲，保持出牌思考空间 |
| 压力层 | 敌方高危意图、我方低生命 | 增加节奏或不协和，不直接提高总响度 |
| 30秒层 | 诅咒风暴启动 | 潮声加速、加入共同敌我的风纹节拍 |
| 60秒层 | 灾蚀风暴启动 | 毒金颗粒、火裂噪声和更快潮脉冲；旋律不再完整收束 |

- 层间切换在小节边界交叉淡化，紧急打断/碎石等系统声不等待音乐边界。
- 0.5×/2×不改变音乐整体播放速度，以免音高失真；只让战斗节拍层切换到对应密度变体。子弹时间降低高频与节奏层音量，保留环境和意图警示。
- 系统暂停在100ms内平滑降到环境底噪；恢复时先恢复警示声，再恢复音乐。
- 顿帧期间音乐作60—180ms的瞬时抽空或低通，不直接冻结音频文件；绝技顿帧可以使用预制停顿点。

## 三、九域音乐语言

| 领域 | 主音色 | 节奏/环境 | 情绪与禁区 |
|------|--------|-----------|------------|
| 镜晶境 | 玻璃磬、泛音琴 | 晶面摩擦与远风 | 清晰、挑剔；禁用梦幻仙境式大混响 |
| 荒脊岭 | 大石鼓、低音弦 | 脚步、骨火爆裂 | 沉重、诚实；不做野蛮部落刻板鼓点 |
| 火尽山 | 板鼓、低男声哼腔 | 幕布摩擦、火星 | 舞台与终幕；不直接套用完整戏曲唱段 |
| 皮安城 | 金属木鱼、机械簧片 | 恒速齿轮、管道气流 | 精确、低温；禁用霓虹电子舞曲 |
| 松三原 | 陶埙、弹拨短音 | 石粒滚动、松风 | 暖、丰饶、略荒诞；不做纯田园治愈 |
| 过明氹 | 极弱女声气音、单音磬 | 空旷耳鸣、水面无波 | 净与抹除；保留大量静默 |
| 啼亡堆 | 木尺击案、低弦 | 翻页、悬链、远哭 | 规训与疲惫；哭声只能作环境远层 |
| 潮王原 | 人声碎片、滑音弦 | 反向潮声、变速口技 | 好奇、变形；语音碎片不得形成可误读台词 |
| 平安京 | 昼侧短笛、夜侧拨弦 | 灯笼风、刀鞘摩擦 | 同一主题昼夜配器互换，不写两首无关曲 |

领域选择页播放8—12秒“域签”：主音色一句、环境声一句、域主主题半句。玩家不看文字也能预感领域气质。

## 四、角色与Boss主题

- 九伙伴各有一个不超过2秒的**石纹动机**，用于加入、技能牌和绝技；技能使用简版，绝技补全后半句。
- 伙伴动机优先继承个人经历：乐芙兰是链字与木尺节奏，芙宁娜是潮脉冲与机关簧片，纳西妲是尘落后生芽的高低双音；不只按石色换音效。
- 域主主题从领域主题中“夺走”一个音：Boss开幕时该音色独奏，阶段转换再把完整领域配器纳入，表现域主把环境变成自己的工具。
- 川灵没有完整旋律，只有三音下行水声；碎石后依次失去泛音。绝境石形成后川灵动机停止，改由主角第一次补完第四个音。
- 48兵使用四十八人不可能逐一辨认的低声呼吸阵列。第一至第五重不出现可听清人声；第六重后，胜利静场中才允许一条遗言靠近前景。

## 五、战斗音效语义

| 事件 | 核心声音 | 识别纪律 |
|------|----------|----------|
| 普通直接伤害 | 短梆+受击材质 | 多段每段音高微升，末段收束 |
| 重击 | 低石击+短暂抽空 | 不能只靠更大音量；用更低频和更长尾音 |
| 护盾获得 | 瓷片拼合 | 与治疗的水/芽声完全不同 |
| 护盾破碎 | 瓷裂向外散 | 不使用玻璃尖锐高频伤耳 |
| 治疗 | 水滴落入血条+芽音 | 满血溢出转盾时追加瓷片声 |
| 毒伤 | 盐粒剥落+低蚀声 | 穿盾时不播放护盾受击声 |
| 火伤 | 短火舌+墨烟 | 层数减半时尾音快速缩短 |
| 虚弱/减速 | 音高下沉、节拍拉宽 | 只影响目标行动语言，不让全曲变慢 |
| 打断成功 | 弦断+意图刻度碎裂 | 失败只用低沉晃动声，绝不共用弦断 |
| 命潮获得 | 水滴入位 | 自然充能、卡牌直接获得使用不同入水方向 |
| 负面牌入组 | 湿墨落纸 | 一次性、循环、处理型分别有短/回环/倒计时尾音 |
| 同时死亡胜利 | 敌方尘解后钤“险胜” | 不播放我方战败低音或碎石声 |

同一tick音效优先级：结果判定/危险警示 > 打断与碎石 > 绝技与重击 > 普通命中 > 粒子装饰。超出同时发声预算时合并低优先级声音，不延迟到下一tick补播。

## 六、UI与局外声音

- 三择浏览：每移到一项是一粒不同方位的轻磬；确认后前三音汇成一声钤印。
- 商店：购买是钱币落木盘；删卡是纸纤维断裂；回收是器物离手后钱币回响。三者不能只共用按钮点击声。
- 营地：挖掘=土石、锤子=三次轻敲后一次定音、温存=火堆与伙伴呼吸，不强加煽情旋律。
- 命纹树：叶节点是单粒尘音，汇流是双音合并，归根是低频水声向上；补点旧叶不重复播放归根演出。
- 图鉴：翻页保持干燥纸声；条件支链解锁用书签落下，区别于命纹消费。
- 骰子：滚动声不提前泄露结果；落定后再按凡/珍/天追加木、石、磬三档尾音。
- 高危长按：印泥摩擦随进度增加，松手取消立即收尾；完成时一声干净重印。

## 七、混音、无障碍与性能

- 提供总音量、音乐、效果、语音、环境五路独立滑杆及一键静音。
- “强化战斗提示”选项提高意图、满潮、打断、碎石与60秒风暴的相对响度，不提高伤害音效。
- 动态范围提供夜间/标准/宽广三档；夜间模式压低重击和Boss低频峰值但保留警示清晰度。
- 重要提示同时拥有视觉和震动冗余，听障玩家不依赖声音完成战斗；关键语音提供字幕与说话者标记。
- 移动端同时活跃音源建议不超过24个；高频多段合并为节奏组，环境循环使用短交叉淡化避免爆音。
- 所有语音、音乐和长环境声使用流式加载；核心警示和UI声常驻内存。

## 八、交付与命名

| 资产 | 格式建议 | 命名示例 |
|------|----------|----------|
| 音乐分层 | 48kHz/24bit WAV母版，运行时压缩 | `music_domain_mirror_base_loop_v01` |
| 角色动机 | 单声道或窄立体声WAV | `motif_partner_zarya_ultimate_v01` |
| 战斗SFX | 短WAV，多变体随机 | `sfx_combat_shield_break_03` |
| UI SFX | 短WAV | `sfx_ui_choice_confirm_seal_01` |
| 环境循环 | 无缝立体声 | `amb_domain_mingdang_whitepool_loop` |
| 语音 | 48kHz/24bit干声+字幕ID | `vo_zarya_camp_warm_02` |

每个循环文件必须标记BPM、小节长度、循环点和可叠加层；每个战斗音效至少提供3个轻微变体，避免高频出牌听感机械重复。音效与顿帧触发误差目标不超过30ms。
