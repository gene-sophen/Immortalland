# 《三乂川》局外成长系统 v0.6

> 局外三大件：**逸尘经济 → 命纹树加点 → 九重轮回难度**，辅以图鉴树与成就解锁。
> 核心循环：Boss胜利得源神石 → 结算转化为逸尘 → 命纹树加点 → 更强的下一局 → 更高重轮回。

---

## 一、逸尘：产出与定位

### 1.1 产出规则

- **每次Boss战胜利获得该域源神石×1**（局内同时是饰品格流派件，见职业与装备.md §五）
- **结算转化**：本局获得的**所有源神石（无论是否装备）在结算时统一转化为逸尘**——未通关也有部分收益（赢几个Boss拿几颗）
- **转化基准**：1颗源神石 = 10逸尘；轮回重数提供倍率（见§三）
- 设计张力：源神石局内装上=即时战力，但结算统一转化——**"这一颗是戴在身上打下去，还是想着它能变成逸尘"**是隐形的心理账户

### 1.2 逸尘消耗

唯一消耗口：**命纹树加点**。不设第二种局外货币，保持轻量化。

## 二、命纹树：三枝加点

树状结构，**三条主枝**（呼应三乂），节点逐层解锁（前置点满才能点后置）：

| 主枝 | 内容 | 节点示例 |
|------|------|---------|
| **角色枝** | 解锁主角身份与新伙伴入池 | 身份：贾克斯/崔斯特/咪哈呦/葛朗台；伙伴：初始伙伴×N → 逐域主题伙伴 |
| **强运枝** | 局内增强 | 初始纽币/共享生命/开局卡牌升级/商店首刷免费/营地多删1张/初始卡组加入一级整备 |
| **秘藏枝** | 解锁新卡牌与饰品入池 | 三级分支卡批次/特殊饰品（多兰盾式）/奇遇事件池扩充 |

### 2.1 树形纪律

- 每枝 **9个节点**（三三见九）：3层×3节点；全树**27节点**
- 成本递增：同枝内每层成本×3（10→30→90逸尘）——一盘全胜约90逸尘+倍率，约1-2盘点一个深层节点
- 强运枝数值走小步快跑（+5%档），不做"点满强度翻倍"的付费墙式设计
- **强运枝边界：不动命源石数量**（命源石恒3颗）——命是稀缺底线，增强只走经济/卡牌/商店轴

### 2.2 角色解锁规则

- **主角九身份**：初始开放**阿泰克/蒂范德/拜冷斯**（攻/防/平衡三个基础身份）；**角色枝解锁**贾克斯/崔斯特/咪哈呦/葛朗台；**成就解锁**普朗克/艾德明
- **伙伴**：部分走角色枝逸尘解锁，部分走成就解锁（见2.4）——**逸尘买"量变"，成就给"质变"**

### 2.3 图鉴树：局外第二棵树

> 局外双树并行：**命纹树=主动加点（花逸尘买成长）**，**图鉴树=被动收集（游玩解锁图鉴→领逸尘）**。一个花钱一个生钱，形成循环

- **五大图鉴类目**：卡牌 / 装备 / 伙伴 / 源神石 / 敌人
- **解锁规则**：局内首次遇见/获得/击败即点亮对应图鉴（见所未见即解锁）
- **奖励**：每点亮1个新图鉴 = 逸尘奖励；类目收集度里程碑（25%/50%/75%/100%）给额外奖励（逸尘/秘藏枝内容/称号）
- **呈现**：图鉴树按类目分五冠，点亮进度可视化；与命纹树同界面双页签
- 原则：图鉴树不消耗任何资源，纯奖励"见得广"——鼓励多尝试不同构筑与路线

### 2.4 成就解锁（第三轨）

**特殊内容不走逸尘，走成就**——局内达成特殊条件直接解锁：

| 成就示例 | 解锁 |
|------------|------|
| 不碎任何命源石通关一重轮回 | 主角·艾德明（盲盒） |
| 单局骰子传说档触发3次并通关 | 主角·普朗克 |
| 单局献祭/牺牲2名伙伴并通关 | 伙伴·（牺牲主题角色） |
| 单局集齐3颗不同源神石装备中通关 | 特殊饰品入池 |
| 连败3次后反杀Boss | 三级分支卡·破石主题 |
| 九重轮回通关 | 剧情结局+隐藏主角皮肤/称号 |

- 原则：**逸尘买"量变"，成就给"质变"**——新角色新伙伴尽量挂成就，让玩家为目标而玩

## 三、九重轮回：难度结构

- 通关一次九域长征 = 完成一重轮回，解锁下一重
- **每重轮回叠加难度修正**（乘区独立、数值走25%档）
- **设计纪律：不修命源石恢复**——恢复手段全重保持一致；**卖血（破石之力）是全难度层都保留的博弈点**

| 轮回 | 修正 |
|------|-----------|
| 一重 | 基准 |
| 二重 | 敌方生命+25% |
| 三重 | 精英节点增多；商店价格+15% |
| 四重 | 敌方攻击提高；开局附带1张负面状态牌 |
| 五重 | 敌方行动进度加快 |
| 六重 | Boss行动池强化；精英额外获得机制词条 |
| 七重 | 敌方双词条强化；命潮自然恢复降低 |
| 八重 | 负面状态牌密度提高；敌方行动池压力升级 |
| 九重 | 最终轮回：全修正叠加+最终Boss战→**胜利解锁剧情结局，主线完成** |

- **逸尘倍率**：第N重轮回结算逸尘×(1+0.25N)——打高难度=更快的树成长，自平衡
- 九重通关后：自由轮回（自选难度修正组合）/挑战词条，进入endgame

## 四、与其他系统的挂点

- **战斗**：Boss胜利=源神石=逸尘源头（冒险系统.md §4.3）
- **装备**：源神石一局两用（局内流派/局外货币），饰品格规则不变
- **卡牌**：秘藏枝解锁的三级分支卡进入9类×9张公共池
- **伙伴**：角色枝+成就双轨解锁；技能与绝技统一使用伙伴.md规定的共享生命与蓄势X接口
- **剧情**：九重轮回=主线叙事框架（"主角在轮回中收集九石之力"），每重通关解锁一段剧情
