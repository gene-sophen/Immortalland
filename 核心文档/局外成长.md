# 《三乂川》局外成长系统

> 局外成长由彩灿尘、倒生命纹树、链式图鉴、成就轨与九重轮回组成。九名伙伴默认开放；永久解锁只作用于主角身份、扩展内容池与收藏信息。

## 一、轮回结算

- 只有战胜48兵才算完整通关；结算按推进、精英/Boss胜利与轮回重数发放彩灿尘。
- 卡牌、纽币、冒险等级、命源石损伤和局内标记在轮回结束时清空。
- 完整通关时，从仍持有的常规饰品中选择1件继承；下一轮回第一次挖掘时作为必定候选取得。
- 特殊、已售出、已丢弃、已放弃及结算时未持有饰品不能继承。

## 二、倒生命纹树

命纹树有角色、强运、秘藏三枝，每枝均采用6个外冠入口→2个汇流节点→1个归根节点的倒生结构，共27节点。

| 主枝 | 职责 |
|------|------|
| 角色枝 | 解锁贾克斯、崔斯特、咪哈呦及身份事件；不解锁伙伴 |
| 强运枝 | 提高初始纽币、共享生命、卡牌/饰品权重、挖掘与营地收益；不修复命源石 |
| 秘藏枝 | 把扩展三级分支、限定来源饰品与稀有事件加入对应内容池 |

- 玩家初次进入即可查看并购买三枝全部18个外冠节点。
- 每个汇流节点关联3个外冠，点亮其中任意2个后开放；归根要求本枝2个汇流均点亮。
- 命纹树消费彩灿尘，不提供局内直接升卡、删卡、锤子、商店刷新、饰品升级或伙伴解锁。
- 完整节点职责、叙事与界面见 `命纹树与图鉴.md`。

## 三、图鉴与成就

- 图鉴分卡牌、饰品、伙伴、源神石、敌人、事件六卷。
- 每卷按初见→识形→知用→成类→尽录线性推进，跨类关系使用不阻塞主链的条件支链。
- 图鉴奖励自动领取，不消耗彩灿尘；支链主要提供轶闻、来源、筛选与收藏内容。
- 六卷尽录解锁隐藏文本《第十块碑》；失败叙事《尘归录》为独立附卷。
- 初始开放阿泰克、蒂范德、拜冷斯；贾克斯、崔斯特、咪哈呦由角色枝解锁。
- 葛朗台由通关持币成就解锁，普朗克由骰子通关成就解锁，艾德明由无命源石碎裂通关成就解锁。

## 四、局内冒险等级

- 冒险等级是单轮回共享成长，不是永久等级。
- 每3点经验提升1级；升级使本轮回共享生命上限+4并恢复4生命。
- 每3级获得纽币，每6级获得高级卡牌或饰品奖励，每9级提高后续高品质奖励权重。
- 等级、经验、生命增量和里程碑收益在轮回结束时清空，不改变九颗命源石。

## 五、九重轮回

进入更高轮回时保留此前全部难度规则并新增本重规则：

| 轮回 | 新增规则 |
|------|----------|
| 第一重 | 标准规则 |
| 第二重 | 怪物直接伤害、毒火层数和治疗量×1.12 |
| 第三重 | 每场开战生命为当前上限的90% |
| 第四重 | 初始牌组加入永恒+虚无诅咒“绊脚石” |
| 第五重 | 怪物生命、护盾和恢复×1.15 |
| 第六重 | 商店购物、刷新和删卡价格×1.20 |
| 第七重 | 初始牌组加入永恒诅咒“扫把星” |
| 第八重 | 共享生命上限最终×0.90；开战90%规则继续生效 |
| 第九重 | 48兵首次死亡后以50%最大生命复起，行动速度+20%、决行动伤害+15% |

- 每次战胜48兵解锁下一重并开放一段主线剧情。
- 第九重使用艾德明、保留管理员的钥匙、形成并保留绝境石且击败复起后的48兵，解锁圆满结局《定川》；未同时满足时完成《未竟》。
- 九重通关后开放自由轮回与挑战词条模式。
- 彩灿尘产出、命纹成本、图鉴阈值与身份成就条件见 `统一数值配置.md`。

## 六、九石生命

- 每场战斗按当前共享生命上限开始，局内生命与命源石完全分离。
- 第一、第二、第三领域的精英或Boss失败分别损伤1、2、3颗；普通探索战不损伤。
- 恰好碎尽9颗时形成绝境石并继续；累计超过9时轮回失败。
- 48兵失败直接结束，不通过剩余命源石继续。
