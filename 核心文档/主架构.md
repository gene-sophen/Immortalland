# 《三乂川》主架构 v0.7

> 本文件只维护全局概述与文档索引。现行基线为v0.7；具体数值统一留到数值策划阶段。

## 一、游戏定位

竖屏单手、轻量化实时策略肉鸽。玩家通过命潮打牌，在敌方行动进度条完成前进行输出、防御、治疗、增伤和打断；单局依次探索九个领域，并在最后挑战最终Boss“48兵”。

核心决策语言是“三选一”：当前3张手牌选1张、路径三选一、事件三选一、营地营务三选一、三级升级三选一和三级分支重选三选一。

## 二、核心术语

| 术语 | 定义 |
|------|------|
| 源神石 | 九种世界能量石，也是Boss可能掉落的流派饰品；定义三级卡体系、九域主题和伙伴/敌人机制语言 |
| 命潮 | 打牌费用，上限3点，随实时进度自然恢复 |
| 命源石 | 九颗局外生命石；只在九域Boss战败时碎裂，与单场共享生命分离 |
| 饰品 | 角色携带的局内被动构筑物；每名角色最多携带3件 |
| 逸尘 | 局外货币，用于命纹树等长期成长 |
| 整备 | 牌组运转类底卡；一级以0费消耗空打完成主动换组 |
| 蓄势3 | 伙伴绝技专属词条；满足专属条件累计3次后，绝技置顶并获得固有，使用后重新蓄势 |

## 三、系统地图

### 3.1 局内

| 子系统 | 概述 | 详设文档 |
|--------|------|----------|
| 战斗 | 主角与最多3名伙伴共享生命，对战单一敌方；无棋盘、站位和瞄准；0.1秒tick与可见敌方行动进度条 | 战斗.md |
| 卡牌 | 命潮上限3，抽三打一弃二；9类底卡、18张基础卡、81张三级卡、衍生牌与伙伴专属卡 | 卡牌系统.md / 公共卡池.md |
| 卡牌成长 | 获得同名新卡时选择入组或升级；营地锤子为普通三级卡重选分支；商店直接删卡 | 卡牌系统.md / 商店系统.md |
| 源神石 | 九石分别承担转换、进阶、异变、虚无、毒蚀、机造、护盾、血火、流转体系 | 源神石.md |
| 伙伴 | 九名伙伴与九石一一对应；每名伙伴携带专属饰品、技能牌和蓄势3绝技牌 | 伙伴.md |
| 饰品 | 每角色3个槽位；普通饰品、源神石、伙伴专属饰品与绝境石共用规则 | 饰品系统.md |
| 敌人 | 单一敌方血条，按行动池选择攻击、护盾、增幅等行为并公开进度 | 敌人设计.md |
| 冒险 | 九域各含3个探索节点和1场Boss；九域结束后挑战48兵 | 冒险系统.md |
| 商店营地 | 商店提供购物、删卡、回收；营地提供挖掘、锤子、温存三选一 | 商店系统.md |

## 四、v0.7系统边界

- 已定稿：1v1敌方、四人共享生命、每战满血、0.1秒tick、伤害与毒火规则、命潮与牌区、9类99张公共阶梯牌、九特殊词条、81张三级卡、六类节点、九石生命、饰品框架与伙伴框架。
- 卡牌没有降级和0级。普通卡只在获得同名新卡时升级；三级卡只通过营地锤子重新九随机三并三选一分支；商店删卡直接移除卡牌。
- 九域Boss战败扣石后直接进入下一域，不重试；48兵战败直接结束轮回。
- 数值后置：费用、伤害、治疗、护盾、持续时间、速率、比例、阈值、抗性、价格、概率和取整。
- 战斗不使用六边形棋盘、位置范围、多单位敌方阵容或角色独立血条；物品系统不使用散件、主副系成装或装备合成。
