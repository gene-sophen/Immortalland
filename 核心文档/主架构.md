# 《三乂川》主架构 v0.6

> 本文件只维护全局概述与文档索引。现行基线为v0.6；具体数值统一留到数值策划阶段。

## 一、游戏定位

竖屏单手、轻量化实时策略肉鸽。玩家通过命潮打牌，在敌方行动进度条完成前进行输出、防御、治疗、增伤和打断；单局沿九域长征推进，局外以命纹树与九重轮回支撑长线。

核心决策语言是“三选一”：当前3张手牌选1张、路径三选一、事件三选一、营务三选一、三级升级三选一和域间三选一。

## 二、核心术语

| 术语 | 定义 |
|------|------|
| 源神石 | 九种世界能量石，定义三级卡体系、九域美术主题和伙伴/敌人机制语言 |
| 命潮 | 打牌费用，上限3点，随实时进度自然恢复 |
| 命源石 | 主角局外生命实体，Boss战败碎裂；与单场共享生命分离 |
| 逸尘 | 局外货币，用于命纹树等长期成长 |
| 骰子 | 节点稀有度和事件随机性的统一入口：普通3面、稀有2面、传说1面 |
| 整备 | 牌组运转类底卡；一级以0费消耗空打完成主动换组 |
| 蓄势X | 伙伴绝技专属词条；条件充能，蓄满后绝技置顶并获得固有，使用后重新蓄势 |

## 四、v0.6系统边界

- 已定稿：1v1共享生命战斗、0.1秒tick、伤害与毒火规则、命潮与牌区、9类99张公共阶梯牌、九特殊词条、81张三级卡名称与九石归属。
- 数值后置：费用、伤害、治疗、护盾、持续时间、速率、比例、阈值、抗性数值和取整。
- 战斗不使用六边形棋盘、位置范围、多单位敌方阵容或伙伴独立血条；公共卡池固定为9底卡、81张三级卡。
