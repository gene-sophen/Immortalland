# 《三乂川》主架构 v0.8

> 本文件维护现行全局概述与文档索引。机制结构以v0.8为基线，具体强度、概率、价格与成长曲线统一由后续数值策划配置。

## 一、游戏定位

竖屏单手、轻量化实时策略肉鸽。玩家依靠上限3点的命潮打牌，在敌方行动进度完成前进行输出、防御、治疗、增伤、减速与打断；单轮回依次探索九个领域，最后挑战“48兵”。

核心交互语言是三选一：抽三打一弃二、三级升级三选一、域间三选一、伙伴三选一、事件三选一与营地营务三选一。

## 二、核心术语

| 术语 | 定义 |
|------|------|
| 源神石 | 固定三级的流派特殊饰品；九石共同定义三级卡体系、九域主题与伙伴/敌人语言 |
| 命潮 | 打牌费用，上限3点，随实时进度自然恢复 |
| 命源石 | 九颗局外生命石，只在九域Boss战败时碎裂，与单战共享生命分离 |
| 饰品 | 每件拥有固定等级的局内被动；主角与每名伙伴各有3个槽 |
| 冒险等级 | 单轮回全队共享等级；探索与温存提供经验，升级提高共享生命上限 |
| 逸尘 | 局外长期成长货币 |
| 蓄势3 | 主动使用同一伙伴技能牌3次后，其绝技置于抽牌堆顶并获得固有 |

## 五、系统边界

- 普通卡只有一级、二级、三级。外部奖励只直接产生一级或二级卡，三级唯一来源是同名升级。
- 伙伴没有等级、卡牌分支或饰品升品。温存只提供冒险经验。
- 饰品等级是固定强度档，不存在升级。身份、伙伴、源神石、绝境石是不可继承的特殊饰品。
- 商店不出售源神石与其他特殊饰品；源神石只来自对应Boss或明确事件。
- 非Boss战败只获得纽币；九域Boss失败取得纽币并碎石后继续；48兵失败直接结束。
- 战斗不使用六边形棋盘、多单位敌方、空间范围或角色独立血条；物品不使用装备散件、成装或合成。
- 费用、伤害、治疗、护盾、持续时间、速率、阈值、概率、价格、奖励量、经验表和取整规则进入数值策划。
