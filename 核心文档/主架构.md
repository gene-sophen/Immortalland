# 《三乂川》主架构

## 一、游戏定位

《三乂川》是竖屏单手、轻量实时策略肉鸽。玩家操纵一名主角和最多三名伙伴，共享局内生命；敌方为单一实体，通过公开行动意图和进度条自动行动。玩家使用上限3点的命潮打牌，在实时进度中完成输出、防御、恢复、增伤、减速、打断与牌组运转。

核心交互语言是“三选一”：抽三打一弃二、三级分支三选一、节点三选一、领域三选一、伙伴三选一、事件三选一及营地营务三选一。

## 二、单轮回主流程

```text
启程 → 选择轮回与主角身份
→ 九域随机展示3域并选择1域
→ 伙伴三选一
→ 4次节点探索 → 精英三选一
→ 4次节点探索 → 精英三选一
→ 4次节点探索 → 固定领域Boss
→ 再完成第二、第三领域
→ 48兵终战 → 轮回结算
```

- 每个领域16次冒险：伙伴选择1次、节点探索12次、精英2次、Boss1次。
- 三个领域合计48次冒险；48兵是其后的终战，不计入48次编号。
- 每次节点探索从战斗、商店、营地、事件、宝藏、随机六类中随机展示3种不同类型，玩家选择1种；不同探索之间允许重复。
- 九名伙伴随机分成3组，每域开场选择1人且全轮回不重复，第三领域形成主角+3伙伴的四人队。

## 三、核心术语

| 术语 | 定义 |
|------|------|
| 命潮 | 打牌费用，上限3点，按实时进度自然恢复 |
| 命源石 | 九颗局外生命石；第一、第二、第三领域的精英或Boss失败分别损伤1、2、3颗 |
| 共享生命 | 单场战斗中主角与伙伴共同使用的生命；每场按当前上限满血开始 |
| 饰品 | 固定品质的局内被动；主角与每名伙伴各有3槽 |
| 源神石 | UI为三级、实际高于常规三级的特殊饰品；九石定义九类流派质变 |
| 绝境石 | 九颗命源石恰好碎尽后形成的特殊饰品，提供高额伤害与回能 |
| 冒险等级 | 单轮回共享等级；经验每3点提升1级，升级提高共享生命上限 |
| 彩灿尘 | 局外永久成长货币，用于命纹树 |
| 蓄势3 | 主动使用同一伙伴技能牌3次后，其绝技置于抽牌堆顶并获得固有 |
| 潮律 | 九域公开的敌我共享环境规则；域主通过行动池更擅长利用 |
| 事印 | 事件产生的跨节点任务标记，不占卡牌或饰品槽，最多持有2枚 |

## 六、系统边界

- 普通卡只有一级、二级、三级；外部奖励只直接产生一级或二级卡，三级只能通过同名升级获得。
- 普通公共卡不使用永恒。伙伴牌、身份关联牌与明确诅咒可以使用永恒保护其不可永久删除。
- 伙伴没有等级、卡牌分支或饰品升品；温存只提供冒险经验。
- 饰品品质固定，不存在升级。源神石仍显示为三级，但用独有源纹表示命定级强度。
- 商店不出售源神石和其他特殊饰品；特殊饰品均有唯一获取路径。
- 普通探索战失败只获得纽币，不损伤命源石；精英和领域Boss失败结算碎石后继续；48兵失败直接结束轮回。
- 战斗不使用六边形棋盘、多单位敌方、空间范围、角色独立血条、装备散件或装备合成。
- 敌人、经济与成长使用统一数值配置；核心机制文档只规定公式、触发、结算顺序和内容职责。
