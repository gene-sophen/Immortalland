## 一、游戏定位

竖屏单手 · 轻量化休闲策略肉鸽 · 云顶式自动战斗 × 皇室式命潮打牌 × 公主连结式绝技时机。
**单局25-30分钟**，九域长征全体验；局外双树+九重轮回支撑长线。
核心决策语言：**三选一**（打牌/路径/事件/营务/升级/选域；双石共鸣为选域与选卡的构筑结果，自动触发，不单设决策点），数值崇拜三六九。

## 二、核心术语

| 术语 | 定义 |
|------|------|
| **源神石** | 九种世界能量石，体系上游枝干：定流派、定域主题、定Boss镜像、结算转化逸尘 |
| **命潮** | 打牌费用（上限3/起始2/1点每3秒三幕加速），涨落汇聚如潮 |
| **命源石** | 主角生命实体（3颗），Boss战败碎1颗；碎石转化为破石之力（连败增益）；碎至第3颗进入背水状态，再输终结 |
| **逸尘** | 局外货币（源神石逃逸的尘土），Boss胜→石头→结算转化，命纹树唯一消耗 |
| **骰子** | 随机总闸：3/6普通、2/6稀有、1/6传说；节点稀有度/品质浮动/事件结果 |
| **整备** | 手牌调度卡（1费回1命潮·消耗·每场限1次），打出即弃2补3=换组效果；命纹树天赋解锁入初始卡组 |

## 三、系统地图

### 局内

| 子系统 | 一句话概述 | 详设文档 |
|--------|-----------|---------|
| **战斗** | 2-3-2-3-2十二格棋盘自动战斗（0.1s tick），玩家布阵+打牌干预；子弹时间拖拽、三幕加速、加时风暴防拖局 | 战斗.md |
| **卡牌** | 六分类（攻击/buff/debuff/战术/技能/诅咒）；抽三打一弃二；公共池12底卡三级阶梯（每底卡9分支）；卡组目标12-18（常规获得制无硬上限） | 卡牌系统.md |
| **装备** | 六散件→主系+副系合成36种二级成装（附加效果词条）；饰品格放源神石定流派 | 职业与装备.md |
| **冒险** | 九域长征：每域3节点（六类×三档稀有度，骰子3/2/1面）+Boss；域间三选一；每域一个特色机制；首局第一域为教学域 | 冒险系统.md |
| **命源石经济** | Boss碎1颗/碎至3颗进背水、再输终结；破石之力三档连败增益；非Boss战败低档参与结算；营地或Boss胜恢复 | 冒险系统.md §四 |
| **商店营地** | 单一综合店（货架+删卡+刷新+回购+命源石修复仅传说档）；营地营务三选一（休整/淬火/割舍+稀有度档位营务） | 商店系统.md |
| **敌人** | 与玩家同构：2-4单位自动普攻+行为卡组循环+蓄能绝技（精英起，进度可见）；杂兵模板/精英词条/九Boss石头镜像两阶段 | 敌人设计.md |
