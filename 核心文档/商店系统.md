# 《三乂川》商店与营地系统 v0.7

> 商店提供购物、删卡、回收；营地提供挖掘、锤子、温存三选一。两类节点分工固定，不互相代办功能。

## 一、商店

| 功能 | 规则 |
|------|------|
| 购物 | 固定展示2张随机卡和1件饰品，分别标价；购买卡牌时立即进入“直接入组/同名升级”选择 |
| 删卡 | 支付纽币，选择1张可删除的普通卡，使其直接从牌组消失；伙伴专属卡不能删除 |
| 回收 | 选择1件已持有饰品出售并获得纽币；商店品质越高，回收价格越高 |

- 商店品质分普通、稀有、传说；品质越高，出现高稀有度卡牌和高品质饰品的概率越高。
- 商店不提供锤子、直接升级、付费刷新、命源石修复或装备交易。
- 回收只处理饰品；其他场景获得超额饰品时，只能放弃新品或替换并丢弃旧饰品。
- 卡牌、饰品、删卡和回收的价格属于数值策划内容。

## 二、购买卡牌

获得商店中的普通卡后，立即选择：

```text
购买新卡
├─ 直接加入：新卡作为独立牌进入牌组
└─ 同名升级：消耗新卡 → 选择1张同名非满级卡 → 该卡升1级
```

- 牌组内既有卡不能互相合成。
- 二级升三级时，从该类别9张三级分支中随机展示3张并三选一。
- 三级卡已经满级；购买同名新卡时只能直接加入。
- 系统不存在卡牌降级和0级卡。

## 三、营地

每次进入营地，从以下3项营务中选择1项执行：

| 营务 | 规则 |
|------|------|
| 挖掘 | 获得1件随机饰品或一笔纽币；若保存了上个轮回的继承饰品，本轮回第一次挖掘必定取得该饰品 |
| 锤子 | 选择1张普通三级卡，从该类别9张三级分支中重新随机展示3张，三选一替换当前分支；卡牌等级不变 |
| 温存 | 选择1名伙伴提升伙伴等级，并结算该等级对应的共享生命、专属饰品品质和专属卡分支成长 |

- 锤子不能作用于一级卡、二级卡、伙伴技能牌或伙伴绝技牌。
- 营地不直接升级或删除普通卡，也不恢复命源石。
- 继承饰品取回后遵守正常饰品槽位与替换规则。

## 四、功能分工

| 需求 | 系统入口 |
|------|----------|
| 购买卡牌或饰品 | 商店·购物 |
| 精简普通牌组 | 商店·删卡 |
| 出售饰品 | 商店·回收 |
| 获取随机饰品或纽币 | 营地·挖掘 |
| 重选普通三级卡分支 | 营地·锤子 |
| 提升伙伴等级 | 营地·温存 |
