# 《三乂川》商店与营地系统

> 商店负责购物、删卡、回收；营地负责挖掘、锤子、温存。两类节点互不代办。

## 一、商店

| 功能 | 规则 |
|------|------|
| 购物 | 初始展示2张一级/二级普通卡与1件常规饰品，分别标价；源神石与其他特殊饰品不出售 |
| 删卡 | 支付纽币，删除1张可删除普通卡；伙伴牌、负面牌与身份关联牌按各自保护规则处理 |
| 回收 | 出售1件当前持有饰品并取得纽币；特殊饰品允许出售，但同轮回不能再次获得 |
| 刷新 | 支付纽币刷新购物区的2张卡与1件饰品；删卡与回收次数不刷新 |

- 商店分普通、稀有、传说三档。品质越高，高等级常规饰品和二级卡的权重越高。
- 商店品质决定本节点可用的删卡与回收次数上限，并共同影响购物、删卡与回收价格档位。
- 商店不提供源神石、三级卡、直接升级、锤子或命源石修复。
- 通售饰品进入常规货池，商售饰品只在商店出现；掘藏、战利、域产饰品不进入普通货位。
- 不竭货箱使购买后的货位补充同类商品；折扣效果按饰品卡面叠加规则结算。
- 一级卡、二级卡和一至三级饰品基础价格分别为38、72、95、175、320纽币；领域、商店品质、删卡累计、刷新累计与第六重倍率见 `统一数值配置.md`。

## 二、购买卡牌

取得商店中的普通卡时立即选择：

```text
直接加入：新卡作为独立牌永久加入牌组
同名升级：消耗新卡 → 选择1张同名非满级卡 → 该卡升1级
```

- 牌组内既有同名卡不能互相合成。
- 一级升二级直接替换；二级升三级时从该类别9个三级分支中随机展示3个并三选一。
- 三级卡只能由同名升级产生；三级同名新卡不存在于商店货池。

## 三、回收边界

- 回收是唯一可以出售饰品的入口；其他场景超出槽位时只能放弃或替换丢弃。
- 身份、伙伴、源神石、绝境石售出后，本轮回均不能再次获得。
- 售出饰品不回滚已结算的一次性收益；持续被动停止。售出多兰饰品时移除对应关联牌。
- 失效蜥蜴断尾可以售出，以后取得的新副本拥有新的保命次数。

## 四、营地

未装备三务帐篷时，从以下3项中选择1项：

| 营务 | 规则 |
|------|------|
| 挖掘 | 取得随机常规饰品或纽币；若存在继承饰品，本轮回第一次挖掘优先取得该饰品 |
| 锤子 | 选择1张普通卡；一级/二级从同等级其他类别中随机展示3类并横向变化，三级从所属类别9个分支中随机展示3个并重选 |
| 温存 | 为本轮回的共享冒险等级提供大量经验；升级时提高共享生命上限 |

- 锤子不排除当前分支，也不保证出现新分支；选择当前分支仍消耗本次营务。
- 锤子不能作用于伙伴牌、身份关联牌、负面牌或永恒牌；没有合法目标时不可选择。
- 营地不直接升级或删除普通卡，也不恢复命源石。
- 装备三级常规饰品三务帐篷时，三项营务各执行1次，顺序由玩家决定；没有合法目标者可以跳过。继承饰品在挖掘实际执行时取得，与执行顺序无关。
- 挖掘的等级分段、饰品品质概率与纯纽币结果见 `统一数值配置.md`。
