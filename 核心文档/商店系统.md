# 《三乂川》商店与营地系统 v0.6

> **商店只有一个（综合货架）**；运营压力转移到**营地**（不止休息，还有锻造/挖宝/割肉等事件化操作）。
> 本文定义商店与营地的交易规则；货架价格、刷新费、基础回购比率与营务出现率不属于本文件的规则范围。

---

## 一、商店（单一综合店）

| 项目 | 说明 |
|------|------|
| **综合货架** | 3格混排（稀有节点6格、传说节点9格——货架三六九，见冒险系统.md §2.1）：卡牌（一/二级，本域主题加权）、散件/成装、补给品（单场增益）、偶尔特殊饰品——一格一货，售出即空 |
| **删卡** | 移除1张卡（含诅咒）；每店限1次 |
| **刷新** | 花纽币重刷货架 |
| **回购** | 卖出多余散件/成装换纽币，基础回购价低于买入价；**物品升值**：买入的物品在后续商店售出时升值（每跨越1个商店+25%档）——买低放久卖高 |
| **路过奖励** | 进店未消费离店 +5纽币（小额安慰金） |
| **命源石修复** | 高价限购1颗，**仅传说档商店开放**（与营地免费恢复形成双轨，冒险系统.md §2.1） |

- 升级卡牌**不在商店**——移交营地（见下）
- 货架内容随投放权重曲线升档（冒险系统.md §三）；破石折扣、命纹树首刷免费等增益照常挂接

## 二、营地（多功能成长节点）

营地 = **每次到营地，从3项营务中三选一**——免费但限选一项。

### 2.1 基础营务（常备）

| 营务 | 效果 |
|------|------|
| **休整** | 恢复局内队伍状态，并恢复1颗命源石 |
| **淬火** | 升级1张卡（一→二直升；二→三从9条分支给3候选三选一） |
| **割舍** | 移除1张卡（含诅咒） |

### 2.2 营务稀有度差分（事件营务由档位承载）

营地三选一的选项质量由**节点稀有度档位**决定（冒险系统.md §2.1）：

| 档位 | 营务构成 |
|------|----------|
| **普通** | 基础营务三选一（休整/淬火/割舍） |
| **稀有** | 事件营务出现：挖掘/献火/追忆/淬毒附魔，及**遗落的装备/饰品**等优质选项 |
| **传说** | 宝藏级营务：埋宝藏（大量逸尘/特殊饰品）、稀有附魔、高档遗落装备等 |

### 2.3 事件营务清单

| 营务 | 效果 |
|------|------|
| **挖掘** | 挖出土中秘藏：随机饰品/逸尘/三级分支卡（小概率） |
| **献火** | 献祭1件散件或1张卡 → 换全队永久增益（本局） |
| **追忆** | 触发主角/伙伴剧情片段 + 小额奖励（伙伴好感节拍挂点） |
| **淬毒/附魔** | 按本域源神石语言强化1张卡，本局有效；强化只使用《源神石.md》的现行体系语言 |

## 三、分工一览

| 需求 | 去哪 |
|------|------|
| 花钱变强（买卡买装备） | 商店货架 |
| 免费成长（升级/删卡/回血/剧情） | 营地三选一 |
| 急救（诅咒净化、命源石） | 营地割舍（免费限量）/ 商店修复（花钱灵活） |
| 经济调节（卖货、刷新） | 商店 |

- 主题掉落、破石折扣、强运枝商店增益照常挂接
