# 《三乂川》命纹树与图鉴

> 本文件确定局外成长的拓扑、内容边界与叙事接口；彩灿尘成本、强运增量、里程碑阈值和奖励数量见 `统一数值配置.md` 第十一节。

## 一、命纹树总结构

命纹树仍为角色枝、强运枝、秘藏枝三条主枝，每枝9个节点，共27个节点。三枝均采用相同的**倒生拓扑**：

```text
外冠层：6个起始节点，可从任意节点开始
       \  /  \  /  \  /
汇流层：2个汇流节点，各读取本枝3个外冠节点
          \      /
归根层：   1个终点节点
```

- 玩家第一次进入命纹树时即可查看并购买三枝全部18个外冠节点，不设置唯一根节点。
- 每个汇流节点各关联本枝3个外冠节点；点亮其中任意2个后开放。未点亮的外冠节点不会因此消失，之后仍可补全。
- 每枝的归根节点要求本枝2个汇流节点均已点亮。
- 三枝彼此独立，不用先完成一枝才能进入另一枝；玩家可以广泛铺开，也可以集中归根。
- 外冠、汇流、归根分别消耗30、90、180彩灿尘；彩灿尘产出见 `统一数值配置.md`。
- 命纹树不扩充或修复九颗命源石，不提供局内直接升卡、删卡、锤子、商店刷新、装备或伙伴解锁。

该拓扑让选择数量从18个开放入口，逐步收束为6个汇流节点和3个归根节点，符合“初期选择多、后期答案逐渐集中”的目标。

## 二、倒生树的世界设定

命纹树不是自然生长的植物，而是川灵将失败世界线倒写后形成的**逆生物**。它没有种子，也没有正常意义上的树根：

- 最先显现的是悬在川心上方的叶与细枝，叶尖朝下，像许多尚未被选择的未来。
- 玩家点亮外冠节点时，一段失败世界线先化为叶脉；相近的命运随后彼此寻找，才向内长出枝干。
- 两道汇流命纹完成后，枝干继续向川心收缩，最后生出一截向上的“根”。根不是扎入土壤，而是扎进川灵留下的旧伤。
- 因此这棵树的生长顺序是**先叶、后枝、再干、终生根**。世人称其为树，只因没有更合适的名字。
- 外冠代表“曾经可以成为的许多人”，汇流代表“反复发生的几类命运”，归根代表“所有失败最后留下的同一个答案”。

三枝归根全部点亮代表三条主脉已经贯通，但未点亮的外冠节点仍可继续补全；27节点全部点亮才算命纹树完整收集。无论主脉贯通或全收集，都不直接解锁最终剧情；最终剧情仍读取第九重、管理员的钥匙与绝境石条件。

## 三、三枝内容槽位

以下确定每个节点负责的内容；效果数值见 `统一数值配置.md`。所有节点均只解锁或强化其标注范围，不越过三枝边界。

### 1. 角色枝——候补者名录

角色枝负责主角身份与身份专属内容，不解锁伙伴。

| 层级 | 节点 | 内容 |
|------|------|------|
| 外冠 | **武备名** | 解锁主角身份贾克斯 |
| 外冠 | **命牌名** | 解锁主角身份崔斯特 |
| 外冠 | **共鸣名** | 解锁主角身份咪哈呦 |
| 外冠 | **旧籍页** | 解锁阿泰克、蒂范德、拜冷斯对应的身份事件组 |
| 外冠 | **异路签** | 解锁贾克斯、崔斯特、咪哈呦对应的身份事件组 |
| 外冠 | **功名册** | 解锁葛朗台、普朗克、艾德明对应的身份事件组；未解锁身份不会生成对应事件 |
| 汇流 | **百器同途** | 汇合贾克斯、崔斯特、咪哈呦一组；开放三者共用的身份事件组 |
| 汇流 | **旧名归册** | 汇合旧籍页、异路签、功名册一组；开放身份故事的链式回看 |
| 归根 | **九身一命** | 解锁“问命”身份选择方式：从全部已解锁身份中随机展示3个再选择；不改变各身份强度 |

葛朗台、普朗克与艾德明继续由各自通关成就解锁，不被角色枝替代；阿泰克、蒂范德与拜冷斯继续初始开放。
所有已开放身份的初始牌组、身份饰品和关联牌必须始终可以在身份选择界面完整预览，不作为命纹奖励锁定。

### 2. 强运枝——四十八遗言

强运枝负责稳定的局外基础增益，不提供新机制内容，也不改变命源石数量。

| 层级 | 节点 | 内容方向 |
|------|------|----------|
| 外冠 | **余钱纹** | 提高轮回初始纽币 |
| 外冠 | **健命纹** | 提高标准共享生命上限 |
| 外冠 | **牌缘纹** | 改善一级、二级普通卡奖励的高档权重 |
| 外冠 | **器缘纹** | 改善常规饰品奖励的高等级权重 |
| 外冠 | **掘藏纹** | 改善营地挖掘结果，不改变继承饰品必得规则 |
| 外冠 | **营火纹** | 提高营地经验收益或温存收益，增量读取局外成长配置 |
| 汇流 | **丰行脉** | 汇合余钱、牌缘、器缘；强化常规探索奖励的稳定性，不直接生成三级卡或源神石 |
| 汇流 | **安身脉** | 汇合健命、掘藏、营火；强化长线生存与成长，不修复命源石 |
| 归根 | **川佑归流** | 每个领域首次完成一组四节点探索时获得一次固定成长奖励；种类与数量读取局外成长配置 |

强运枝只改变基础值或投放权重，不改变普通/稀有/传说的3/6、2/6、1/6品质骰本身，也不让商店出售源神石或三级卡。

### 3. 秘藏枝——九主异闻

秘藏枝负责把新的可收集内容加入对应池，不直接提高已拥有内容的战斗数值。

| 层级 | 节点 | 内容 |
|------|------|------|
| 外冠 | **攻增谱** | 解锁打击、重击、鼓舞三类的扩展三级分支进入同名升级池 |
| 外冠 | **守蚀谱** | 解锁防御、虚弱、易伤三类的扩展三级分支进入同名升级池 |
| 外冠 | **运铸谱** | 解锁能量、整备、锻造三类的扩展三级分支进入同名升级池 |
| 外冠 | **行商谱** | 解锁一组商售或通售常规饰品进入对应来源池 |
| 外冠 | **掘藏谱** | 解锁一组掘藏、战利或域产饰品进入对应来源池 |
| 外冠 | **奇闻谱** | 解锁一组稀有事件与领域事件进入事件池 |
| 汇流 | **万法入川** | 汇合三组卡牌分支；开放已解锁三级分支的图鉴轶闻与构筑检索 |
| 汇流 | **百物有主** | 汇合饰品与事件内容；开放来源筛选和限定来源图鉴侧链 |
| 归根 | **秘藏全书** | 开放秘藏内容的完整来源提示；只显示取得渠道，不保证本轮回出现 |

三级卡依然只能由同名卡升级获得；秘藏枝只是决定扩展分支是否进入九随机三的候选池，不改变升级规则。

## 四、图鉴：线性主链与条件支链

图鉴不是第二棵需要花费资源的树。它由卡牌、饰品、伙伴、源神石、敌人、事件六卷组成，每卷采用**线性主链**：前一里程碑完成后才显示下一里程碑的完整要求与奖励。

```text
初见 → 识形 → 知用 → 成类 → 尽录
                    └─ 条件支链 ─ 轶闻/来源/关系文本
```

- **初见**：首次见到该类内容，开启分类卷册。
- **识形**：记录一定数量的不同条目，开放基础检索与筛选。
- **知用**：满足取得、使用、击败或完成条件，开放机制说明。
- **成类**：完成该类主要收藏，解锁分类轶闻。
- **尽录**：完成该卷正式收集目标，点亮卷末印章。
- 六卷的阈值和奖励数量读取图鉴配置；阶段顺序固定，不允许跳级领取。

### 条件支链

支链不消耗彩灿尘，也不阻塞主链，只在玩家同时满足两个或以上相关条目时出现。

| 支链 | 示例条件 | 内容用途 |
|------|----------|----------|
| 人石链 | 同时记录伙伴及其对应源神石 | 解锁持纹者与源神石的关系轶闻 |
| 人器链 | 取得伙伴及其专属饰品记录 | 解锁饰品成为被动语言的来历 |
| 域敌链 | 击败领域特产怪与该域Boss | 解锁领域生态与Boss利用共享规则的说明 |
| 牌石链 | 记录同一源神石对应的九类三级卡 | 解锁该石的完整体系语言 |
| 事物链 | 在事件中取得限定饰品 | 解锁事件后续与器物来源 |
| 身份链 | 使用特定身份完成对应条件 | 解锁身份轶闻，不替代身份解锁成就 |

六卷全部点亮卷末印章后，解锁隐藏文本《第十块碑》。尘归录作为失败叙事的独立附卷，按轮回失败条件线性开放，不计入六卷完成度，也不阻塞《第十块碑》。

## 五、界面表现

- 命纹树默认以树冠朝下、根部朝上的纵向构图展示；外冠18节点位于屏幕下半部，汇流6节点居中，3个归根节点向上扎入川心。
- 初次打开时先看到大量可选叶片，缩放后才发现枝干正在向上汇聚，视觉方向与常规技能树相反。
- 可购买、已点亮、仅可预览三种状态必须同时用形状和亮度区分，不能只靠九石颜色。
- 点亮外冠时先亮叶脉；点亮汇流时播放两股或三股命纹合流；点亮归根时根须向川灵旧伤生长。
- 图鉴采用六本并列卷册。卷内主链横向或纵向单线推进，支链从相关里程碑侧边伸出；支链不画回主链，避免误解为前置条件。
- 所有尚未达到的数值阈值显示进度，不用“未完成”贴纸；尚未识得的具体条目用剪影与来源类别代替名称。

## 六、规则边界

1. 命纹树是消费彩灿尘的永久成长；图鉴是记录行为后自动推进的收藏系统，两者不能共用加点操作。
2. 命纹树的解锁不会追溯发放局内奖励；新内容从下一次生成对应池时开始生效。
3. 图鉴支链只提供文本、检索或收藏奖励，不是构筑必要前置。
4. 成就轨继续独立承担葛朗台、普朗克、艾德明等条件解锁，不塞入图鉴主链。
5. 彩灿尘价格、强运百分比、里程碑数量与收藏奖励读取局外经济配置，不改变27节点职责与六卷拓扑。

## 七、结构边界

- 三枝6—2—1倒生拓扑、27个节点职责、六卷线性主链与条件支链通过结构审查。
- 角色枝只负责主角身份与身份事件，伙伴保持全部开放；强运枝只提供稳定成长；秘藏枝只把新内容加入对应池，边界清晰。
- 归根不直接开启最终剧情，六卷尽录只解锁《第十块碑》，与第九重钥匙+绝境石真结局条件不存在捷径冲突。
- 彩灿尘成本、强运幅度、图鉴阈值与奖励量由局外数值表提供，不改变树形、节点名称和职责分配。
