# 《三乂川》战斗系统设定 v0.7

> 战斗采用敌我1v1的实时卡牌结构。六边形棋盘、布阵、射程、索敌、移动、位移、召唤单位和范围选格均不再使用。

## 一、战斗双方

- 我方由主角和当前已经加入的伙伴组成，最多为主角+3名伙伴；全队共享一条局内生命值，角色不拥有独立战斗血条。
- 敌方以一个战斗实体参与战斗，只有一条生命值；具体行动池由敌人设计定义。
- 卡牌无需选择施放者、目标或格子。打出后按卡面直接作用于我方共享状态或唯一敌方。
- 局内生命与局外命源石分离。每场战斗以当前共享生命上限的满血状态开始；局内生命归零才判定战斗失败，并按冒险系统处理后续流程。

## 二、实时tick与战斗流程

- 战斗以 **0.1秒为1tick**。持续时间、进度条、周期触发和延迟效果均以整数tick运行。
- 玩家依靠命潮自然恢复并打出卡牌；敌方依靠行动进度条完成行动。
- 敌方从行动池中选择攻击、护盾、增幅等行动，立即公开行动意图及其进度条；进度条蓄满时自动结算，再选择下一项行动。
- 玩家可以在敌方蓄力期间通过输出、防御、治疗、减速或打断改变结果。

同一tick按以下固定顺序结算：

1. 锁定该tick前已经提交的玩家出牌。
2. 支付费用并结算卡牌及其即时触发。
3. 结算打断、净化、变化等会改写后续事件的效果。
4. 结算到期的毒伤、火伤、持续治疗与护盾自然衰减。
5. 推进命潮自然充能和敌方行动进度。
6. 结算本tick达到满进度且未被取消的敌方行动。
7. 扣减持续时间并移除到期状态。
8. 执行死亡检查、牌区移动、手牌补足与界面刷新。

同一步骤内按效果建立先后顺序结算。敌方死亡后取消尚未结算的行动；我方死亡后不再补牌或进入下一tick。行动池与可打断规则统一遵守《敌人设计.md》。

## 三、命潮与手牌

### 3.1 命潮

- 命潮是打牌费用，上限为 **3点**，并随真实时间自然恢复。
- 卡牌可以立即获得命潮、修改自然恢复速度、预借未来命潮或使下一张牌免费。
- 命潮达到上限后不再自然增加；溢出处理由明确写出溢出效果的卡牌负责。

### 3.2 抽三打一弃二

- 常态手牌为3张。
- 玩家主动打出1张牌后，另外2张牌进入弃牌堆，再从抽牌堆补足3张。
- 抽牌堆为空时，将弃牌堆洗回抽牌堆；消耗区、能力区和绝技蓄势区不参与重洗。
- 抽牌触发按“抽牌动作次数”计算，不按该动作实际获得的牌数计算。
- 自动打出的牌不替玩家打出负面状态牌；具体卡面可另行改变牌区流转。

### 3.3 牌区

| 牌区 | 作用 |
|------|------|
| 抽牌堆 | 等待进入手牌的普通卡与衍生牌 |
| 手牌 | 当前3张候选牌；部分词条可暂时改变换组方式 |
| 弃牌堆 | 未消耗卡的循环区 |
| 消耗区 | 本场战斗不再参与抽取的卡牌 |
| 能力区 | 已生效且持续至战斗结束的能力牌 |
| 绝技蓄势区 | 尚未蓄满或使用后重新充能的伙伴绝技 |

## 四、伤害公式

```text
有效攻击 = 卡牌基础攻击 + 力量
最终直接伤害 = 使用有效攻击计算出的基础结算值
             × (1 + 激昂 + 鼓舞)
             × (1 + 易伤 + 脆弱)
             × 各项明确写出的额外增伤独立乘区
```

- **力量**：永久、线性增加直接攻击的基础值。
- **激昂**：次数型自身增伤；在下一次符合条件的直接伤害结算中生效并消耗次数。
- **鼓舞**：限时自身增伤；层数表示剩余时间，重复获得只延长持续时间，不提高单次增伤幅度。
- **易伤**：限时提高敌方受到的直接伤害。
- **脆弱**：次数型提高敌方受到的直接伤害。
- 激昂与鼓舞同区加算；易伤与脆弱同区加算；两个区间彼此乘算。
- 被动、环境或卡面明确标注的额外增伤使用独立乘区。
- 毒伤与火伤不进入上述常规增伤区，只受自身层数规则和明确写出的专属放大效果影响。

## 五、生命、护盾与恢复

- 护盾先于共享生命承受普通直接伤害和火伤。
- 护盾按固定速率随时间衰减；衰减速率在数值策划阶段确定。
- 壁垒能力可令护盾停止自然衰减，但护盾仍会被伤害消耗。
- 所有写作“失去生命”的主动代价均穿透护盾，直接扣除共享生命，并产生一次生命损失事件。
- 恢复只回复局内共享生命，不回复局外命源石；具体治疗量由数值策划确定。
- 可净化的负面战斗状态由急救、净化炉等卡牌处理；牌组中的负面状态牌属于另一类对象。

## 六、持续伤害

### 6.1 毒伤

- 毒伤穿透承受方护盾，直接扣除其生命。
- 毒伤层数上限为9，当前层数同时决定伤害与持续能力。
- 每次按时间结算后，毒伤层数线性减少。
- 触媒增加额外毒伤结算次数；每次额外结算都视为完整结算，并正常触发毒层衰减。

### 6.2 火伤与重伤

- 火伤不能穿盾，先由承受方护盾承受；火伤层数没有上限。
- 每次按时间结算后，当前火伤层数减半。
- 火伤附带重伤。重伤本身不造成伤害，只降低治疗效果。
- 重伤持续时间依据最近一次施加火伤时的层数刷新，并按时间线性递减。
- 火伤和毒伤的伤害、间隔、衰减量、治疗削减比例及取整方式在数值策划阶段确定。

## 七、敌方控制

- **虚弱/失去力量**：降低敌方直接伤害或基础攻击。
- **减速**：降低敌方行动进度条填充速度，不直接回退已经获得的进度。
- **打断**：取消敌方当前可打断行动，使其重新选择行动；不可打断行动不受影响。
- 当前公共战斗语言不使用击退、位移、禁足、冰冻或行动进度直接回退。

## 八、特殊词条

| 词条 | 规则 |
|------|------|
| 固有 | 在抽牌堆中优先于非固有牌进入下一组手牌；多个固有按进入抽牌堆的先后排列，超出空位的继续留在抽牌堆顶，不突破3张手牌上限 |
| 消耗 | 结算后进入消耗区；消耗X表示共有X次消耗额度，前X−1次结算后进入弃牌堆，最后一次才进入消耗区 |
| 保留 | 因常规弃二本应弃置时留在手牌，占据下一组手牌的一个位置 |
| 虚无 | 高于同类平均质量；未主动打出而被弃置时视为消耗，并触发消耗联动 |
| 奇巧 | 牌因常规弃二被弃置时额外触发奇巧效果，随后仍进入弃牌堆；主动打出时只结算普通卡面。奇巧是可重复的弃牌附加触发，激发则是在主动/弃置两种完整效果中二选一 |
| 激发 | 主动打出时结算一个效果；未打出而被弃置时结算另一个效果 |
| 轻盈 | 打出时另外两张牌不被弃置，只抽1张新牌补回3张 |
| 能力 | 主动打出后进入能力区并持续至战斗结束；同名默认叠加，卡面注明不可叠加的除外 |
| 蓄势3 | 伙伴绝技专属；满足绝技条件时蓄势+1，累计3次后置于抽牌堆顶并获得固有；使用后返回蓄势区、清零并重新蓄势 |

## 九、负面状态牌

| 类型 | 规则 |
|------|------|
| 一次性惩罚 | 被弃置时触发惩罚，随后消耗 |
| 永久惩罚 | 不能主动打出，弃置后继续循环并反复占据候选位 |
| 处理型 | 必须主动打出才能处理并消耗；未打出而被弃置时继续循环 |

- 负面状态牌与角色身上的毒伤、火伤、减速等负面战斗状态相互独立。
- 变化不是弃置，被变化为燃料时不会触发弃置惩罚。
- 处理型负面状态牌可被绝时域降为0费并主动处理；自动出牌与复制效果不能选择负面状态牌。

## 十、伙伴绝技

- 每名伙伴的绝技使用蓄势3。未蓄满时只显示在绝技蓄势区，不污染普通牌组。
- 每次满足该绝技写明的条件时蓄势+1；累计3次的事件结算完成后，将绝技置于抽牌堆顶并赋予固有。
- 绝技进入牌组后暂停蓄势，保证同名绝技不会同时存在多张。
- 绝技主动使用后返回绝技蓄势区，进度清零并重新充能。
- 每张伙伴绝技在卡面写明自己的专属蓄势条件，并统一遵守上述牌区循环。

## 十一、胜负

- 敌方生命归零：战斗胜利。
- 我方共享生命归零：战斗失败。非Boss战不损伤命源石；九域Boss战按序位损伤命源石并在未终结时直接进入下一域；最终Boss“48兵”战败直接结束轮回。
- 战斗时长、全部可调费用和数值、状态强度、触发间隔与抗性数值统一在数值策划阶段确定。
