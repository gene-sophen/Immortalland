# 《三乂川》战斗系统设定 v0.4

> 自动战斗 + 命潮技能牌模型：云顶式棋盘自动战斗为底，皇室战争式命潮手牌为干预，蓄能绝技为高潮。

---

## 一、战场

### 1.1 棋盘

六边形网格 5 行 12 格（3的倍数，呼应三乂），从下到上按 2-3-2-3-2 排布：

```
        ◇ ◇         敌方区 2
       ◇ ◇ ◇        敌方区 3
        ◇ ◇         中间桥 2（咽喉）
       ◇ ◇ ◇        我方区 3
        ◇ ◇         我方区 2
```

- **我方区5格**：布阵放3名英雄，余2格给障碍/投放留余地
- **中间桥2格**：近战交锋必经的咽喉要道，天然前线——小棋盘的战术重心
- **敌方区5格**：单场敌方2-4名单位+Boss
- 全图跨度约3-4格：射程按**近战1 / 中程2 / 远程3**标定，衰减值独立印牌面（无全局公式）
- 大格子保证竖屏可读性与点按容错，AI寻路复杂度同步下降

### 1.2 地皮

| 地皮 | 效果 | 来源 |
|------|------|------|
| 普通 | 无 | 默认 |
| 障碍 | 不可停留/穿越，阻挡近战路径与直线弹道 | 随机场地/荒脊岭 |
| 增益地皮 | 停留单位攻击+2，每20tick护盾+2 | 随机场地/皮安城 |
| 火焰地皮 | 停留单位每20tick受2点火焰伤害 | 火尽山/法术卡三级分支 |
| 毒沼 | 区域内单位每20tick+1层中毒 | 纳西妲技能卡 |

同一格同时只存在一种地皮效果，新覆盖旧。

**12格密度控制**：单场静态特殊地皮≤2格、障碍≤2格；**投放型区域效果可铺设在已有单位的格子上**（驻留效果不占格位，只影响站在上面的单位）。

### 1.3 地皮设计原则（自动战斗引擎约束）

自动寻路下"踩地皮"不受人为控制，地皮设计遵守四条：

1. **触发型→驻留型**：不做"踩上去触发"，做"在区域内按tick结算"——站位不可控，区域可控
2. **静态地皮=部署博弈**：战斗开始前存在的地皮是阵型决策（布阵阶段可见、可选站位）
3. **动态地皮=玩家投放**：战斗中的新地皮主要来自法术卡投放（指哪打哪），领域机制只是次要来源
4. **领域地皮机制须可预测**：如火焰蔓延须沿固定方向逐行推进并提前电报，不做随机蔓延

### 1.4 布阵阶段

- 战斗开始前：展示敌方阵容与站位 + 我方初始3张手牌
- 玩家在我方区5格内自由拖拽摆放3名英雄，**无时间限制**
- 确认后进入实时战斗

## 二、单位与属性

### 2.1 英雄属性（6+2项）

基础6项：**攻击 / 减伤 / 生命 / 嘲讽 / 等级 / 绝技蓄能**（伙伴）。
**自动行为画像**2项：**攻击间隔 / 射程**（另含移动速度、暴击率等次级参数）。

坦度统一走**减伤**机制（不设防御力属性）：百分比属性，5%步进、上限50%，结算在乘法增益后、护盾前（见§4.4）。

| 职业 | 攻 | 减伤 | 血 | 嘲讽 | 攻击间隔 | 射程 | 定位画像 |
|------|----|------|----|------|----------|------|----------|
| 战士 | 10 | 10% | 45 | 100 | 26tick（2.6s） | 1 | 近战均衡 |
| 骑士 | 8 | 25% | 50 | 120 | 34tick（3.4s） | 1 | 低频重击主坦 |
| 法师 | 12 | 0% | 30 | 60 | 30tick（3.0s） | 3 | 远程重炮 |
| 猎人 | 11 | 0% | 32 | 70 | 22tick（2.2s） | 3 | 远程速射 |
| 刺客 | 13 | 0% | 28 | 50 | 20tick（2.0s） | 1 | 近战高频爆发 |
| 牧师 | 7 | 5% | 35 | 80 | 28tick（2.8s） | 2 | 中程辅助 |
| 主角 | 10 | 10% | 40 | 80 | 26tick（2.6s） | 2 | 中庸（不定职业画像，定位由对局构筑决定） |

- **攻速以tick制表达：攻击间隔 = 每N tick攻击一次**；攻速词条按25%档减少tick数，下限5tick（0.5秒，引擎兜底）
- 等级1-9：固定成长为每级攻+2/血+5（减伤不走固定成长，由装备/词条/升级三选一提供）
- **升级属性三选一**：每次升级从攻+3 / 减伤+5% / 血+8 中三选一——同级不同命，成长个性化
- 3/6/9级为里程碑：触发源流三选一 + 伙伴技能卡解锁（见卡牌系统.md §三）

### 2.2 状态效果词库（tick化，分增益/减益两类）

**增益类**：

| 状态 | 效果 | 持续/叠加 |
|------|------|-----------|
| 护盾 | 吸收伤害 | 60tick或击破 |
| 增伤 | 造成伤害+25%（可分类型：普攻/技能/全域，由卡面注明） | 40tick |
| 再生 | 每20tick回复2（持续型治疗） | 60tick，重复施加=延长持续 |
| 金身 | 免疫一切伤害（含dot），技能提供的短无敌 | 20tick，不可叠 |
| 蓄力 | 下次攻击+50% | 消耗型 |
| 嘲讽↑ | 嘲讽权重翻倍 | 40tick |

**减益类**：

| 状态 | 效果 | 持续/叠加 |
|------|------|-----------|
| 灼烧 | 每20tick 2伤；**共生重伤**（受疗−50%） | 60tick；**不可叠层**，重复施加=延长持续 |
| 中毒 | 每20tick每层1伤 | 100tick，叠层刷新，上限9层 |
| 迟缓 | 攻速/移速−25% | 40tick，不可叠 |
| 禁足 | 无法移动 | 30tick |
| 冰冻 | **无法行动**（攻击/移动/施放全锁） | 20tick，不可叠 |
| 易伤 | 受到伤害+25% | 40tick |
| 虚弱 | 攻−25% | 40tick |

- **dot双轴分工**：灼烧=不叠层+共生重伤（压治疗）；中毒=叠层滚雪球
- **控制链分层**：迟缓（软）＜禁足（锁移动）＜冰冻（锁行动）；控制对Boss是否递减→数值阶段校准
- 持续伤害无视护盾直接扣血；金身=免疫一切伤害含dot
- 重伤不独立存在（与灼烧共生）；驱散类效果对「不可驱散」目标无效

## 三、战斗总流程

```
布阵阶段（无时限）
   ↓
实时自动战斗（0.1秒tick引擎驱动）
   ├─ 英雄自动走位/索敌/普攻（ chunky低攻速大数字 ）
   ├─ 玩家干预：命潮技能牌（常驻3张手牌）+ 绝技（蓄能满解锁）
   ├─ 三幕节奏：命潮回复 1x → 1.5x（20s）→ 2x（40s）
   └─ 40s后加时：全场亢奋 + 源神风暴（45s起）
   ↓
胜负判定 → 战后结算
```

## 四、自动战斗引擎

### 4.1 时间刻度（0.1秒tick）

- 1 tick = 0.1秒；伤害/回复/dot/冷却/前摇全部按整tick结算
- 时间流速以timescale实现（0.3x=现实1秒走3tick游戏时间；2x=20tick）；**任何流速下结算时机无浮点争议**
- 防循环兜底：同名触发效果每tick限1次、每秒限3次
- 攻速兜底：攻击间隔下限5tick（0.5秒）

### 4.2 索敌与走位

- 普攻目标：按嘲讽权重随机抽取，**相邻敌人权重×1.5**；目标死亡/失效后重新抽取
- 近战单位：沿六边形寻路接近目标（避开障碍）；远程单位：目标进入射程即站定输出
- **伤害地皮软墙规则**：近战寻路时若存在绕行≤2格的替代路径则绕过伤害地皮，否则直接穿过——投放型地皮可以当"软墙"引导敌方走位
- 除软墙规则外，单位不主动避让危险地皮（保留玩家用位移技能干预的空间——位移为刺客型英雄的技能特质，不做公共卡）

### 4.3 chunky攻击模型

- 每击伤害 = 攻击力（整数大数字，不做"高攻速小数字"）
- 攻击间隔按职业20-34tick（2.0-3.4秒，见2.1）；攻速词条按25%档减少tick数，下限5tick
- 距离衰减：**不设全局公式，独立印在牌面/面板**（如某远程敌人"超过2格伤害−5"）

### 4.4 伤害结算管线

```
基础值 = 底值 + 系数 × 施放者/攻击者对应属性
 → +加法增益（鼓舞、蓄力）
 → ×乘法增益（源流/装备/易伤，仅25%/50%档）
 → ×(1−减伤)（5%步进，上限50%）
 → −独立衰减值（若有）
 → −护盾吸收 → 剩余扣生命
```

统一向下取整；设计数值时优先整数结果。

## 五、命潮与手牌

### 5.1 命潮曲线

| 参数 | 数值 |
|------|------|
| 初始 | 2点 |
| 上限 | 3点（攒满触发战术时刻） |
| 回复 | 第一幕1点/3s → 第二幕1点/2s（20s）→ 第三幕1点/1.5s（40s） |
| 卡牌费用 | 1费为基准；重牌2费；3费=全槽梭哈（多为绝技/重炮） |

- 上限3的隐藏收益：每一点能量都有存在感；降费机制有明确地板（0费）；UI只需3个刻度

### 5.2 手牌规则（常驻三选一）

- 手牌区常显一组3张；**打出1张 → 其余2张全部弃掉 → 补上新的一组3张**（抽三打一弃二）——每一次施放都是完整的三选一
- **手牌调度靠卡牌，无换组按钮**：常规对局不提供花钱换组；调度能力由整备系卡牌承载（打出即弃2补3=换组效果，见卡牌系统.md §二）
- **战术时刻**：命潮满3点时，时间减速0.4x（≤40tick）+ **往抽牌堆加入1张一级整备**
- 抽牌堆空→弃牌堆洗回；**构筑卡组目标12-18张**（常规获得制、无硬上限，厚度靠删卡服务软纪律；含角色技能卡与蓄能绝技卡，详见卡牌系统.md）
- 循环节奏：每场战斗施放6-14次——Boss战可完整循环卡组1-2遍

### 5.3 施放规则

- 流程：点选手牌 → 点选施放者 → 点选目标格/目标单位（单手拇指可达）
- **施放者绑定**：公共攻击牌指定存活英雄施放（伤害=底值+系数×其攻击，射程/弹道从其站位计算）；技能卡自动绑定对应角色
- **系数模型**：卡牌效果值 = 底值 + 系数×施放者属性；系数只取50%/100%/150%/200%档
- 打出即结算，无延迟；**随机效果一律在抓取/入手时前置结算并牌面明示**（放出时心里有数）

### 5.4 子弹时间与辅助档位

| 操作 | 时间流速 |
|------|----------|
| 点住手牌 | 0.5x |
| 拖拽瞄准 | 0.3x，按住不限时 |
| 松手施放 | 恢复1x |

辅助档：**标准**（0.3x瞄准）/ **轻松**（瞄准完全暂停）/ **自动**（绝技自动释放）。
倍速开关：1x/2x/3x随时切换。

## 六、绝技系统（蓄能制）

绝技卡直接在卡组中，卡面印「蓄能X」计数器（卡牌系统.md §4.2）。

| 规则 | 内容 |
|------|------|
| 蓄能 | **阈值X与触发条件均按角色个性化设计**（如：打出技能卡+1 / 施放buff+1 / 暴击+1 / 承伤按比例），充满解锁可打出 |
| 费用 | **0命潮**——蓄能即成本 |
| 呈现 | 卡组/手牌中直接显示充能进度（当前/X），无独立资源轨 |
| 主角 | 与伙伴同规则（主角技能卡3张含绝技） |

**绝技设计三红线**：

1. 蓄能制——触发条件按角色个性化，不走时间轨
2. 0命潮施放，蓄能即成本
3. **表达人设而非放大数值**——遮住名字能认出是谁的招

节奏锚：蓄能阈值按角色节奏标定——以每场8-12次出牌估算，主力绝技约20-30秒充满；杂兵战放1次、Boss战2-3次。

## 七、加时与防拖局

40秒后进加时，三层递进：

1. **全场亢奋**：双方攻速+30%，此后每10秒伤害再+25%
2. **命潮2x**：进入第三幕回复速率
3. **源神风暴**：45秒起，每秒对双方全体递增伤害（初始2点/秒，每秒+2，无视护盾；平安京领域提前至35秒，见冒险系统.md §2.2）

战斗硬上限约75-90秒。**同一tick双方同归于尽：判玩家获胜**。

## 八、敌方设计框架

### 8.1 行为模式

- 敌方普攻：与我方同引擎（索敌/间隔/衰减独立值）
- 敌方技能：**前摇红区15tick（1.5秒）**+范围/数值公示，给玩家位移技能/防御牌的反应窗口；精英/Boss每8-12秒一次技能节拍
- **打断**：前摇红区中的敌方技能可被「打断」类效果取消（如封喉咒）
- 过明氹领域：敌方技能**无前摇提示**（只能看到敌方位置，数值与攻击意图未知，见冒险系统.md §2.2）

### 8.2 档位与递进

| 档位 | 血 | 攻 | 模式 |
|------|----|----|------|
| 杂兵 | 18-35 | 6-9 | 普攻+简单技能 |
| 精英 | 50-90 | 10-14 | +1词缀（灼烧/护盾/狂暴/召唤） |
| Boss | 130-260 | 12-18 | 2主动技能+阶段转换+领域机制放大 |

领域递进：二域×1.5、三域×2.2、最终Boss×2.8（原型校准）。

单场规模：**杂兵/精英战2-4名；Boss战1名+增援**，召唤物在场上限2名（含Boss增援）——12格棋盘的密度控制。

### 8.3 九域机制设计约束

领域机制以**每域一个特色**为准（冒险系统.md §2.2），设计约束（与§1.3地皮原则一致）：

- 避免依赖"踩地皮触发"的效果（AI走位不可控）
- 兼容的四种形式：**部署阵型博弈**（战前可见的静态布局）/ **区域驻留结算**（按tick生效的区域效果）/ **全局规则**（反伤、伤害转化、源神石增幅等）/ **可预测推进机制**（电报化的蔓延、固定节拍的全场事件）
- 领域机制应同时作用于敌我双方，或为玩家保留对策窗口（位移技能/法术卡/阵型可应对）

## 九、阵亡与胜负

| 对象 | 规则 |
|------|------|
| 伙伴阵亡 | 退场至战斗结束；其技能卡（含绝技）退化为0费垃圾卡；战后复活，生命=50%上限 |
| 主角致命伤 | 触发【命运三选一】（每局限1次，见下）；已用则战斗失败、本局结束 |
| 胜利 | 敌方全灭（召唤物无主自动消亡） |

**命运三选一**：主角受到致命伤害时触发，掷骰定档（普通/稀有/传说影响数值强度）→ 三轴交易三选一：

| 选项 | 即时救命 | 持续增益 | 长期代价 |
|------|----------|----------|----------|
| ① **背水**（战斗轴） | 生命锁1点+全队满护盾 | 本局主角攻击+25% | 命源石本局不可修复 |
| ② **典当**（经济轴） | 复活至75%生命 | —— | 消耗全部纽币 |
| ③ **逆命**（构筑轴） | 复活至50%生命 | 本局命潮上限+1（3→4） | 牌组注入2张诅咒「命运之债」 |

- 卡厄石持有者可重掷一次档位
- 设计纪律：每个选项 = **即时救命 + 持续增益 + 长期代价**，不做纯收益；定位=逆风补偿的仪式感+难度安全阀

战后结算：经验（普通1/精英2/Boss全员+1级）、纽币（8-12/15-20/30-40）、卡牌奖励三选一、状态地皮清除。

## 十、数值与时长锚

### 10.1 数值体系

- **100数量级**：英雄血28-50、杂兵18-35、精英50-90、Boss 130-260
- **TTK锚**：杂兵双英雄集火8-10秒、精英全队25-30秒、Boss 60-75秒
- **命潮当量**：1点命潮 ≈ 1.5-2秒全队自动输出
- **取整纪律**：系数50%档起步、增益25%/50%档、衰减独立数值、向下取整
- **防贬值**：翻倍类效果必带"消耗"限制

### 10.2 时长预算

| 战斗类型 | 时长 | 施放次数 | 绝技次数 |
|----------|------|----------|----------|
| 杂兵 | 25-35秒 | 4-6 | 0-1 |
| 精英 | 40-50秒 | 6-9 | 1-2 |
| Boss | 60-90秒 | 10-14 | 2-3 |

全局：一局约25-30分钟（战斗12-14场+功能节点，详见冒险系统.md §一），节点级存档随停随玩。

## 十一、表现与操作（竖屏）

按界面草图布局：

```
┌─────────────┐
│ 顶栏×2       │  敌方概要/战斗计时/倍速/领域机制提示
├─────────────┤
```
