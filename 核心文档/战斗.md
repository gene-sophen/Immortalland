# 《三乂川》战斗系统

## 一、战斗双方

- 我方由主角与当前伙伴组成，共享一条局内生命、护盾、增益、减益与命潮资源。
- 敌方始终为单一实体，拥有一条生命、护盾、状态和行动进度。
- 战斗没有棋盘、站位、距离、范围、移动或选中目标；卡牌打出后直接对规则指定的一方生效。
- 每场战斗按当前共享生命上限满血开始。局内生命归零不直接扣除固定局外生命，而是由冒险结算决定命源石损伤。

## 二、实时tick与统一时钟

- 最小结算单位为0.1秒，记作1 tick。
- 命潮恢复、敌方进度、持续状态、伙伴蓄力、30/60秒风暴均读取统一模拟时钟。
- 0.5×、1×、2×倍速和拖牌子弹时间只改变模拟时间推进速度，不改变结算顺序。
- 打开系统设置、应用退到后台或系统打断时暂停模拟时钟；查看卡牌或状态详情不暂停。

每个tick按以下顺序执行：

1. 登记本tick内已经完成拖放并合法提交的玩家操作。
2. 应用上个tick结束时登记的新增、延长、减速和其他进度修正。
3. 推进命潮自然充能、敌方行动进度和我方蓄力进度。
4. 结算玩家卡牌、饰品、能力与生成队列；打断在本步骤立即取消尚未结算的对应敌方行动。
5. 结算本tick到期且未被打断的敌方行动。
6. 结算毒伤、火伤、重伤、持续治疗及其他定时效果。
7. 执行状态衰减、次数移除、牌区移动与死亡检查。

同一步骤内按效果进入队列的先后执行；额外结算不能反向插入已经完成的步骤。只有在该tick登记截止前完成提交的牌才能抢在到期敌方行动前结算，拖拽中或截止后松手的牌进入下一tick。敌方死亡后取消其未结算行动；我方死亡后不再补牌或进入下一tick。同一tick内敌我同时死亡，判定我方胜利。

## 三、命潮与手牌

- 命潮上限3点，基础自然恢复为2秒/点；达到上限后的溢出丢失。
- 充能加速提高自然恢复速度；充能推进直接填充当前命潮点的进度。
- 每次需要补牌时抽3张组成当前手牌。玩家主动打出1张，默认弃置另外2张，再补3张。
- 牌堆不足时，将弃牌堆洗回抽牌堆；消耗区、能力区和绝技蓄势区不参与洗牌。
- 轻盈牌主动打出时，另外2张不弃置，只补1张；保留、虚无、奇巧、激发等牌区规则按 `卡牌系统.md` 执行。
- 卡牌不需要瞄准。费用不足、目标规则不合法或卡面条件不满足时不能提交。

## 四、牌区

| 牌区 | 职责 |
|------|------|
| 抽牌堆 | 等待进入手牌的普通卡、伙伴技能牌、诅咒和衍生牌 |
| 手牌 | 当前3张候选；保留、轻盈等效果可以临时改变数量与弃置 |
| 弃牌堆 | 正常打出或弃置后等待洗回的牌 |
| 消耗区 | 最终消耗、虚无弃置消耗及已耗尽消耗次数的牌 |
| 能力区 | 主动打出后永久持续至本场结束的能力牌 |
| 绝技蓄势区 | 未蓄满或使用后重新充能的伙伴绝技 |

## 五、直接伤害

常规直接伤害按以下顺序计算：

```text
段基础 = 卡牌基础伤害 + 力量
自增伤区 = 1 + 激昂 + 鼓舞
敌增伤区 = 1 + 易伤 + 脆弱
最终伤害 = 段基础 × 自增伤区 × 敌增伤区 × 各独立额外增伤
```

- 力量为永久线性基础值，作用于每个伤害段；标准1层力量为每段+5。
- 激昂与鼓舞加算；激昂按主动直接伤害牌次数消耗，鼓舞按持续时间存在，叠加只延长时间。
- 易伤与脆弱加算；易伤按持续时间存在，脆弱按主动直接伤害牌次数消耗。
- 激昂与脆弱覆盖整张牌的全部伤害段，在整张牌完成后各消耗1次。
- 饰品、身份和环境明确写出的额外增伤使用独立乘区；同名百分比来源先加算再乘，避免指数膨胀。
- 毒伤与火伤不读取力量、激昂、鼓舞、易伤或脆弱，只读取明确写出的专属增幅。

## 六、生命、护盾与恢复

- 标准基础共享生命为100。冒险等级、身份、命纹与饰品可以提高本轮回或本场生命上限。
- 护盾优先承受不能穿盾的伤害。护盾不自然衰减，只有承伤、主动消耗、效果移除或战斗结束才减少。
- 战斗结束时清空护盾、临时生命上限和本场状态；本轮回生命上限保留至轮回结束。
- 恢复不能超过当前共享生命上限；过量治疗只有卡面或饰品明确说明时才转化为护盾或生命上限。
- 放血、卡牌生命代价、裂创等“失去生命”效果穿盾；生命代价不足时按卡面决定是否允许打出。
- 查莉娅的充能护盾优先于普通护盾承伤，把实际吸收量转为充能；不受伤一段时间后充能逐渐减少，毒伤仍穿透。
- 金身期间免疫伤害和可阻止的负面状态；已经存在的持续状态是否推进由卡面说明。

## 七、毒伤、火伤与重伤

### 毒伤

- 毒伤穿盾，层数上限9。
- 每3秒结算一次，伤害为当前层数×5；结算后层数-1。
- 触媒或额外结算按当前层数立即执行一次完整毒伤结算，并照常衰减。

### 火伤

- 火伤不穿盾，层数无上限。
- 每2秒结算一次，伤害为当前层数×5；结算后层数减半并向下取整。
- 新施加火伤同时刷新重伤。重伤本身无伤害，只降低治疗效果；持续时间读取最近一次施加火伤时的层数并按时间线性减少。

### 专属增幅

- 降解石、九毒针盘、熔火风箱、大理石等明确效果可以提高毒火层数、额外结算或专属伤害。
- 额外毒火结算不再次触发产生它的同名条件，防止结算递归。

## 八、敌方控制

- 敌方行动在开始时公开类型、效果预览、是否可打断和预计完成时间。
- 减速降低敌方行动充能速度；标准1层持续4秒并使速度-30%，总减速不超过80%。
- 打断立即取消当前可打断行动，敌方随后按行动池重新选择；不可打断行动仍可受到减速和其他状态。
- 虚弱降低敌方攻击最终伤害；永久削攻、行动限制和控制抗性按敌人卡面公开显示。
- 冰冻、污染和卡牌类型限制必须在生效前提供可读意图和处理窗口。

## 九、两阶段诅咒风暴

- 战斗开始30秒后，命潮自然恢复加快并出现诅咒风暴，对敌我双方造成不穿盾的环境伤害；持续越久，风暴逐步增强。
- 战斗开始60秒后，命潮再次加快，风暴升级为灾蚀风暴：同时具有毒、火、穿盾、减疗和不可净化属性，并继续随时间增强。
- 环境风暴不属于敌方攻击，不触发只读取“敌方攻击”的反制；可以触发通用生命损失、护盾承伤和风暴饰品。
- 风暴为防杀构筑提供终局输出，同时为所有战斗设置软时限。具体间隔、倍率与曲线读取统一战斗数值表。

## 十、伙伴绝技

- 每名已加入伙伴的技能牌直接进入牌组，绝技初始位于蓄势区。
- 主动使用该伙伴技能牌3次后，绝技置于抽牌堆顶并获得固有。
- 绝技必须抽到并主动打出，不能点击头像跳过牌组流程。
- 使用后绝技返回蓄势区并清零。奥丽莎只有在蓄能冲击已经主动打出后的蓄力阶段，头像才临时作为提前释放按钮。

## 十一、胜负与冒险结算

- 敌方生命归零即战斗胜利；我方共享生命归零即战斗失败；同tick同时归零判我方胜利。
- 普通战胜利获得卡牌与纽币，失败只获得纽币且不损伤命源石。
- 精英和领域Boss失败按当前领域损伤1/2/3颗命源石并继续流程；超过九颗则轮回终止。
- 48兵失败无论剩余命源石多少都直接结束轮回。
