# 《三乂川》冒险系统 v0.6

> 单局采用九域长征：九域全体验，每域3个探索节点与1场Boss。九域共享v0.6战斗底层，并通过美术、事件、奖励和Boss的源神石语言形成差异。

## 一、九域长征

```text
随机起始域 → 领域1（3节点+Boss）→ 剩余领域三选一 → …… → 领域9 → 通关结算
```

- 每域固定3个探索节点和1场Boss。
- 起始域随机；通关一域后，从剩余领域中给出3个候选，显示源神石、内容倾向与奖励特色后选择下一域。
- 战斗节点、精英和Boss均使用v0.6单敌方行动池战斗。
- 单局时长、节点数量权重和敌人强度由数值策划阶段确定。

## 二、探索节点

| 节点 | 内容 |
|------|------|
| 战斗 | 普通敌人战；奖励纽币与卡牌三选一 |
| 精英 | 高强度行动池；奖励领域主题牌、装备或其他稀有内容 |
| 事件 | 剧情与三选一事件，可承载伙伴剧情节拍 |
| 商店 | 综合货架、删卡、刷新、回购与传说档命源石修复 |
| 营地 | 休整、淬火、割舍及稀有事件营务三选一 |
| 奇遇 | 高方差风险与高回报内容 |

Boss为每域固定终点，使用所属源神石的机制语言组织行动池。

## 三、节点稀有度

节点类型保持六种，每个节点分为普通、稀有、传说三档。稀有度决定奖励厚度、选择数与特殊内容出现率，不直接锁定物品品质。

| 节点 | 普通 | 稀有 | 传说 |
|------|------|------|------|
| 战斗 | 标准行动池与基础奖励 | 强化行动池与奖励加成 | 迷你精英配置与高额奖励 |
| 精英 | 基础精英 | 更多机制与掉落加成 | 高难机制与高级掉落加成 |
| 商店 | 3格货架 | 6格货架 | 9格货架并开放命源石修复 |
| 营地 | 基础营务 | 事件营务与优质遗落物 | 宝藏级营务 |
| 事件 | 标准事件池 | 奖励档提升 | 稀有剧情与构筑事件 |
| 奇遇 | 标准高方差 | 回报上限提高 | 高风险的奇遇级收获 |

骰子提供普通3面、稀有2面、传说1面的基础分布；域序可以在数值策划阶段调整权重。节点三选一时显示类型和稀有度。

## 四、九域内容边界

九域名称、统治者、源神石归属和美术设定见《世界观.md》。领域不使用障碍地皮、火焰地皮、隐藏位置、射程或红区，也不附加独立领域战斗效果。领域差异由美术、事件、奖励倾向和Boss的源神石语言承担。

## 五、投放与升级

| 阶段 | 领域 | 投放倾向 |
|------|------|----------|
| 一阶 | 第1—3域 | 一级卡和散件装备为主 |
| 二阶 | 第4—6域 | 二级卡与二级成装权重提高 |
| 三阶 | 第7—9域 | 三级卡、源神石与稀有内容权重提高 |

- 二级卡升三级时，从该类别9张分支中随机给出3张，玩家三选一。
- 低域可小概率出现高级内容，高域也允许基础内容；具体权重在数值策划阶段确定。
- 标准Build曲线用于调节每域预期构筑强度和敌人强度。

## 六、命源石

- 初始与上限均为3颗。
- 普通或精英战失败不碎石，获得低档参与奖励并继续冒险。
- Boss战失败碎1颗，可重整后重新挑战；敌方生命不继承。
- 营地休整或战胜Boss可恢复命源石。
- 碎至第3颗进入背水状态；背水状态下再次战败，本局终结。
- 命源石与战斗共享生命相互独立：单场共享生命归零只负责触发本次战败。

### 6.1 破石之力

每碎裂1颗命源石，队伍获得一层本局持续的破石增益；恢复命源石不清除已经获得的增益。具体攻击、生命、折扣和奖励数值在数值策划阶段确定。

### 6.2 逸尘结算

无论通关或失败终结，按域数、Boss胜利、构筑完成度等进度结算逸尘，用于局外成长。源神石的局内流派与结算转化规则继续沿用。

## 七、新手引导

首局第一领域使用脚本化教学：

1. 共享生命、敌方意图和行动进度条。
2. 命潮自然恢复与抽三打一弃二。
3. 护盾、治疗、毒伤穿盾与火伤减疗。
4. 装备、卡牌升级与营务三选一。
5. 伙伴绝技蓄势X及命源石战败规则。

不再教学布阵、射程、索敌、移动或格子范围。
