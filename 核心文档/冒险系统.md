# 《三乂川》冒险系统

## 一、轮回流程

```text
选择轮回与身份
→ 领域三选一 → 伙伴三选一
→ 4次节点探索 → 精英三选一
→ 4次节点探索 → 精英三选一
→ 4次节点探索 → 领域Boss
→ 重复完成三个不同领域
→ 48兵 → 轮回结算
```

- 每轮回只探索九域中的3个不同领域。每次从尚未进入的领域中随机展示3个，玩家选择1个。
- 每个领域固定16次冒险：伙伴1、探索12、精英2、Boss1；三域合计48次。
- 48兵位于48次冒险之后。战胜才算完整通关；战败直接结束轮回。
- 领域Boss和精英无论胜败，只要轮回没有终结，就完成当前冒险并继续前进，不允许原地重试。

## 二、节点三选一与品质

- 每次节点探索从战斗、商店、营地、事件、宝藏、随机六类中抽取3个不同类型并展示，玩家选择1个。不同探索之间允许同类重复。
- 除营地、伙伴选择和固定Boss外，每项候选独立以六面骰生成品质：普通3/6、稀有2/6、传说1/6。
- 品质是同一冒险进度的相对档位；节点基础收益随领域与行程自然增长，因此后期普通节点可以高于前期传说节点。
- 随机节点进入后，从战斗、商店、营地、事件、宝藏中转化为一种，使用略高的高品质权重。
- 品质生成、候选内容和随机结果在动画前写入存档，重开只能重播，不得重投。
- 品质骰、领域收益、等级奖励和节点纽币的完整数值见 `统一数值配置.md`。

## 三、节点规则

| 节点 | 规则 |
|------|------|
| 战斗 | 胜利展示3张一级或二级普通卡选1张并获得纽币；失败只得纽币，不损伤命源石 |
| 商店 | 购物、删卡、回收与刷新，详见 `商店系统.md` |
| 营地 | 挖掘、锤子、温存三选一；持有三务帐篷时三项各执行一次且顺序自选 |
| 事件 | 从正式事件池生成，固定三个入口，详见 `事件系统.md` |
| 宝藏 | 展示3件具体常规饰品，选择1件并同时获得纽币 |
| 随机 | 转化为前五类之一，揭示后完整执行对应节点 |
| 精英 | 战前展示3名具体精英、机制、品质、抗性、公开掉落与失败碎石量，选择1名战斗 |
| Boss | 固定为领域域主；胜利获得饰品与纽币，失败获得纽币并结算命源石损伤 |

- 九类一级卡在同一投放条件下等概率出现。
- 商店与节点只直接产出一级或二级普通卡；三级普通卡只能通过同名卡升级获得。
- 身份、伙伴和绝境石只从固定来源取得。源神石只来自对应Boss或明确的传说领域事件，商店不出售。
- 战利与域产饰品遵守 `饰品系统.md` 的来源边界；战前公开掉落表。

## 四、卡牌获取与锤子

- 取得普通新卡时，选择直接加入牌组，或消耗新卡令1张同名非满级普通卡升1级；牌组内既有同名卡不能彼此合成。
- 一级升二级直接替换；二级升三级时，从所属类别9个三级分支中随机展示3个并三选一。
- 营地锤子选择1张普通卡：一级或二级从同等级另外类别中随机展示3种并横向变化；三级从所属类别9个分支中随机展示3个并重选。
- 原类别或原分支可以出现。选择原结果仍消耗本次锤子。
- 伙伴牌、身份关联牌、负面牌和永恒牌不进入普通升级或锤子流程。

## 五、伙伴与冒险等级

- 九名伙伴在轮回开始时随机分成3组，每组3人且不重复；每个领域开场从当组选择1人加入。
- 伙伴加入时，其技能牌加入牌组，绝技进入蓄势区，专属饰品进入该伙伴饰品栏。
- 全队共享冒险等级和经验，不存在伙伴等级。
- 除伙伴选择外，每次完成探索、精英或Boss冒险获得1点经验；进入新领域额外获得3点经验。
- 营地本身提供2点经验；选择温存时总计获得3点经验。
- 每3点经验提升1级。常规每级提高本轮回共享生命上限；每3级获得纽币奖励，每6级获得高级卡牌或饰品奖励，每9级提高后续奖励的高品质权重。
- 每级生命上限+4并恢复4生命；每3级纽币依次为40、50、60……；每6级从二级卡三选一与二级饰品三选一中选择一组；每9级使后续品质骰最终点数+1，最多累计2次。
- 每场战斗都以当前共享生命上限的满血状态开始，冒险等级不改变九颗命源石。

## 六、命源石与失败

| 所在领域 | 精英或Boss失败损伤 |
|----------|--------------------|
| 第一领域 | 1颗 |
| 第二领域 | 2颗 |
| 第三领域 | 3颗 |

- 普通探索战败不损伤命源石。
- 精英或Boss失败先发放失败纽币，再结算碎石并继续流程。
- 累计损伤小于9时保留剩余石；恰好达到9时，九石在战败结算后汇聚为绝境石并继续前进。
- 单次损伤使累计值从9以下直接超过9，或形成绝境石后再次应当碎石，本轮回立即结束。
- 48兵战败直接结束，不检查剩余命源石。
- 第一与第二领域共六场危险战全败恰好累计9；第三领域三场危险战全败也恰好累计9。系统始终按实际累计值结算，不预设固定失败路线。

## 七、绝境石

- 绝境石形成后必须放入主角饰品栏并占1格；主角槽满时选择1件替换并丢弃。
- 绝境石使命潮自然充能速度+50%，全部伤害+50%；增伤覆盖直接伤害、毒伤和火伤。
- 绝境石可以在商店售出，但不能再次形成、不能继承。
- 绝境石与管理员的钥匙共同构成第九重《定川》结局条件，仍必须实际战胜复起后的48兵。

## 八、轮回继承

- 完整战胜48兵后，从结算时仍持有的常规饰品中选择1件继承。
- 特殊饰品、已售出、已丢弃、已放弃及结算时未持有饰品不能继承。
- 继承饰品在下一轮回第一次执行营地挖掘时作为必定候选取得。
- 失效蜥蜴断尾被继承时视为新副本，恢复保命次数。
