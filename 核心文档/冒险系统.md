# 《三乂川》冒险系统 v0.8

> 单轮回依次完成九域，每域包含3个探索节点与1场Boss；九域结束后挑战最终Boss“48兵”。

## 一、轮回流程

```text
选择身份 → 随机起始域与第一组伙伴三选一
→ 领域1（3个探索节点+Boss）→ 第二组伙伴三选一
→ 领域2（3个探索节点+Boss）→ 第三组伙伴三选一
→ 领域3—9（各3个探索节点+Boss）
→ 48兵 → 通关结算
```

- 起始域随机；每域结束后，从尚未进入的领域中展示3个候选并选择下一域。
- 每域的3个探索节点依次完成，随后进入该域Boss。
- 九域Boss无论胜败，轮回未终结时都完成本域并直接前往下一域，不重试。
- 战胜48兵才算完整通关；48兵战败立即结束轮回。

## 二、节点生成与品质

- 每域3个探索位置分别从战斗、商店、营地、事件、宝藏、随机六类中独立有放回抽取，允许同类节点重复。
- 每个节点独立投掷六面骰决定品质：1—3为普通，4—5为稀有，6为传说。铅骰子等最终点数修正适用。
- 品质提高战斗难度、奖励强度、商品等级权重或事件价值，不改变节点的基础功能。
- 随机节点进入后，从战斗、商店、营地、事件、宝藏五类中转换为一种并完整执行；其稀有与传说权重高于普通节点。
- 节点奖励随领域进程逐步提高。

## 三、节点功能与奖励

| 节点 | 规则 |
|------|------|
| 战斗 | 普通战斗胜利获得1张一级或二级卡与纽币；失败只获得纽币，且不损伤命源石 |
| 商店 | 提供购物、删卡与回收；见《商店系统.md》 |
| 营地 | 从挖掘、锤子、温存中选择1项；装备三务帐篷时三项各执行1次，顺序自选 |
| 事件 | 固定三选一，执行通用事件或所在领域专属事件 |
| 宝藏 | 公开展示“常规饰品+纽币”“一级或二级卡+纽币”“纯纽币”三包奖励，选择1包 |
| 随机 | 转换为前五类之一并提高高品质权重 |
| 九域Boss | 胜利获得1件饰品与纽币；失败只获得纽币，再按序位损伤命源石 |

- 九类一级卡在同一投放条件下等概率出现。所有商店与节点卡牌奖励只直接产出一级或二级卡。
- 三级普通卡只能通过取得同名新卡、选择升级现有二级同名卡获得。
- Boss饰品奖励可以是对应源神石或常规饰品。源神石也可由明确的领域事件提供；商店不出售源神石。
- 身份、伙伴和绝境石各自只有固定来源，不进入常规奖励池。
- 所有完成结算的探索节点提供冒险经验；温存提供大量冒险经验。

## 四、卡牌获取与锤子

- 取得普通新卡时，选择直接加入牌组，或消耗新卡令1张同名非满级普通卡升1级。牌组内既有同名卡不能互相合成。
- 一级升二级直接替换；二级升三级时，从所属类别9个三级分支中随机展示3个并三选一。
- 营地锤子选择1张普通三级卡，再从全部9个分支中纯随机展示3个不同分支；当前分支可以出现，也不保证出现新分支。选择当前分支仍消耗本次锤子。
- 伙伴牌、身份关联牌与负面牌不进入普通升级和锤子流程。

## 五、伙伴与冒险等级

- 九名伙伴随机分为3组，每组3人且全程不重复；开局、第一领域结束后、第二领域结束后各选择1人，最终形成主角+3伙伴。
- 九名伙伴默认开放，不受局外解锁影响。
- 单轮回使用全队共享的冒险等级与经验，不存在伙伴等级。
- 探索结算提供经验，营地温存提供大量经验；经验达到升级条件时提高本轮回共享生命上限。
- 冒险等级不影响九颗命源石。每场战斗仍以当前共享生命上限的满血状态开始。

## 六、九颗命源石

| 九域Boss序位 | 战败损伤 |
|--------------|----------|
| 第1—3个 | 碎裂1颗 |
| 第4—6个 | 碎裂2颗 |
| 第7—9个 | 碎裂3颗 |

- 非Boss战败不损伤命源石。Boss战败先发放失败奖励，再结算碎石并继续进入下一域。
- 累计局外损伤小于9时保留剩余命源石；恰好达到9时，九石在战败结算后汇聚为绝境石并继续流程。
- 单次损伤使累计值从9以下直接超过9，或形成绝境石后再次受到局外损伤，轮回立即失败。
- 命源石一般不回复；48兵战败不检查剩余命源石，直接失败。

## 七、事件总规则

- 每次事件固定展示3个选项并选择1项，不额外增加第四个离开按钮。
- 主要结构为“两个固定选项+一个六面骰选项”或“三个同类选项”。骰子选项必须提前公开1—6点的全部结果。
- 无合法目标的选项锁定，但事件生成时必须至少存在1个合法选项；保守离开若存在，也占用三项之一。
- 事件不能直接给予三级卡或直接升级现有卡；可以给予一级/二级同名新卡并进入正常入组或升级流程。
- 事件可以删除普通卡、同级变化一级/二级普通卡、交易常规饰品、给予任务标记或提供对应源神石的机会。
- 通用事件可在任意领域出现；领域事件只进入对应领域事件池且不保证出现。每个具名事件同一轮回最多结算一次。
- 领域事件只产生一次性剧情、选择与奖励，不给领域附加常驻战斗规则。

## 八、通用事件池

| 事件 | 结构 | 三项选择 |
|------|------|----------|
| 三悬礼 | 两固定+骰子 | 获得经验；提高共享生命上限；投骰取得纽币、卡牌、常规饰品或负面牌结果 |
| 活墙三问 | 三个同类 | 删除1张普通卡；将1张一级/二级普通卡变为同级随机卡；选择1张非满级普通卡并取得其同名新卡 |
| 偶藏室 | 两固定+骰子 | 随机取得一级常规饰品；支付纽币后从2件二级常规饰品中选1件；投骰决定饰品等级与代价 |
| 识命之颅 | 两固定+骰子 | 承担永久代价换纽币；取得一级/二级卡并加入负面牌；投骰进行资源交换 |
| 蒙面换客 | 三个同类 | 展示至多3件持有的常规饰品，每项分别交换1件随机常规饰品；特殊饰品不能交易 |
| 诅咒古卷 | 两固定+骰子 | 浅读取得小型卡牌收益；深读取得较高收益并加入负面牌；通读投骰决定高阶奖励与诅咒 |
| 沉没宝库 | 两固定+骰子 | 安全取得少量纽币；取得大量纽币并加入贪婪类负面牌；投骰决定财宝、空箱或附带代价的奖励 |
| 心念盛放 | 两固定+骰子 | 接受额外挑战换三级常规饰品；取得大量成长并承受永久负面；投骰结算高波动终局奖励 |
| 远行委托 | 三个同类 | 从战斗、商店、营地3个公开任务中选择1个，完成后自动兑现奖励 |

远行委托标记进入独立任务区，不属于卡牌且不占牌区：战斗任务要求赢得下一场普通战斗，商店任务要求完成下一次付费交易，营地任务要求完成下一项营务。完成后自动结算并移除；轮回结束时未完成标记失效。

事件给予源神石时遵守特殊饰品唯一规则；若结果指向本轮回已经取得过的源神石，改为三级常规饰品且不重掷。

## 十、继承与新手引导

- 战胜48兵后，从结算时仍持有的常规饰品中选择1件继承；特殊、已售出、已丢弃和已放弃饰品不能继承。
- 继承饰品在下一轮回第一次执行营地挖掘时取得。
- 首局依次教学共享生命与敌方意图、命潮与抽三打一弃二、护盾治疗毒火、同名升级与三槽饰品、伙伴蓄势3、Boss碎石与48兵终局。
