# 《三乂川》冒险系统 v0.4

> 单局结构：**九域长征——九域全体验，每域3节点+1Boss**；失败也有收益、连败能收菜的韧性经济。

---

## 一、单局宏观结构：九域长征

```
起始域（随机）→ [域1: 3节点+Boss] → 下一域三选一 → [域2] → …… → [域9] → 通关结算
```

- **每域固定4步**：3个探索节点 + 1场Boss战
- **起始域随机**：每局开局即有差异
- **域间三选一**：每通关一域，从剩余领域中给3个候选，选1作为下一域——候选**直接标注该域的源神石/流派倾向/特色**（我先去有大理石卡的域，还是先去有商店的域）——用信息换随机，选择即策略
- **战斗密度刻意偏低**：核心战斗=**9场Boss战**；探索节点中的战斗/精英少而精（期望3-5场）≈ 全局**12-14场**
- **时长**：战斗约10-12分钟 + 节点选择/事件/商店运营约13-18分钟 ≈ **25-30分钟/局**

## 二、域内结构：3节点 × 节点三选一

每个探索节点，系统从节点池中给3个候选，**三选一**进入：

| 节点类型 | 内容 | 出现权重 |
|---------|------|------------|
| **战斗** | 杂兵战（25-35s），基础奖励：纽币+卡牌三选一 | 中（密度刻意压低） |
| **精英** | 精英战（40-50s），掉领域主题牌+散件 | 中 |
| **事件** | 剧情/抉择事件（事件三选一），伙伴节拍挂载点 | 中 |
| **商店** | 单一综合店：混排货架（卡/装备/补给/饰品）+删卡+刷新+回购+命源石修复（仅传说档） | 中 |
| **营地** | 营务三选一：休整（回血+命源石）/淬火（升卡）/割舍（删卡）+稀有度档位营务（商店系统.md §二） | 低 |
| **奇遇** | 未知高方差（诅咒风险与高回报并存） | 低 |

- 每域3节点 ≈ **1场战斗 + 2次非战斗决策**——告别"全程打架"，运营决策占大头
- Boss战为域底固定第4步，Boss机制=该域源神石关键词的敌方镜像

### 2.1 节点稀有度（收益差分层）

节点类型保持六种纯净；**每个节点roll三档稀有度——普通 / 稀有 / 传说**。

> **关键定位：稀有度决定的是"收益差异"（奖励厚度/选择数/掉落概率），不直接锁物品品质**——品质上限由投放权重曲线与骰子门内浮动决定，后期普通档节点也可能出高品质物品。

| 节点 | 普通 | 稀有 | 传说 |
|------|------|------|------|
| **战斗** | 标准杂兵+基础奖励 | 带词缀增援+奖励加成 | 迷你精英配置+高额奖励 |
| **精英** | 1词条 | 2词条+掉散件概率提升 | 2词条+掉成装/三级分支卡概率提升 |
| **商店** | 货架3格 | 货架6格+稀有商品（三级分支卡/特殊饰品）出现率提升 | 货架9格+命源石修复开放 |
| **营地** | 基础营务三选一 | 事件营务出现（挖掘/献火/追忆/附魔）+遗落装备/饰品等优质选项 | 宝藏级营务（埋宝藏/稀有附魔/高档遗落装备） |
| **事件** | 标准事件池 | 奖励档位提升 | 稀有事件池（伙伴剧情/改变构筑的大事件）出现率提升 |
| **奇遇** | 标准高方差 | 回报上限提升 | 必出"奇遇级"收获但风险同步放大 |

- **出现率=骰子系统**：普通3/6、稀有2/6、传说1/6（六面骰：3面普通/2面稀有/1面传说）；域序修正=骰子门内浮动，7-9域传说面上调
- **信息前置**：节点三选一时直接显示类型+稀有度颜色（白/蓝/金）——用信息换随机，选择即策略
- 复杂度纪律：**新内容优先做进稀有度差分，而不是新增节点类型**——六类是上限

### 2.2 九域特色（每域仅此一项）

> 设计原则：**每域只挂一个特色，不做四件套**；特色分摊到不同轴上——有的给全局buff/debuff、有的给特殊地皮、有的触发惩罚风暴、有的是局外经济/事件收益。领域氛围（晶体/尸山/潮水等）由美术与事件文案承载，不占机制位。
> 本表为 v0.5 领域规则基准；数值强度统一受标准Build曲线约束。

| 领域 | 特色轴 | 特色内容 |
|------|--------|------------------------|
| **镜晶境**（金刚石·欧金金） | 局外·经济 | **晶矿值钱**：本域纽币获取+50%——此地不动刀兵，遍地是钱 |
| **荒脊岭**（大理石·沃夫冈） | 局内·地皮 | **山脊棱线**：障碍地皮（不可停留/穿越，≤2格）——灰色山脊直接改变布阵与走位 |
| **火尽山**（戏命石·异画师） | 局内·地皮 | **火焰地皮**：停留单位每20tick受2点火焰伤害——血红的石堆大地在烧 |
| **皮安城**（海克石·维克托） | 局内·buff | **充能管网**：命潮回复+25%——机械内脏泵送能量 |
| **松三原**（陶玉石·食欲饕） | 局外·事件 | **富矿平原**：本域事件节点奖励升一档（普通按稀有档给，稀有按传说档给） |
| **过明氹**（降解石·张学良） | 局内·debuff | **无预警**：只能看到敌方位置——具体数值、攻击意图（技能目标/红区提示）全部未知——纯白之野，杀机不显 |
| **啼亡堆**（科目石·板蓝根） | 局外·成长 | **册封**：本域战斗经验+50%——尸骨铺路，爬得更快 |
| **潮王原**（卡厄石·赵元任） | 随机·骰子 | **潮王保佑**：进入本域时掷骰一次，按档位获得随机祝福（普通=小额增益 / 稀有=中额 / 传说=大奖） |
| **平安京**（阴阳石·妖刀姬） | 惩罚·风暴 | **日落而息**：加时源神风暴提前10秒来临（45s→35s）——这座城不养拖局之人 |

> 特色轴分布：地皮×2、局内buff×1、局内debuff×1、局外×3、随机×1、惩罚×1——九域九种手感，无一重复。未设计地皮的域=默认普通地皮。

## 三、强度曲线与投放权重（软品质门）

> 不做硬性内容解锁门——**玩家成长节奏由玩家发挥**。三段只是投放权重的自然迁移与数值强度锚：

| 阶段 | 领域 | 投放权重倾向（非锁死） |
|------|------|---------|
| 一阶 | 第1-3域 | 一级卡、散件装备为主 |
| 二阶 | 第4-6域 | 二级卡、二级成装合成权重上升 |
| 三阶 | 第7-9域 | 三级分支卡、源神石（饰品格流派）权重上升；低级内容权重下降 |

- 低域小概率出高级物、高域仍有低级物；骰子门内浮动（±1域）保留：第3域尾可能提前摸到二级
- **难度锚 = 标准Build曲线**：设计"每域每节点预期队伍战力"基准线，作为敌人强度的调参锚
- 伙伴入队/牺牲节拍为**剧情节拍**（开局/一域Boss后/二域Boss后，伙伴.md），独立于强度曲线

## 四、命源石：生命、连败与韧性经济

> 主角的生命实体化为**命源石**——主角能量汇聚成的三颗石头。碎裂不是纯惩罚：**破石转化为力量**（连败增强）；三颗=连败次数上限；恢复手段提供生存保底。

### 4.1 命源石规则

- **初始与上限：3颗**
- **非Boss战败（普通/精英）**：不碎石头——按参与结算给低档收益（经验+少量纽币），胜利奖励错失，继续走
- **Boss战败 → 碎裂1颗**；可原地重整重打（敌人血量不继承）
- **恢复**：在恢复节点（营地等）或**战胜Boss**后，恢复1颗
- **碎至第3颗 = 进入背水状态**（获得第三档破石增益，命悬一线仍可翻盘）；**背水状态下战败 = 本局终结**——进入结算（见4.3）

### 4.2 破石之力：连败增强

每碎裂1颗命源石，队伍立即获得一层**破石增益**（**获得后本局内持续，恢复命源石不清除**）：

| 碎裂数 | 破石增益 |
|--------|---------------------|
| 碎1颗 | 全队攻击/生命+15%；下次商店全场-25% |
| 碎2颗 | 增益升至+30%；免费删卡1张或卡牌升级1次 |
| 碎3颗（背水） | 增益升至+50%；三级分支卡/特殊饰品 **三选一**——再输即终结 |

- 与战斗中"命运三选一"（单场背水一战）形成两层兜底：**单场靠命运，整局靠破石**
- 设计张力：石头是命也是buff——"要不要故意放水碎一颗换力量"成为可博弈选项；增益恢复后保留使该博弈更强，靠**3颗上限+背水再输即终结的风险**约束摆烂

### 4.3 局外结算（逸尘）

- 无论通关还是碎石终结，按**进度（域数+击杀+构筑完成度）**结算局外货币**逸尘**（源神石中逃逸出的尘土能量），用于局外成长（命纹树唯一消耗，详见局外成长.md）
- 核心：**每一局都有推进感**——输掉的局也在为下一局铺路

## 五、新手引导（首局教学域）

**首次游玩的第一个领域 = 教学域**：3个小节点+关底Boss全程脚本化引导

| 节点 | 教学内容 |
|------|---------|
| 小节点1（战斗） | 布阵 + 自动攻击/索敌基础 |
| 小节点2（战斗） | 手牌三选一（抽三打一弃二）+ 命潮消耗与回复 |
| 小节点3（营地/事件） | 装备佩戴（主副系/饰品）+ 营务三选一 |
| 关底Boss | 蓄能绝技释放 + 命源石规则（战败碎石演示） |

- 仅首局强制；二周目起教学域还原为正常随机节点
- 进阶机制（降费卡/破石之力/连败收割/图鉴）不做进教学，靠首局自然遇见时的轻量气泡
