# 《三乂川》冒险系统 v0.7

> 单局采用九域长征：每域3个探索节点与1场Boss；完成九域后挑战最终Boss“48兵”。九域共享同一战斗底层，以美术、事件、奖励倾向和Boss的源神石语言形成差异。

## 一、单轮回流程

```text
随机起始域
→ 领域1（3个探索节点+Boss）
→ 从剩余领域中三选一
→ ……
→ 领域9（3个探索节点+Boss）
→ 最终Boss“48兵”
→ 通关结算
```

- 每域固定3个探索节点和1场Boss。
- 起始域随机；每个领域结束后，从尚未进入的领域中展示3个候选并选择下一域。
- 九域Boss无论胜败，完成结算且轮回未终结时都直接进入下一域，不重试当前Boss。
- 第九域结束后进入48兵战。战胜48兵才算完整通关；战败直接结束本次轮回。

## 二、六类探索节点

| 节点 | 内容 |
|------|------|
| 战斗 | 分普通、稀有、传说三档；品质越高，敌人越难，胜利奖励越多 |
| 商店 | 购物、删卡、回收；购物区出售2张随机卡和1件饰品 |
| 营地 | 挖掘、锤子、温存三选一 |
| 事件 | 剧情与选择事件，可承载伙伴剧情和构筑交换 |
| 宝藏 | 直接展示3项奖励，选择1项获得 |
| 随机 | 从前五类中随机生成一种，并提高生成节点的品质 |

前三个探索节点从六类中生成；最后一关不参与随机，固定为该领域Boss。

## 三、节点品质

- 战斗、商店、营地、事件和宝藏均可拥有普通、稀有、传说三档品质。
- 品质提高该节点的难度、商品稀有度、奖励强度或事件价值，不改变节点的基础功能。
- 随机节点生成的实际节点品质高于同阶段的常规节点。
- 节点生成权重、具体奖励数量和价格统一由节点配置表与数值策划确定。

## 四、卡牌获取与成长

- 获得一张普通新卡时，玩家二选一：直接加入牌组；或消耗该新卡，令牌组内一张同名非满级卡升1级。
- 牌组内已经存在的同名卡不能彼此合成；没有新卡进入时，不能主动升级现有卡。
- 一级升二级直接替换；二级升三级时，从该类别9张三级分支中随机展示3张并三选一。
- 三级是普通卡最高等级。营地锤子只为普通三级卡重新随机3张分支并三选一，不改变卡牌等级。
- 商店删卡令一张可删除的普通卡直接从牌组消失。系统不存在卡牌降级和0级卡。
- 伙伴技能牌和绝技牌不进入普通卡的升级、锤子或删卡流程。

## 五、伙伴加入与成长

- 开局从3名伙伴中选择1名同行。
- 第一领域结束后选择第2名伙伴加入。
- 第二领域结束后选择第3名伙伴加入；伙伴不再牺牲，队伍扩为主角+3名伙伴。
- 每次伙伴加入及每次伙伴升级都会提高后续战斗的共享生命上限。
- 营地温存选择1名伙伴提升等级；参战也可推动伙伴升级。

## 六、九颗命源石

九颗命源石等同于9点局外生命，与局内共享生命完全分离。每场战斗都以当前共享生命上限的满血状态开始。

| 九域Boss序位 | 战败造成的局外伤害 |
|--------------|--------------------|
| 第1—3个Boss | 碎裂1颗命源石 |
| 第4—6个Boss | 碎裂2颗命源石 |
| 第7—9个Boss | 碎裂3颗命源石 |

- 非Boss战败不损伤命源石；战败节点结束后继续后续冒险。
- 九域Boss战败时先扣除对应命源石。累计局外伤害小于9时，保留剩余命源石并直接进入下一域。
- 累计局外伤害恰好达到9时，九石在战败结算后汇聚为饰品“绝境石”，触发背水一战；装备绝境石后继续进入下一域。
- 单次损伤使累计局外伤害从9以下直接超过9，或进入背水一战后再次受到局外伤害，本次轮回立即失败。
- 命源石在一般情况下不回复；只有明确写出例外的效果可以恢复。

## 七、饰品与继承

- 饰品分三个品质，每名角色最多携带3件，且没有额外背包。
- 九域Boss可能掉落所属源神石，也可能掉落常规饰品。
- 获得饰品时若没有空槽，只能放弃新品，或替换并丢弃一件旧饰品。
- 完整战胜九域并击败48兵后，可以从本轮回获得的可继承饰品中选择1件留给下一重轮回；未完整通关则不能留下饰品。
- 继承饰品在下一重轮回首次选择营地“挖掘”时必定取得；绝境石不能继承。

## 八、九域内容边界

九域名称、统治者、源神石归属和美术设定见《世界观.md》。领域不使用障碍地皮、隐藏位置、射程或范围红区，也不附加独立领域战斗效果；领域差异由美术、事件、奖励倾向和Boss行动池承担。

## 九、新手引导

首局第一领域依次教学：

1. 共享生命、敌方意图和行动进度条。
2. 命潮自然恢复与抽三打一弃二。
3. 护盾、治疗、毒伤穿盾与火伤减疗。
4. 同名新卡升级、商店删卡、营地锤子与饰品槽。
5. 伙伴绝技蓄势3及九颗命源石的Boss战败规则。

不教学布阵、射程、索敌、移动、格子范围、装备合成或卡牌降级。
