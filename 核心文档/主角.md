## 身份的局内落地

> **主角不做强制职业画像**（职业与装备.md §一）：属性面板统一中庸，战斗定位由玩家对局内自行构筑。
> 身份差异 = **初始卡组构成 + 特化流派倾向 + 身份专属饰品**（数值为方向性示例，数值阶段校准）。

| 身份 | 风格 | 初始卡组倾向 | 身份专属饰品（特化方向） |
|------|----------|---------|----------|
| 阿泰克 | 倾向激进进攻，忽视防御 | 攻击牌偏多 | **战狂之证**：全队攻击+10% |
| 蒂范德 | 优先保证防守，确保生存下去 | 护盾/buff牌偏多 | **铁卫之证**：全队减伤+5% |
| 拜冷斯 | 攻防均衡 | 攻防均衡 | **中庸之证**：攻击+5%、生命+5% |
| 贾克斯 | 武器系统特化 | 标准 | **武器大师之证**：开局携带1件随机散件 |
| 崔斯特 | 卡牌系统特化 | 战术牌偏多 | **卡牌大师之证**：开局往抽牌堆加入1张一级整备（开局多一次调度权） |
| 咪哈呦 | 源神石系统特化 | 标准 | **源神亲和之证**：开局随机获得1颗源神石（本局） |
| 葛朗台 | 纽币系统特化 | 标准 | **资产家之证**：初始纽币+100 |
| 普朗克 | 骰子系统特化 | 标准 | **量子之证**：每局骰子可重掷1次 |
| 艾德明 | 拥有未知能力 | 随机 | **管理员权限**：每局随机复制另一身份的专属饰品效果 |

## 身份解锁（局外成长.md §2.2）

- **初始开放**：阿泰克 / 蒂范德 / 拜冷斯（攻/防/平衡三个基础身份）
- **命纹树·角色枝解锁**：贾克斯 / 崔斯特 / 咪哈呦 / 葛朗台
- **成就解锁**：普朗克（单局骰子传说档触发3次并通关）/ 艾德明（不碎任何命源石通关一重轮回）
