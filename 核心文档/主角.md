# 《三乂川》主角设定

## 一、主角与身份

主角姓名由玩家设置。身份只决定初始卡组、身份专属饰品与解锁条件，不锁定局内职业；所有身份都可以通过公共卡、伙伴、源神石与常规饰品构筑任意体系。

未特别说明时，标准初始卡组为5张一级打击与5张一级防御。

## 二、九种身份

| 身份 | 初始卡组 | 一级身份专属饰品 | 饰品效果 |
|------|----------|------------------|----------|
| 阿泰克 | 5张一级打击、1张一级重击、4张一级防御 | 无 | 以更激进的初始牌组开局 |
| 蒂范德 | 5张一级防御、1张一级虚弱、4张一级打击 | 无 | 以更稳健的初始牌组开局 |
| 拜冷斯 | 标准卡组 | 平衡球 | 一级打击的伤害与一级防御的护盾提高25% |
| 贾克斯 | 标准卡组，另加入多兰击、多兰御、多兰潮 | 多兰剑、多兰盾、多兰戒 | 三件饰品分别维持一张强度对应二级打击、防御、能量的特殊卡；开局占满主角3个槽位 |
| 崔斯特 | 标准卡组，另加入1张一级整备和1张一级能量 | 命运牌匣 | 两张额外牌按普通卡处理，可以升级或删除 |
| 咪哈呦 | 标准卡组 | 共鸣晶 | 源神石提供的可量化增益提高25%；不改变触发条件、上限、次数或规则 |
| 葛朗台 | 标准卡组，另加入贪婪 | 聚宝契据 | 开局获得大量纽币，同时加入贪婪负面牌 |
| 普朗克 | 标准卡组；开局随机2张一级普通牌各执行一次横向锤子 | 铅骰子 | 所有六面骰在完成重掷、追投与契约选择后，最终点数+1，最高为6 |
| 艾德明 | 标准卡组 | 管理员的钥匙 | 没有效果，只占用主角饰品栏1格，作为挑战难度 |

## 三、身份关联牌

- **多兰击、多兰御、多兰潮**分别由多兰剑、多兰盾、多兰戒维持，不进入普通卡的升级、复制、删卡与锤子流程。
- 售出某件多兰饰品时，对应关联牌立即从牌组、手牌、抽牌堆、弃牌堆、消耗区和能力区移除。
- **贪婪**是永久惩罚型负面牌：不能主动打出；因常规弃置进入弃牌堆时降低命潮自然充能进度，随后继续循环。
- 崔斯特额外取得的整备与能量属于普通卡，遵守正常入组、升级、删除和锤子规则。

### 普朗克开局锤炼

- 初始牌组生成后，同时随机锁定2张不同的可锤炼一级普通卡，再依次结算。
- 每张从另外8个一级类别中随机展示3类，玩家选择1类，将目标变化为对应一级卡。
- 两张目标不可重选；第一次变化不改变第二张目标。伙伴牌、身份关联牌、负面牌和永恒牌不进入目标池。
- 该过程属于变化，不是获得或升级，不触发同名合成、永久入组或经济饰品。

## 四、身份饰品规则

- 身份专属饰品固定为一级，进入主角饰品栏并占用槽位。
- 阿泰克与蒂范德没有身份饰品，因此开局拥有3个空槽。
- 身份饰品属于特殊饰品：可以在商店售出，但同一轮回内不能再次获得，也不能继承到下一轮回。
- 售出身份饰品不会回滚已经结算的一次性收益；需要饰品持续存在的被动会立即停止生效。多兰饰品与关联牌按本文件第三节处理。

## 五、身份解锁

- 初始开放阿泰克、蒂范德与拜冷斯。
- 贾克斯、崔斯特与咪哈呦由命纹树角色枝解锁。
- 葛朗台在完整击败48兵时持有至少650纽币后解锁；聚宝契据开局额外获得220纽币。
- 普朗克在一次通关中至少3次骰出未经铅骰加值的原始6点后解锁；铅骰子的+1在事件允许的重掷与追投之后结算。
- 艾德明通过无命源石碎裂通关成就解锁。
- 九名伙伴全部默认开放，不属于身份解锁系统。
