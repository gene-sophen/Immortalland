# 《三乂川》角色美术

> 本文档为主角身份与伙伴的角色美术规范，独立于核心文档存放，不修改任何机制定义。
> 身份与伙伴机制遵循 `主角.md`、`伙伴.md`；人物小传遵循 `剧情与设定.md`；造型语言遵循 `美术风格.md`。
> 命名纪律与设定文档一致：现有名称全部保留。

---

## 一、总则

角色造型在岩彩水墨体系下的五条规则：

1. **剪影先行。** 64px 缩略下必须可辨。每名角色只允许一个主剪影记忆点（兵器、帽、轮廓），其余细节让位。
2. **一人一处石纹。** 角色身上恰有一处命定石之色的发光纹（伙伴=石纹，身份=随身器物），是全身上下唯一的彩色高饱和点。
3. **铁线描人，皴擦画衣。** 人物轮廓用铁线描，衣物肌理用皴擦与点苔，不设西式高光。
4. **色不过三。** 单角色配色 = 墨阶底 + 域/石色一主 + 辅色一，禁止第四种色相。
5. **战斗不站场。** 战斗界面中主角与伙伴不以立绘站场（战场留白给敌方与演出）——主角以"牌"存在，伙伴以头像与绝技特写存在。立绘的展示位在：编成界面、营地温存、图鉴、伙伴详情页。

补充三条生产纪律：

- **自然差异优先于符号差异**：九伙伴必须在年龄感、体型、脸型、肤色、站姿和重心上有真实差异，不能只靠发色与饰品区分。
- **器物必须可使用**：武器、帽、背篓、星仪和机关水滴要有可信的握持、承重、收纳与活动方式；漂浮物必须给出轨道或石力来源。
- **同名不等于同造型**：不得照搬其他商业作品中同名角色的服装、徽记、武器、发型组合或经典姿势；本作角色的识别必须来自石纹、九域经历和治川九艺。

> 设计理由：治川者不出手，出手的是九艺。战场只有敌人，我方以牌与潮的形态在场——这既是风格选择，也是小屏信息减荷的决定。

## 二、主角：治川者本体

主角本体（玩家命名）是所有身份的共用基底：

- **基底造型**：玄色直裰，袖口收窄（打牌的手不能有累赘），腰束一条川流纹素带。发色墨黑，无冠。剪影记忆点 = **负手而立的直裰轮廓与腰后斜挂的空剑鞘**——鞘是治川者的礼器，不出剑，以示"治而不杀"。
- **石纹位**：无。主角体内无石纹（他是铸堤人，不是堤），这是与九位伙伴的根本区分。
- **色彩**：全墨阶，唯一的色来自身份器物。

阿泰克的护腕与蒂范德的旧盾属于身份剪影道具，不是机制上的身份饰品，也不占饰品槽；界面上不得给它们“饰品”角标。两人没有身份饰品的规则保持不变。

### 川灵：叙事引导者

- **形态**：没有固定性别与年龄的人形水痕，腰部以下融入一条向下流动的淡墨川；脸只保留眉眼和鼻梁的最少线条，避免成为抢占玩家投射的具体角色。
- **旧伤**：胸口有一道向上的空白裂口，倒生命纹树的三条归根最终扎入此处。裂口不是石纹，不对应任何一枚源神石。
- **色彩**：平时只有清墨、淡墨与极少彩灿尘；每碎一颗命源石，轮廓减少一层墨阶。绝境石形成后不再完整显形，只以水纹和声音存在。
- **剪影点**：上半身像披长袍的人，下半身是三股汇成一股的水路。不得画成神仙、龙王、幽灵少女或有王冠的任务发布者。
- **展示位**：主菜单远景、领域三选一的水面倒影、碎石演出、命纹树背景和轮回结算；不占战斗头像或队伍位置。

### 九身份器物外化

身份的区分不靠换装，靠**随身器物**——器物即身份饰品的造型本体，在立绘、头像、编成界面中全程可见：

| 身份 | 气质一句话 | 器物与造型要点 |
|------|-----------|----------------|
| 阿泰克 | 先出手再讲理的游侠 | 双护腕缠赭红布条，直裰下摆撕短；器物=无（双腕即器物），姿态永远前倾 |
| 蒂范德 | 走一步看三步的老戍卒 | 肩背一面旧瓷青圆盾，盾面有修补锔钉；步伐沉，立绘重心最低 |
| 拜冷斯 | 讲"公平"二字的中人 | 衣分玄素两半，腰间悬平衡球——一枚黑白互衔的玉球，恒速自转 |
| 贾克斯 | 满世界收旧兵器的行商 | 多兰三件套全戴身上：剑负背、盾缚臂、戒戴指；背架高耸如货郎担，剪影最宽 |
| 崔斯特 | 相信运气胜过相信命的牌师 | 胸前悬命运牌匣，指间永远夹着一张背纹牌；斗篷内衬织满牌背纹 |
| 咪哈呦 | 听得懂石头说话的采石女 | 耳坠=共鸣晶，衣摆缀九色碎石纹（全角色唯一的多色，但粒小如苔点，不违规） |
| 葛朗台 | 把钱当命的老账房 | 聚宝契据卷轴贴身收藏，腰上钱箱以锁链拴在腕上——**锁链即"贪婪"的外化**；指上全是算盘茧 |
| 普朗克 | 跑过九域所有赌局的骰客 | 颈挂铅骰子（坠感要画出来，压得绳线下垂），披肩织六面纹；笑起来缺一颗牙 |
| 艾德明 | 不知自己在管理什么的管理员 | 旧制服，颈挂一把黄铜钥匙；全角色唯一"零石色"——器物无光、衣无任何彩色，剪影干净得反常 |

> 解锁叙事提示：艾德明的"无色"与普朗克的"铅骰"在图鉴轶闻中回收（铅骰是管理员的配重——此钩挂 `剧情与设定.md` 的命纹树与图鉴体系）。

## 三、九伙伴造型

> 人物背景以 `剧情与设定.md` 的伙伴篇为准，此处只做视觉外化。伙伴没有等级、品质成长或卡牌分支，因此每人只有一套正式基础造型；变化来自表情、姿态、技能演出和是否装备专属饰品，不使用“一至三阶”外观。

### 查莉娅 · 大理石纹（砺）

- **石纹**：缠手绷带下的小臂外侧，铁锈红，随充能亮度渐强。
- **造型**：高马尾、蜜糖色肌肤、运动背心与岩灰训练长裤，双手缠旧绷带；专属饰品“查莉娅的哑铃”横背在肩后，岩铃比常规器械更厚重。剪影点 = 高马尾与横置巨型哑铃。
- **色彩**：蜜糖肤色与玄灰为底，铁锈红只落在石纹、绷带边与岩铃裂纹。
- **演出钩子**：充能护盾 = 岩片自地面飞起拼合成甲；绝技"重力喷涌" = 全场岩屑向敌聚拢一瞬，再炸开。

### 奥丽莎 · 金刚石纹（固）

- **石纹**：胸腔的琥珀核心内部，晶白火彩，是金身的光源。
- **造型**：奶白色圆润装甲、机械短发与两根情绪天线，关节保留皮安城老式铆钉；面部有清晰而克制的人形表情，不使用无脸表盘。专属饰品“奥丽莎的琥珀核心”直接构成胸腔视觉中心。剪影点 = 圆肩、短发天线与核心圆光。
- **色彩**：奶白 + 玄灰，琥珀金与晶白火彩集中在核心。
- **演出钩子**：金身 = 体表晶化镀层，受击迸光谱碎闪；蓄能冲击 = 核心光缩成一点再喷出，全场最"直"的一道光。

### 乐芙兰 · 科目石纹（序）

- **石纹**：斜戴高礼帽的帽徽，青金色，锁链出手时逐环点亮。
- **造型**：暗紫短发、斜戴高礼帽、燕尾服短外套与高腰长靴；披风内衬以极淡书页纹和幻影扑克混排。专属饰品“乐芙兰的幻术礼帽”就是主剪影。剪影点 = 斜高帽、燕尾与垂地锁链。
- **色彩**：墨与暗紫为底，青金石纹和琉璃金链字为焦点。
- **演出钩子**：锁链由书页文字与幻影牌边凝成，缠上敌人时字沿链移动；成功打断时所有链字同时翻为“判”。

### 拉克丝 · 陶玉石纹（流）

- **石纹**：星形法杖中央的温润玉芯，玉青光沿星芒流转。
- **造型**：金色高马尾、蓝白礼裙、辩士绶带与星形法杖；礼裙轮廓轻而端正，避免陶赭大面积覆盖人物。专属饰品“拉克丝的辉光法杖”全程可见。剪影点 = 高马尾、星杖与斜披绶带。
- **色彩**：绢白与浅蓝为底，玉青石纹为高饱和锚点，陶赭只用于细小矿釉扣件。
- **演出钩子**：曲光屏障 = 光自顶珠折出弧面护住全队；终极闪光 = 唯一允许压暗全场的白光，释放前她先微微欠身——辩士的礼。

### 拉露恩 · 卡厄石纹（变）

- **石纹**：后颈，混沌紫，切换武器时按当前形态偏转色相。
- **造型**：银白长发、轻质白裙、幽蓝月环耳坠，背后悬浮三枚月石武器；专属饰品“拉露恩的月环武匣”表现为一圈不闭合的月环轨道，而非额外第四武器槽。剪影点 = 长发、月环与三枚浮空武器。
- **色彩**：月白与幽蓝为底，混沌紫/橙红只在切换状态时沿武器棱面流动。
- **演出钩子**：三武器切形 = 兵器出手瞬间色相整体偏转（高伤橙/吸血紫/减速蓝紫）；绝技"月相盛放" = 背环满月一次盈满。

### 倪克斯 · 阴阳石纹（衡）

- **石纹**：眉心，玄素双色各占一半，形态切换时对调。
- **造型**：黑色长直发、星夜渐变长裙与高立领，手持半玄半素的昼夜星仪；两种形态只改变裙摆光带、瞳色和星仪朝向，不做全身瞬间换装。专属饰品“倪克斯的昼夜星仪”是状态读取中心。剪影点 = 黑长直、高立领与星仪圆盘。
- **色彩**：玄/素双主色 + 青灰衔接线，星夜蓝只作低饱和过渡。
- **演出钩子**：昼夜切换 = 一道光扫过星仪与裙摆，玄素光带对调但基础服装不变；血量越低，星仪转得越快，玄素边界越模糊。

### 朱庇特 · 戏命石纹（终）

- **石纹**：咽喉处一点血光（"伶人的命门"），开嗓即亮。
- **造型**：深色舞台礼装与火尽山戏服结构结合，肩饰黑玉薄片如凝固火焰，专属饰品“朱庇特的终幕火种”藏在胸袋而非袖底。剪影点 = 火焰形肩饰、长礼服后摆与大开大合的谢幕手。
- **色彩**：墨黑 + 血光 + 冷银辅。
- **演出钩子**：火伤 = 火星拖戏腔般的弧线；鼓舞延时 = 身上黑玉片逐一点亮如幕灯；绝技自带一个极短的亮相帧。

### 芙宁娜 · 海克石纹（械）

- **石纹**：潮律礼帽的帽针，冰蓝色，与全队命潮同频呼吸。
- **造型**：水蓝卷发、潮律礼帽、舞台礼服式机关裙，裙摆内衬可见微型齿轮；周身悬三枚机械水滴。专属饰品“芙宁娜的潮律礼帽”承担最稳定的识别。剪影点 = 卷发、礼帽与悬浮水滴构成的三角。
- **色彩**：冰蓝 + 电流青 + 绢白辅。
- **演出钩子**：命潮治疗 = 水滴坠入我方血条激起小潮；绝技 = 三枚水滴连成潮环绕场一周。

### 纳西妲 · 降解石纹（蚀）

- **石纹**：掌心，尘金色，施术时如搓起一撮金尘。
- **造型**：白绿渐变短发、叶片纹样的植物质感服装，身后背一只装有毒草与净土新芽的小篓；赤足，走过的地方留淡绿芽痕。专属饰品“纳西妲的净土新芽”固定别在篓沿。剪影点 = 叶形发梢、宽大叶袖与背篓新芽。
- **色彩**：盐碱白 + 叶绿低饱和底，尘金石纹为高饱和锚点。
- **演出钩子**：毒伤 = 敌方脚下生枯白斑蚀；生灭结算 = 枯白处瞬间抽芽再枯萎一次——**死与生同帧**。

## 四、角色在 UI 中的体现

### 头像规范

- 战斗伙伴位头像 96px：只取**面部 + 石纹位**，石纹角标压右上角（12px 圆点，命定石色）；蓄势点为三枚刻痕在头像下缘，满蓄时石纹角标开始呼吸。
- 图鉴/列表头像 64px：剪影辨识的最低验收线——所有角色以此尺寸过审。

### 展示位分级

| 界面 | 角色呈现 | 说明 |
|------|----------|------|
| 战斗 | 伙伴头像列 + 绝技剪影特写条 | 不站场，见总则第5条 |
| 编成/开局三择 | 半身立绘 + 器物特写框 | 身份器物单独给一格特写 |
| 营地·温存 | 伙伴全身立绘 + 火堆 | 唯一展示全身动态的场景 |
| 图鉴屏风 | 正式立绘 + 表情/技能演出切片 | 不展示不存在的伙伴阶位 |
| 伙伴详情页 | 立绘 + 小传（竖排） + 技能卡 | 点击头像任意处进入 |

### 状态视觉总表

伙伴没有阶位外观。局内只使用三类临时状态变化：**技能可用**（石纹短亮）→ **蓄势进行中**（头像下方1—2枚刻痕点亮）→ **绝技就绪**（三枚刻痕全亮、专属饰品呼吸光）。状态结束后必须回到基础造型，不能让临时演出看起来像永久升级。

绝技就绪只表示绝技牌已经置于抽牌堆顶，不能点击头像直接释放。头像点击默认打开伙伴详情；只有奥丽莎已经主动打出“蓄能冲击”并处于蓄力中时，头像才临时变成“提前释放”按钮，并显示蓄力进度环。

### 表情与姿态切片

每名主角身份与伙伴至少交付以下切片，以减少剧情中反复使用同一张立绘的僵硬感：

| 类型 | 数量 | 用途 |
|------|------|------|
| 基础表情 | 4 | 平静、警觉、喜悦、受挫 |
| 关系表情 | 2 | 温存专属的放松、个人秘密被触及时的回避/认真 |
| 技能姿态 | 1 | 技能牌画芯与详情页动作参考 |
| 绝技姿态 | 1 | 绝技特写条和绝技牌画芯 |
| 受击/绝境反应 | 1 | 碎石、绝境石形成与近败剧情 |

表情切片优先更换眉眼、嘴角和头部角度，不用大幅改变脸型。姿态切片保持服装、器物与石纹位置完全一致。

### 角色关系构图

- 主角与伙伴同框时，主角永远留出可供玩家投射的半步距离，不用拥抱、牵手等强制关系姿态作为通用图。
- 伙伴双人图优先表现“共同处理一件事”，例如修理星仪、抄录锁链文字、照看净土新芽，而不是并排看镜头。
- 九人群像按石性形成三组三角：固/砺/流负责前景体量，序/械/衡负责中景秩序，终/蚀/变负责后景动势；不能按人物身高简单排队。
- 真结局群像中，本轮同行三人靠近主角，其余六人由九域共鸣进入远景，既体现本轮选择，又不否认全员结局。

## 五、角色生产与一致性

### 设定锚点表

每名角色建立一张不可漂移的锚点卡，至少包含：正面/侧面/背面、身高比例、肤色与发色取样、器物三视图、石纹位置、左右手使用习惯、三种禁画错误。后续头像、卡芯和事件插图必须引用同一锚点卡，不以单张AI生成图反推设定。

### 交付顺序

1. 黑色剪影九宫格，先审主记忆点与体型差异。
2. 墨阶设定稿，审衣物结构、承重与动作范围。
3. 石色小稿，审唯一高饱和锚点和色弱识别。
4. 正式立绘与表情切片。
5. 头像、卡芯、绝技特写等派生裁切。

### 禁止漂移

- 不改变角色既定年龄感、体型、肤色与石纹位置来追求“更好看”。
- 不把专属饰品画成不占槽的第二件同名物；卸下饰品后的立绘应有对应无饰品切片或遮罩方案。
- 不为伙伴制作不存在的等级、品质、觉醒或分支外观。
- 不用石色全身发光表达绝技就绪；只允许石纹、饰品与局部轮廓短时增强。
