# 《三乂川》饰品系统

> 常规饰品共59件。每件拥有固定品质、来源、机制职责与叠加边界；品质不是升级链。

## 一、品质阶级

品质不是简单的数值倍率，而是改变一件饰品能够承担的构筑职责。

| 品质 | 设计职责 | 典型复杂度 | 期望感受 |
|------|----------|------------|----------|
| **一级** | 提供启动资源、单一反制或一个清晰的小循环 | 一个主要触发，最多一个追击条件 | 拿到就有用，并提示一种可继续构筑的方向 |
| **二级** | 成为稳定引擎或把两个系统接在一起 | 累计、条件转化、跨节点经营或双向联动 | 会改变选牌、出牌顺序或路线选择 |
| **三级** | 定义一条Build、突破常规资源交换或显著改变冒险规划 | 可持续成长、规则改写、保命、复制、全营务等 | 围绕它构筑值得，成熟后能够打出明显高潮 |
| **源神石** | UI仍为三级，但属于命定级强度 | 直接完成对应流派的质变闭环 | 与成熟Build匹配时高于常规三级，详见 `源神石效果.md` |

一级不等于“白板数值”。三级也不要求堆叠多个句子；规则改写本身可以简洁而强大。

## 二、获取来源

| 标签 | 获取边界 |
|------|----------|
| **通售** | 商店、宝藏、Boss、通用事件和普通奖励均可出现 |
| **商售** | 只在商店出售，刷新可寻找；用于经营、交易和路线规划 |
| **掘藏** | 只由营地挖掘获得；角色等级提高高品质结果权重 |
| **战利** | 由指定普通怪、特产怪或精英掉落；进入战斗前公开 |
| **域产** | 只在指定领域的战斗、事件或宝藏中取得 |

- 战利与域产可以并列，表示只由该领域的指定敌人产出。
- Boss常规饰品奖励从通售池、所在领域域产池及已公开战利池中生成；源神石另走特殊奖励判定。
- 来源受限不额外提高战斗强度，而是提高可追求性和叙事归属。
- 59件常规饰品全部可以出售和继承；身份、伙伴、源神石、绝境石继续属于特殊饰品。

## 七、叠加与安全边界

1. 同一角色不能装备同名饰品，不同角色的同名常规饰品允许叠加；各副本独立计数。
2. 多件同类触发按“先固定值、后比例、再规则改写”结算。两个规则改写冲突时，以更具体、来源更稀有的效果优先。
3. 追加伤害、额外结算、复制主效果默认不再次触发产生它们的同名条件，防止指数递归；其他正常联动照常发生。
4. 获得时效果每个副本只触发一次；换装不重复。蜕变、继承取得和重新获得失效断尾均视为新副本。
5. 构筑已经成功时允许多个二级、三级饰品形成高强度线性叠加，不因为“可能很强”给所有效果添加低次数上限。
6. 百分比生命上限按基础上限与等级增长计算，不重复读取其他百分比饰品已经放大的结果；多个百分比来源加算后统一乘一次，避免指数膨胀。

## 八、数值配置接口

各品质的固定值、百分比、累计门槛、售价与回收价读取统一配置，不改变59件饰品的名称、品质、来源和机制职责。数值校准满足：一级可形成方向，二级可稳定驱动，三级可围绕构筑；同一Build同时取得三级核心饰品与对应源神石时，允许形成显著强势的后半程体验。
