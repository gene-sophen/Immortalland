# 《三乂川》饰品系统 v0.7

> 饰品是v0.7唯一的角色携带物。系统不再使用散件、主副系成装、装备轴或装备合成。

## 一、携带规则

- 主角与每名伙伴分别拥有3个饰品槽位。
- 饰品没有额外背包；获得新饰品而所有可用槽位均满时，只能放弃新品，或选择一件旧饰品替换并丢弃。
- 已持有饰品可以在主角与伙伴之间换装；伙伴专属饰品也可以卸下。
- 饰品效果默认由我方全队共享。卡面可以额外限定“由特定角色携带时生效”，不满足携带者条件时该项效果不生效。
- 饰品分为三个品质；品质越高，效果越强。品质名称与具体强化内容由对应饰品卡面统一定义。

## 二、饰品类型

| 类型 | 规则 |
|------|------|
| 常规饰品 | 由商店、挖掘、宝藏、事件及Boss奖励提供 |
| 源神石 | 九域Boss可能掉落的流派饰品，使用《源神石.md》的九套体系语言 |
| 伙伴专属饰品 | 每名伙伴自带1件，占用该伙伴的饰品槽；视为伙伴被动，可随伙伴升级提高品质 |
| 身份专属饰品 | 用于表达主角身份差异，占用主角饰品槽 |
| 绝境石 | 九颗命源石恰好全部碎裂时形成的特殊饰品，固定在主角饰品栏生效 |

## 三、获取、替换与回收

- 商店购物区出售1件饰品；商店品质越高，出现高品质饰品的概率越高。
- 营地挖掘获得1件随机饰品或一笔纽币。
- 九域Boss可能掉落所属源神石，也可能掉落常规饰品。
- 只有商店可以回收饰品并换取纽币；其他场景不能出售。
- 超出容量的饰品只能放弃或替换丢弃，丢弃不返还纽币。

## 四、伙伴专属饰品

- 伙伴加入时携带自己的专属饰品，并占用该伙伴1个饰品槽。
- 专属饰品可以卸下、重新装备或由其他饰品替换。
- 伙伴共同参战及营地温存可以提升伙伴等级；专属饰品按伙伴成长节点提高品质并强化被动。
- 专属饰品不改变伙伴技能牌和绝技牌的牌区保护规则。

## 五、绝境石

- 九域Boss战败结算使累计局外伤害恰好达到9时，九颗命源石汇聚为绝境石并触发背水一战。
- 绝境石没有强制携带者条件，但固定在主角饰品栏生效并占用1格；其增益由我方共享。
- 若主角3个饰品槽均满，玩家必须选择1件主角当前饰品替换并丢弃，再装备绝境石。
- 绝境石只在主角饰品栏生效，不能带入下一重轮回。

## 六、轮回继承

- 完整击败九域Boss并战胜最终Boss“48兵”后，可以从本轮回获得的可继承饰品中选择1件保留到下一重轮回。
- 未完整通关不能保留饰品；绝境石不能成为继承对象。
- 继承饰品不会在下一轮回开局直接装备，而是在第一次选择营地“挖掘”时必定取得。
