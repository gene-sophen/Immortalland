# 版本工作区说明

本目录只存放当前正在设计、尚未整体拍板的版本内容。每个版本使用独立子目录，版本内的规则、数值、美术、剧情、UI和生产清单放在同一目录中，避免草案散落到根目录或核心文档。

## 约定

1. 新版本开始时建立 `vX.Y/` 子目录，并首先创建 `改动内容vX.Y.md`。
2. 讨论中的改动先写入该版本目录；同一主题内容较多时建立独立文件，并由改动记录引用。
3. 未整体拍板前不修改 `../核心文档/`。
4. 整体拍板后，先把可执行、无分歧的规则同步到核心文档，再提交版本。
5. 版本结束后保留其最终改动记录；过程稿、过期备忘和被替代方案移入 `../弃置文件/历史版本记录/` 对应版本目录。
6. `../参考资料/` 是跨版本研究库，不随单一版本移动。
7. 文件移动后必须检查相对链接；禁止让工作稿反向成为核心规则来源。

v0.10已定稿并写入核心文档；最终改动记录与完成审计保留在 `v0.10/`，过程稿封存于 `../弃置文件/历史版本记录/v0.10/`。下一策划版本尚未建立。
