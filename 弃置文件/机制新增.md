# 《三乂川》机制新增与优化汇总 v1.1

> 本文件汇总设计讨论中**新增或优化**的元层机制（战斗机制本身见《战斗.md》），按系统分类。
> 来源标注：【大巴扎】=大巴扎研究启发；【修正】=对既有设计缺陷的修正；【优化】=既有系统的增强。
> v1.1 拍板：技能体系统一为全部入卡组、四层牌池废弃改两层、命运三选一v2、圆满改独特奖励、品质门对齐九域三段。**全部待拍板项已确认，见§九拍板记录。**

## 一、卡牌系统修订

### 1.1 两层牌池结构【v1.1修订：四层牌池作废】

| 层 | 内容 | 出现规则 |
|----|------|----------|
| 公共池（12底卡三级阶梯） | 战斗语法、所有流派地基 | 任何奖励都可能出现（详见卡牌系统.md §二） |
| 角色技能卡 | 主角与伙伴的技能①②+绝技+分支变体，绑定角色 | 随角色入队/升级入组；不进公共池、不可删除 |

> 旧四层结构（公共牌池20张/职业牌池/招牌牌/身份牌）废弃：职业牌池与身份牌概念并入角色技能卡。

### 1.2 卡组构成修订【修正】

- **基础攻击/防御牌移出卡组**：普攻由自动战斗承担；伙伴差异由"自动行为画像"（攻击间隔/射程/攻速/暴击）承载
- **卡组构成与获取**：目标厚度12-18、常规获得制无硬上限、删卡服务软纪律——详见卡牌系统.md §五

### 1.3 端口化词库【大巴扎】

所有卡牌/关键词归入五个端口，**设计新卡先定端口再定效果**：

| 端口 | 内容 | 备注 |
|------|------|------|
| 输出端 | 攻击牌、灼烧、中毒、暴击 | |
| 防御端 | 护盾、治疗、减伤 | |
| 运转端 | 充能、专注、连击、回收、迟缓/禁足 | 作用于能量轴与敌方行动轴 |
| 经济端 | 纽币相关 | 降解石系 |
| **空间端**（独有） | 移动、地形、嘲讽操控、射程 | 棋盘赋予的第四维度，核心卖点 |

配套纪律：绝技/技能卡按"终端牌"设计——**需求端口而非需求固定牌**（如金克斯绝技需求"移动次数"这一运转端口）；9种源流各自归属端口，注入即改变卡牌端口角色。

### 1.4 行为标签库（6个）【优化】

| 标签 | 效果 |
|------|------|
| 固有 | 每场战斗初始手牌必含（如主角签名卡） |
| 消耗 | 每场战斗限X次（原"打出后移除"的实时化） |
| 终极 | 施放后清空命潮条（一波流按钮） |
| 连击 | 队友施放技能牌时触发（引擎层每秒≤3次兜底） |
| 回收 | 打出后回到待抽区而非弃牌堆（限次数） |
| 垃圾 | 0费无效果，打出即弃（0级牌） |

### 1.5 "战斗成长"词条【大巴扎】

新增词条类：数值加成仅本场战斗有效（如"本战斗中每次造成伤害+1攻"），与永久成长（科目石传说装）组成双轴；嗜血/科目石流派的核心引擎。

### 1.6 投放权重：九域三段软门【大巴扎】【修正】

> 品质门**软化**（冒险系统.md v2.1）：不做硬性内容解锁，三段仅为投放权重倾向；玩家成长节奏由玩家发挥。

| 阶段 | 投放权重倾向（非锁死） |
|------|------|
| 一阶（1-3域） | 一级卡、散件装备为主 |
| 二阶（4-6域） | 二级卡、合成件权重上升；**构筑转型期**（与伙伴入队/牺牲剧情节拍重叠） |
| 三阶（7-9域） | 三级分支卡、源神石权重上升；低级内容权重下降 |

**骰子修正：骰子在门内浮动**——低域小概率出高级物、高域仍有低级物。
（与冒险系统.md §三对齐；卡级术语统一为一级/二级/三级，旧"一星/二星/三星"说法作废。）

## 二、伙伴系统

### 2.1 伙伴战斗力两层表达【v1.1修订】

| 层 | 内容 | 形式 |
|----|------|------|
| 本体层 | 普攻、属性、战场被动、自动行为画像 | 非卡牌 |
| 技能卡层 | 技能①②+绝技+分支变体，随等级解锁入卡组 | 技能卡 |

> 旧"职业层/招牌层"并入技能卡层（四层牌池废弃）。

### 2.2 技能卡解锁节奏（1/3/6/9级）【v1.1修订】

| 等级 | 解锁 | 定位 |
|------|------|------|
| 1级（入队） | 技能①入卡组 | 身份名片 |
| 3级 | 技能②入卡组 | 机制核心（联动源流/棋盘/色相） |
| 6级 | 绝技卡入卡组（蓄能制，0命潮，战斗.md §六） | 人设顶点 |
| 9级 | **圆满：专属涂装 + ①②各开放第4个「圆满分支」**（独特奖励，非数值放大） | 羁绊终极奖励 |

加入等级保底：开局伙伴1级、一域后加入3级、二域后替换者5级——**牺牲者绝技已点亮 vs 替换者未点亮，落差即痛感**。

### 2.3 技能卡规则【v1.1修订】

- 技能卡**绑定角色**：不进公共池、不可删除（卡牌系统.md §3.2）；原"不可移除只能降级"保护规则随技能带方案一并作废
- 伙伴阵亡：其技能卡（含绝技）退化为0费垃圾卡（战斗内）；战后复活恢复
- 伙伴牺牲（二域Boss后剧情）：技能卡随她平静离场（化入源神石）——"收缩→重建"心跳保留

### 2.4 绝技设计三红线【新增】

1. **蓄能制**：触发条件按角色个性化（打出技能卡/普攻/承伤/暴击……），不走时间轨
2. 0命潮施放，蓄能即成本
3. **表达人设而非放大数值**：遮住名字能认出是谁的招

## 四、成长与升级

### 4.1 每级属性三选一【大巴扎】

升级时除固定成长（攻+2/血+5）外，从攻+3/减伤+5%/血+8中三选一（减伤5%步进、上限50%，见职业与装备.md v2.2）——同级不同命，伙伴成长个性化。
（3/6/9级仍为源流三选一，不叠加。）

### 4.2 等级与里程碑

等级上限9（九数）；3/6/9级 = 源流三选一 + 伙伴技能卡解锁（见2.2），升级成为庆典时刻。

## 五、构筑安全网

### 5.1 命运三选一 v2【大巴扎】【修正】

主角受到致命伤害时触发（**每局限1次**）：掷骰定档（普通/稀有/传说影响数值强度）→ 三轴交易三选一：

| 选项 | 即时救命 | 持续增益 | 长期代价 |
|------|----------|----------|----------|
| ① **背水**（战斗轴） | 生命锁1点+全队满护盾 | 本局主角攻击+25% | 命源石本局不可修复 |
| ② **典当**（经济轴） | 复活至75%生命 | —— | 消耗全部纽币（押上全部身家换命） |
| ③ **逆命**（构筑轴） | 复活至50%生命 | 本局命潮上限+1（3→4） | 牌组注入2张诅咒「命运之债」 |

- 卡厄石持有者可重掷一次档位
- 设计纪律：每个选项 = **即时救命 + 持续增益 + 长期代价**，不做纯收益——救的是这一场，赌的是这一局
- 定位：逆风补偿的仪式感 + 难度设计的安全阀（设计师可按"玩家多一条命"调难度）

### 5.2 引擎层保险丝（规则索引）

- 防循环：同名触发每tick限1次、每秒限3次（战斗.md §4.1）
- 防拖局：加时亢奋+源神风暴（战斗.md §7）
- 防贬值：翻倍类效果必带"消耗"

## 七、开发侧机制

### 7.1 标准Build曲线【大巴扎】

设计"每领域每节点的预期队伍战力"基准线，作为敌人强度的调参锚——大巴扎用同日快照保证PvP公平，我们用同一条曲线保证PvE难度公平。

### 7.2 平衡方法论

数据驱动：原型期即埋统计点（三选一选取率、卡牌施放率、伤害贡献、胜率关联）；单机肉鸽组合过强可容忍，恶性组合按格补丁。
