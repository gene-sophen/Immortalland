## 卡牌系统

### 卡牌基本结构

| 属性 | 说明 |
|------|------|
| 名称 | 卡牌名称 |
| 品质 | 一星/二星/三星 |
| 费用 | 1-3费 |
| 类型 | 攻击/防御/增益/减益/战术 |
| 基础效果 | 一星时的效果（包含所有机制） |
| 二星强化 | 数值提升 |
| 三星源流 | 注入源流后追加效果 |
| 标签 | 源流标签（三星后才有） |

### 卡牌品质路径

> **一级定义机制，二级提升数值，三级注入源流（唯一分支点）**

| 品质 | 变化 | 玩家操作 |
|------|------|----------|
| **一星** | 获得基础效果 | 无 |
| **二星** | 数值提升（线性增强） | 自动升级，无分支 |
| **三星** | 注入源流，获得流派效果 | **三选一**：从3种源流中选择1种 |


**升级方式**：同名合成 或 升级卷轴
### 5.8 降级系统（两级降级）

```
三星 →（降级1次）→ 二星 →（降级1次）→ 一星 →（降级1次）→ 0级垃圾牌 →（降级1次）→ 消失
```

**0级垃圾牌**：0费、无类型、无效果、打出进入弃牌堆

### 5.3 卡牌类型（6种）

| 类型 | 功能定位 | 示例 |
|------|----------|------|
| 攻击| 直接造成伤害 | “造成X点伤害” |
| 防御| 提供护盾或减伤 | “获得X点护盾” |
| 增益| 施加正面效果 | “本回合攻击+2” |
| 减益| 施加负面效果 | “敌人本回合伤害-2” |

| 战术| 特殊功能 | “移动英雄1格”、“抽一张牌” |

### 5.9 全局源流池

| 规则 | 说明 |
|------|------|
| 共享机制 | 全队共享一个公共源流池 |
| 获取方式 | 角色升级时三选一获得 |
| 注入规则 | 三星卡牌从全局源流池中抽取3种供选择 |
| 上限规则 | 每个英雄最多拥有3个源流（含重复叠加） |
| 叠加规则 | 同源流可叠加，效果累加；不同源流共存 |
