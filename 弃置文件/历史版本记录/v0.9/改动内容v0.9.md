## 四、详细设计记录

### v9-D1 三领域轮回与节点选择

#### 1. 轮回主流程

```text
启程 → 选择主角身份
→ 从未探索领域中随机展示3个，三选一
→ 进入领域并执行该领域16次冒险
→ 再从剩余领域中随机展示3个，三选一
→ 第二领域16次冒险
→ 第三次领域三选一 → 第三领域16次冒险
→ 最终Boss“48兵” → 轮回结算
```

- 一次轮回只进入3个不同领域，未被选择的6个领域本轮回不再出现。
- 三轮伙伴候选仍将九名伙伴随机分成3组，每组3人且全程不重复，最终形成主角+3名伙伴。
- 每个领域依次执行：**伙伴三选一 → 4次节点探索 → 精英三选一并战斗 → 4次节点探索 → 精英三选一并战斗 → 4次节点探索 → 固定领域Boss战**。
- 伙伴选择计为1次冒险；12次节点探索、2场精英战、1场Boss战各计1次，因此每个领域固定16次冒险。
- 三个领域合计48次冒险；48兵是完成48次冒险后的最终战斗，不计入“48次冒险”的编号。
- 每次节点探索从战斗、商店、营地、事件、宝藏、随机中抽取3个不同类型并同时展示，玩家选择其中1个进入。同次不重复，不同次允许重复。
- 每次精英遭遇在战斗前展示3名具体精英，玩家先查看敌方机制与公开掉落，再选择1名进入战斗。
- 每个领域的关底Boss固定为该领域Boss，不进行Boss三选一。

#### 2. 替代关系

- 替代v0.8“九个领域全部探索、每域3个节点+Boss”的长征结构，并替代v9-P1的“每域15个随机节点+Boss”内部节拍。
- 原先域间从剩余领域三选一的规则保留，但只执行3次领域选择。
- 命源石不再只读取Boss序位；精英与Boss战败统一读取所在领域的1/2/3颗固定损伤，详见v9-D12。

### v9-D2 节点奖励、商店与事件优化

#### 1. 节点奖励

- 战斗节点胜利必定获得1次卡牌奖励与1次纽币奖励；战斗失败继续沿用只获得纽币的规则。
- 宝藏节点固定展示3件具体常规饰品，玩家选择1件，并额外获得纽币；不再使用“饰品+纽币、卡牌+纽币、纯纽币”三类奖励包。
- 奖励仍随角色等级、节点品质与轮回推进提高，但三级普通卡继续只由同名升级产生。
- 领域特产怪与特殊掉落怪可以拥有公开的固定或定向掉落表，使战斗节点也承担构筑规划功能。

#### 2. 商店刷新

- 商店新增刷新功能，刷新购物区的2张卡与1件常规饰品。
- 删卡与回收不因刷新而重置次数。
- 刷新费用、同店连续刷新是否涨价、刷新后商品来源权重由商店经济阶段确定。
- 商售限定饰品只进入商店货池；其他来源限定饰品不会因刷新进入商店。

#### 3. 事件质量原则

参考 `../../../参考资料/大巴扎深度机制研究.md`，事件由单纯随机奖惩升级为可规划内容：

- **信息透明**：选择前展示奖励类型、永久代价、骰面结果与延迟条件；随机只决定结果，不隐藏规则。
- **构筑回声**：事件可以检测牌组类别、状态体系、持有饰品、身份、伙伴和所在领域，并用条件选项替换原有三项之一；仍保持总计3个选项。
- **延迟兑现**：保留远行委托等任务标记，使当前选择影响后续战斗、商店或营地。
- **保留投入**：同级变化卡牌时保留卡牌等级；饰品交易明确来源限制与不可再次获得边界。
- **品质分工**：普通事件以即时一段式收益为主；稀有事件允许构筑检测与定向交换；传说事件承载限定饰品、高风险成长和跨节点任务。
- **无空转选项**：事件生成前检查合法目标，不能用没有目标的按钮占据三选一位置。

### v9-D3 锤子、营地、等级与难度

#### 1. 锤子

- 锤子只能选择可锤炼的普通卡。
- 选择一级或二级卡时，从同等级的9种基础卡类型中随机抽取3种不同类型并三选一，将目标牌横向变化为所选类型，等级不变。
- 原类型可以进入随机结果；选择原类型仍消耗本次锤子。
- 选择三级卡时维持v0.8规则：在该类别9个三级分支中随机展示3个不同分支并三选一，当前分支允许出现。
- 伙伴牌、多兰关联牌、负面状态牌与其他受保护卡牌不能成为目标。

#### 2. 营地

- 营地节点不再拥有普通、稀有、传说品质，进入后只执行统一营地规则。
- 挖掘奖励的等级权重随角色等级提高；角色达到稀有度里程碑后，提高高等级掘藏饰品的出现概率。
- 挖掘、锤子、温存仍为三选一；三务帐篷仍允许三项各执行1次且顺序自选。

#### 3. 品质生成与成长

- 除营地、伙伴选择和固定领域Boss外，需要品质的节点或精英候选分别投掷六面骰：1—3为普通、4—5为稀有、6为传说，对应3/6、2/6、1/6。
- 三个节点候选各自独立生成类型与品质，类型不重复但品质可以相同；类型和品质均在选择前公开。
- 精英三选一中的三名精英也在选择前公开自身品质、机制与掉落。
- 品质是同一进度位置上的相对稀有度，不是跨整局固定的绝对收益档。节点基础收益随领域序位、角色等级与冒险进度成长，再叠加品质修正。
- 因此后期普通节点的绝对收益可以高于前期稀有或传说节点；高品质只保证在同阶段比普通品质更高。
- 营地没有品质，不显示品质骰结果；Boss使用固定领域阶段强度，不参与品质随机。

#### 4. 经验与等级

| 行为 | 经验 |
|------|------|
| 进入一个新领域 | 3点 |
| 完成战斗、商店、事件、宝藏或随机节点 | 1点 |
| 完成营地节点并选择挖掘或锤子 | 2点 |
| 完成营地节点并选择温存 | 3点 |

- 角色等级为单轮回全队共享等级，每累计3点经验提升1级。
- 每次升级提高本轮回共享生命上限。
- 等级达到3的倍数时获得纽币奖励。
- 等级达到6的倍数时，在高级卡牌奖励与饰品奖励中进行选择。
- 等级达到9的倍数时，提高后续奖励中高等级内容的获取权重。
- 多个里程碑在同一级同时满足时全部结算，例如18级同时获得3级、6级和9级三类里程碑奖励。
- 本文按3次领域进入均提供3点经验计算。每域12次节点探索、2场精英与1场Boss至少提供15点，再加入域3点；三域基础经验仍为54点，对应提升18级。营地与温存会进一步提高最终等级。
- 每级具体生命增量、3/6/9级里程碑奖励数值与战斗缩放在公共卡池和敌人基础数值完成后反填。

#### 5. 战斗难度

- 普通战斗依据角色等级与战斗节点品质共同决定敌方数值和机制强度。
- 同等级下，普通、稀有、传说战斗依次提高难度与收益。
- 领域Boss不读取角色等级，使用固定的领域阶段强度与行动池，防止升级路线反向抬高Boss数值。
- 48兵读取进入战斗时剩余命源石数量：剩余越少，48兵越强；具体分档与强化内容由Boss设计确定。

### v9-D4 护盾与两阶段诅咒风暴

#### 1. 护盾底层

- 我方与敌方护盾均不再随时间自然衰减，只会因承受伤害、卡牌主动消耗、状态移除或战斗结束而减少。
- 战斗结束后护盾清空，不继承至下一场战斗。
- 0.1秒tick顺序中删除“护盾自然衰减”结算项。
- 毒伤继续穿盾；火伤与30秒阶段的诅咒风暴仍先由护盾承担。

#### 2. 依赖卡牌检查

现行公共卡池中唯一直接以“停止护盾自然衰减”为完整效果的牌是金刚石三级防御牌 **恒晶壁**。其他护盾卡可在新底层直接工作，不因取消衰减而失去卡面效果。

恒晶壁数值初稿：

> **能力、高费、不可叠加。** 2费；本场每累计获得50点护盾，提高5点本场共享生命上限并恢复5点生命，最多提高30点生命上限。

该方案同时补入“战斗内生命上限成长”，并通过50点累计门槛与30点上限避免永续护盾无限转化。该数值属于公共卡池初稿，待标准敌人完成后实测拍板。

#### 3. 30秒加时

- 战斗达到30秒时进入第一阶段加时。
- 我方命潮自然充能与敌方行动充能同时加快。
- 战场周期性出现诅咒风暴，同时对我方与敌方造成环境伤害。
- 第一阶段风暴不穿盾，不施加毒伤或重伤；风暴伤害随战斗继续而提高。

#### 4. 60秒加时

- 战斗达到60秒时进入第二阶段加时，双方充能进一步加快。
- 诅咒风暴升级为毒伤与火伤特征融合的 **灾蚀风暴**：穿透护盾、降低治疗且不能净化。
- 灾蚀风暴属于环境复合伤害，不直接占用普通毒伤9层上限或火伤层数；其伤害继续随时间提高。
- 两阶段风暴都伤害敌我双方，为护盾、恢复、局内生命上限与拖延控制构筑提供防杀终端，同时阻止无限龟缩。
- 风暴触发间隔、伤害成长、充能倍率及敌我同tick死亡的胜负顺序由战斗时序阶段确定。
- 若同一tick的结算使我方与敌方同时死亡，优先判定敌方死亡，结果为我方战斗胜利；不再结算我方战败与命源石损伤。

### v9-D5 敌方怪池与领域共享规则

#### 1. 敌方机制标签

敌人行动池围绕以下标签组合：

| 标签 | 行动方向 |
|------|----------|
| 火伤 | 施加火伤与重伤，压制恢复 |
| 毒伤 | 穿盾持续伤害，迫使玩家主动净化或抢攻 |
| 高回复 | 周期治疗、持续治疗或低生命回复窗口 |
| 高盾量 | 大额护盾、反复护盾与护盾联动行动 |
| 冰冻 | 限制或延迟我方命潮、卡牌或出牌节奏 |
| 快速启动 | 开场行动短、连续行动或预充能 |
| 攻击削减 | 降低我方力量、直接伤害基础值或攻击牌效率 |
| 负面状态 | 施加一次性、永久或处理型负面牌，以及可净化战斗状态 |
| 后期增伤 | 随时间、行动次数或低生命阶段持续成长 |
| 卡牌类型限制 | 限时限制某一类卡牌或提高其使用成本，不允许制造整手完全无法行动的死锁 |

#### 2. 四层怪池

| 怪物层 | 定位 |
|--------|------|
| 普通怪 | 使用1个主要机制标签，承担基础战斗与稳定卡牌/纽币奖励 |

| 领域特产怪 | 只在对应领域出现，围绕领域共享规则组合1—2个特色标签 |
| 精英怪 | 具有独立机制或多个标签组合，进入高品质战斗池并提供更高奖励 |

- 战斗节点品质与角色等级共同决定普通战斗从哪一层怪池及哪个强度档抽取。
- 掉落表在进入战斗前可查看，参考《大巴扎》用固定掉落奖励玩家对怪物知识的理解。

| 松三原 | 双方多段效果的后续段逐步增强 | 多段攻击、连续出牌、段数防御 |

### v9-D7 永恒与蓄势3

- 特殊词条固定为：固有、消耗、保留、虚无、奇巧、激发、轻盈、能力、永恒。

- 永恒防止两张诅咒通过商店或事件永久移除；虚无仍可使绊脚石在单场战斗中进入消耗区，但下一场战斗会随初始牌组重新出现。

### v9-D11 拖牌子弹时间与战斗倍速

#### 1. 全局倍速

#### 2. 子弹时间

- 玩家按住并开始拖动一张可操作卡牌时立即进入子弹时间；松手打出、拖回取消或失去合法拖动状态时恢复此前选择的全局倍速。

- “当前倍速乘0.5”会导致2倍速拖牌时仍以1倍运行，思考帮助不足；固定暂停又会破坏实时压力，因此均不进入当前UI稿。
- 子弹时间只改变整套战斗模拟速度，不单独停止敌方或保留我方命潮正常恢复，避免拖牌期间单方面获利。
- 在子弹时间中，30秒与60秒阈值按缩放后的战斗时间推进；玩家获得更多真实思考时间，但不会减少对局内已经流逝的战斗秒数。

- 老马的腰带为三级通售饰品，按百分比提高本轮回共享生命上限，并同步放大后续冒险等级的生命成长。多个百分比生命来源先加算后统一乘一次，防止指数增长。
- 59件的品质、来源、机制、叠加和四端覆盖见 `饰品系统重构.md`；图标提示词已同步至 `视觉资产清单与生成提示词.md`。

### v9-D19 事件与骰局深度重构

- 事件固定三项入口，但不再局限为“两个固定+一个骰子”或三个同质按钮；新增稳—改—赌、同源异路、即得—延期—挑战、献一得一、三种回答和三档特殊战六种结构。
- 事件骰分为直投、追投和定契。选择前公开投入、1—6点结果、追投条件和最终修正顺序；高点总体价值不低于低点，使铅骰子+1始终为正面效果。
- 建立最多持有2枚的事印，允许事件在后续营地、商店或特殊战斗中兑现；事印公开成功、失败、过期与奖励类型，不占卡牌或饰品槽。
- 9个通用事件与九域各1个专属事件均完成三项选择、品质变体和剧情钩子。事件、营地、特殊战斗成为局内叙事主体，普通节点不再只发放资源。
- 完整规则见 `事件系统重构.md`。

### v9-D20 普朗克身份强化

- 铅骰子的事件骰最终点数+1保留，应用于重掷与追投之后，最高6点。
- 开局生成初始牌组后，同时随机锁定2张不同的一级普通卡，依次从另外8个同等级类别中随机展示3类并三选一变化。
- 两张目标不可重选，变化结果由玩家决定；伙伴牌、身份关联牌、负面牌和永恒牌不能成为目标。
- 该变化不是获得或升级，不触发永久入组、同名合成和经济饰品。完整界面与保存边界见 `主角身份调整.md` 和 `UI设计.md`。

## 五、跨系统联动审查

1. **单局长度**：每域16次冒险由1次伙伴选择、12次节点探索、2场精英与1场Boss构成；三域恰好48次，战斗密度由节点选择额外浮动。
2. **命源石损伤**：碎石改为读取所在领域而非只读Boss序位；第一、第二、第三领域的精英或Boss每次失败分别损伤1、2、3颗，普通探索战不损伤。
3. **等级区间**：12次探索、2场精英、1场Boss和入域经验使每域基础18经验，三域基础54经验；9级与18级稀有度里程碑将稳定触发。
4. **资源密度**：36次节点探索、6场必选精英、战斗必得卡和宝藏饰品三选一会显著增加牌组与饰品供给；三槽限制、商店回收和删卡承担主要压缩作用。
5. **护盾强度**：护盾永不衰减会强化马啼击、留晶影、攻守式等现有牌；诅咒风暴提供对局时限，但仍需在数值阶段限制无限护盾增长。
6. **防杀终端**：30秒风暴可被护盾承受，60秒灾蚀风暴穿盾并减疗，防杀构筑需要在60秒前形成击杀或通过生命上限、恢复与减伤继续竞争。
7. **领域规则**：共享规则允许玩家反向利用领域环境；Boss不随等级缩放，但会利用共享规则获得结构优势。
8. **48兵逆向缩放**：命源石越少，绝境石等玩家补偿越强，同时48兵也越强，形成高风险背水路线而非失败后的纯补偿。
9. **永恒边界**：永恒替代的是第九特殊词条位置，不替代伙伴牌和关联牌的全部保护规则。
10. **轮回叠加**：累积制下，第八重开始时100基础生命会先降为90上限，再以81生命进入每场战斗；这一双重削减是明确的高重轮回压力。
11. **最终剧情路线**：管理员的钥匙要求选择艾德明且保留占位饰品；绝境石可由第一、第二领域六场危险战全败累计9，或第三领域三场危险战全败累计9，也可由其他恰好累计9的组合形成。
12. **数值乘区**：力量每段+5会天然偏好多段卡，25%增伤则同时服务单段和多段；三级卡数值设计必须避免两种增伤在多段体系中同时失控。
13. **倍速一致性**：所有战斗计时读取同一个模拟时间倍率；子弹时间不能让命潮、持续治疗或玩家状态以正常速度运行而只减慢敌方。
