# 《三乂川》完整设计文档（首版汇总）


## 一、项目概述

| 项目 | 内容 |
|------|------|
| **游戏名称** | 三乂川 |
| **世界名称** | 永恒大陆（ImmortalLand） |
| **平台** | 手机端，竖屏，2D |
| **核心定位** | 轻量化休闲策略肉鸽 |
| **核心体验** | 以“三选一”为核心的谋略构筑，通过排兵布阵与组合搭配获得战斗力质变的爽感 |
| **核心操作** | 单手竖屏操作，三选一决策为主，拖拽移动为辅 |


## 二、世界观设定

### 2.1 核心概念

> 这个世界叫做永恒大陆。游戏名为“三乂川”——“三”是尊贵数字，以九为尊，三和六同样重要；“乂”是治理；“川”是大陆。主人公通过三选一的方式治理这个大陆，让大陆步入正轨。

| 数字 | 象征意义 | 玩法映射 |
|------|----------|----------|
| **三** | 尊贵之数，决策之数 | 全游戏三选一（路径/卡牌/源流/事件/同伴） |
| **六** | 圆满之数 | 六面骰子、六种路径类型 |
| **九** | 至尊之数 | 九个领域、九种源神石、最终Boss |

### 2.2 源神石系统

> 这个世界有九种颜色的源神石——赤、橙、黄、绿、青、蓝、紫、黑、白、灰。里面的能量叫做“源神”，给人们带来力量。

| 颜色 | 力量属性 | 对应源流 |
|------|----------|----------|
| **赤** | 炎、烈焰、爆发 | 炎 |
| **橙** | 大地、稳固、防御 | 地 |
| **黄** | 光、治愈、净化 | 光 |
| **绿** | 自然、毒、持续侵蚀 | 毒 |
| **青** | 风、机动、迅捷 | 风 |
| **蓝** | 霜、寒冰、控制 | 霜 |
| **紫** | 雷、连锁、传导 | 雷 |
| **黑** | 暗、侵蚀、削弱 | 暗 |
| **白/灰** | 混沌、中立、万能 | 混沌 |

### 2.3 骰子系统

> 这个世界存在一种六面骰子，当陷入抉择时便会投掷它做决定。三面一级，两面二级，一面三级。

| 骰子面数 | 级别 | 概率 | 玩法对应 |
|----------|------|------|----------|
| 3面 | 一级 | 50% | 普通难度/普通奖励 |
| 2面 | 二级 | 33.3% | 稀有难度/稀有奖励 |
| 1面 | 三级 | 16.7% | 传说难度/传说奖励 |

**骰子应用场景**：路径稀有度决定、事件结果判定、战利品品质、刷新内容池

### 2.4 永恒大陆九宫格结构

> 这个大陆有九个领域，每个领域都有统治者。领域有三个等级，每个等级有三个。

| 层级 | 领域 | 对应源神石 | 游戏阶段 |
|------|------|-----------|----------|
| **第一层** | 赤焰荒原 | 赤 | 前期 |
| | 青风林地 | 青 | 前期 |
| | 绿沼深渊 | 绿 | 前期 |
| **第二层** | 橙岩山脉 | 橙 | 中期 |
| | 蓝霜冻原 | 蓝 | 中期 |
| | 紫雷裂谷 | 紫 | 中期 |
| **第三层** | 黄光圣殿 | 黄 | 后期 |
| | 黑暗深渊 | 黑 | 后期 |
| | 灰白混沌 | 白/灰 | 最终 |

**每层结构**：3个领域 × 每领域6处路径节点 + 第9处Boss = 每层18处节点 + 3场Boss战

### 2.5 剧情与游戏进程对照

| 阶段 | 剧情事件 | 游戏内容 |
|------|----------|----------|
| **开局** | 选择主人公名字（职业），从3位美少女中选择1位同伴 | 确定初始牌组与队伍构成 |
| **第一领域** | 探索赤/青/绿三个一级领域（每领域6处+1Boss） | 熟悉基础机制，获得一级源神石 |
| **第一领域Boss战后** | 击败统治者，从3位新美少女中选择1位加入 | 队伍扩充至3人 |
| **第二领域** | 探索橙/蓝/紫三个二级领域 | 难度提升，获得二级源神石 |
| **第二领域Boss战后** | 一位同伴牺牲化为源能石，从3位新美少女中选择1位 | 队伍重组，获得源能石永久Buff |
| **第三领域** | 探索黄/黑/灰白三个三级领域 | 最高难度，获得三级源神石 |
| **最终Boss战后** | 击败最终统治者 | 通关结局 |

### 2.6 货币系统

> 货币叫做“纽币”，可以交换珍贵的物品。

| 用途 | 说明 |
|------|------|
| 商店购买 | 购买卡牌、装备、特殊物品 |
| 营地升级 | 花费纽币升级卡牌或角色 |
| 事件支付 | 部分事件需要支付纽币换取更好结果 |
| 删除卡牌 | 付费删除牌组中的卡牌 |
| 刷新三选一 | 付费刷新路径/卡牌/商店选项 |


## 三、核心玩法机制

### 3.1 三选一系统（核心决策机制）

> 游戏的核心操作，贯穿始终。

| 三选一类型 | 出现时机 | 内容 |
|------------|----------|------|
| **路径三选一** | 每个节点 | 从3条路径中选择1条（战斗/冒险/事件/营地/商店/未知） |
| **卡牌三选一** | 战斗中每轮 | 从3张牌中选择1张使用，其余弃掉 |
| **源流三选一** | 角色升级时 | 从3种随机源流中选择1种注入 |
| **三星卡牌源流注入** | 卡牌升三星时 | 从3种源流中选择1种注入 |
| **事件三选一** | 事件节点 | 从3种应对方式中选择1种 |
| **同伴三选一** | Boss战后 | 从3位美少女中选择1位加入 |

### 3.2 骰子与随机性

| 随机场景 | 骰子作用 |
|----------|----------|
| 路径稀有度 | 决定该路径的等级（一/二/三级） |
| 事件结果 | 决定成功/失败/大成功 |
| 战利品品质 | 决定掉落品质的保底与上限 |
| 刷新内容 | 决定刷新出的三选一内容池 |

### 3.3 构筑系统（核心策略循环）

**职业为起点 → 源流为方向 → 卡牌为执行 → 装备为增幅**

| 层 | 内容 | 获取方式 | 作用 |
|----|------|----------|------|
| **职业** | 6种（战士/法师/猎人/刺客/骑士/牧师） | 开局选择 | 决定基础牌组与战斗机制 |
| **源流** | 9种（九色源神石） | 升级时三选一 | 决定力量属性与附加效果 |
| **卡牌** | 通用牌+职业专属牌 | 三选一获取/升级 | 战斗中的具体执行手段 |
| **装备** | 基础件→合成件→传说 | 散件合成/掉落 | 提供被动增幅与额外效果 |


## 四、战斗系统

### 4.1 战场与地形

| 维度 | 设计 |
|------|------|
| **棋盘** | 六边形网格（3×5或4×4），距离计算直观 |
| **地形** | 随机生成，含障碍物（阻挡）与增益地皮（加成） |
| **站位** | 英雄放置在棋盘上，位置影响攻击距离与伤害 |

### 4.2 战斗流程（部署-执行闭环）

| 阶段 | 操作 | 说明 |
|------|------|------|
| **信息揭示** | 敌方本回合行动预览（攻击目标/伤害/技能范围） | 完全透明 |
| **部署阶段** | ① 移动英雄（免费，受移动力限制）<br>② 打出技能卡牌（消耗费用） | 玩家主动操作 |
| **自动战斗阶段** | ① 双方普攻（嘲讽值权重分配目标，距离衰减计算伤害）<br>② 卡牌效果结算<br>③ 敌方按固定规则行动 | 系统自动执行 |
| **回合结算** | 检查胜负、恢复费用、补充手牌 | 进入下一回合 |

### 4.3 卡牌使用流程（三选一核心）

```
牌组 → 抽3张
         ↓
    ┌────┼────┐
    ↓    ↓    ↓
  选1张  全弃掉  刷新(消耗1费)
  消耗费用  不用费  重抽3张
    ↓         ↓         ↓
执行效果  跳过本回  重新决策
         ↓
    重新抽3张进入下一轮

循环终止：费用用完 / 主动结束回合
```

### 4.4 费用系统

| 维度 | 规则 |
|------|------|
| 初始上限 | 3点 |
| 每回合恢复 | 恢复至上限（不累计） |
| 消耗途径 | 使用卡牌（按费用）+ 刷新（1费） |
| 临时提升 | 可通过装备/特殊物品/卡牌效果提升 |

### 4.5 伤害与仇恨机制

| 机制 | 说明 |
|------|------|
| **嘲讽值** | 每个英雄有基础嘲讽值，敌人按权重随机抽取目标 |
| **距离衰减** | 伤害 = 基础攻击力 × (1 - 衰减系数 × 攻击距离) |
| **近战** | 衰减低或无视衰减 |
| **远程** | 基础伤害高但受衰减影响大 |


## 五、卡牌系统

### 5.1 卡牌基本结构

| 属性 | 说明 |
|------|------|
| 名称 | 卡牌名称 |

### 5.2 卡牌品质路径

> **一级定义机制，二级提升数值，三级注入源流（唯一分支点）**

| 品质 | 变化 | 玩家操作 |
|------|------|----------|
| **一星** | 获得基础效果 | 无 |
| **二星** | 数值提升（线性增强） | 自动升级，无分支 |
| **三星** | 注入源流，获得流派效果 | **三选一**：从3种源流中选择1种 |

## 六、装备系统

### 6.1 装备槽位

每个英雄拥有**3个装备槽位**：

| 槽位 | 数量 | 可放内容 | 不可放内容 |
|------|------|----------|-----------|
| **主系槽** | 1个 | 二级及以上装备、二级及以上特殊物品 | 一级散件、一级特殊物品 |
| **副系槽1** | 1个 | 一级散件、二级合成件、任何品质特殊物品 | 三级装备 |
| **副系槽2** | 1个 | 一级散件、二级合成件、任何品质特殊物品 | 三级装备 |

**核心约束**：三级装备只能放在主系槽（每英雄最多1件三级装备）

### 6.2 装备品质（三级）

| 品质 | 名称 | 效果定位 | 获取方式 |
|------|------|----------|----------|
| **一级** | 散件 | 基础数值，过渡用 | 三选一（高概率）/商店/战斗掉落 |
| **二级** | 合成件/稀有主系 | 中级效果，构筑核心 | 两件指定散件合成/三选一（低概率）/精英掉落 |
| **三级** | 传说主系 | 质变效果，流派核心 | 二级装备+1件任意装备升级/Boss掉落 |

### 6.3 合成路径

```
散件A（一级） + 散件B（一级）
        ↓（合成，有配方）
    二级合成件
        ↓
    ├─→ 放入副系槽（提供中级效果）
    ├─→ 放入主系槽（提供核心效果，可能影响卡牌）
    └─→ + 1件任意装备（升级）
            ↓
        三级传说装备
            ↓
        只能放入主系槽（品质封顶）
```

### 6.4 散件种类（6种）

| 散件名称 | 效果 | 关联源流 |
|----------|------|----------|
| 大剑 | 攻击+ | 炎/暗 |
| 反曲弓 | 攻击距离/行动频率+ | 风/雷 |
| 法棒 | 技能效果+ | 霜/毒 |
| 护甲 | 护盾/防御+ | 地/光 |
| 斗篷 | 抗性/减伤+ | 光/暗 |
| 腰带 | 血量+ | 地/炎 |

### 6.5 合成配方（部分示例）

| 配方 | 合成件 | 效果 | 关联源流 |
|------|--------|------|----------|
| 护甲+护甲 | 反甲 | 血量+，受到攻击反伤 | 地 |
| 大剑+披风 | 吸血刀 | 攻击+，每次攻击恢复血量 | 炎 |
| 毒宝石+大剑 | 淬毒刃 | 攻击+，攻击附带毒层 | 毒 |
| 血宝石+护甲 | 血甲 | 血量+，每回合恢复 | 暗 |
| 大剑+长弓 | 狙击弓 | 攻击+，攻击距离+，无视衰减 | 风 |
| 法棒+斗篷 | 元素披风 | 源流效果+ | 任意 |

### 6.6 主系装备与卡牌系统的联动

| 影响方式 | 示例 |
|----------|------|
| 生成新卡牌 | 每回合获得1张特定牌 |
| 强化特定类型 | 攻击牌伤害+2 |
| 提升出现概率 | 三选一中特定类型出现率+30% |
| 解锁新卡池 | 允许获得原本不在牌池中的卡牌 |

### 6.7 特殊物品（占用装备栏）

## 十一、设计原则总结

| 原则 | 说明 |
|------|------|
| **三为核心** | 所有关键决策都是三选一，呼应“三乂川”之名 |
| **骰子为随机载体** | 所有随机性通过六面骰子可视化呈现 |
| **九为终极结构** | 九个领域、九种源神石，构成完整游戏进程 |
| **职业与源流分离** | 主人公决定职业，源神石决定力量属性 |
| **三级品质贯穿** | 卡牌、装备、路径、事件、骰子，全部遵循三级体系 |
| **三级封顶** | 所有品质最高三级，防止数值膨胀 |
| **主副分权** | 主系装备影响卡牌系统，副系只提供数值 |
| **强制取舍** | 三级装备只能放主系，特殊物品占装备栏 |
