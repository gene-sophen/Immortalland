# 《三乂川》源神石系统·体系重构 v1.1

> 定位：源神石是**全游戏体系的上游枝干**——九域主题、卡牌注入、流派（饰品格）、Boss设计、事件全部从这张表辐射。

## 一、九石关联体系

| 源神石 | 核心意象（原设） | 关联体系 | 一句话机制方向 |
|--------|----------------|---------------|---------------|
| **阴阳石** | 反转调和，昼夜变换 | **循环 · 增益 · 抑制** | 周期性在"增益己方/抑制敌方"间切换，昼夜节律 |
| **科目石** | 阶级分明，科目四 | **献祭 · 成长 · 增益** | 以献祭换阶级跃升，击杀/牺牲滚雪球 |
| **卡厄石** | 拥抱不可预测 | **随机 · 变异 · 循环** | 效果随机变异，但循环回归（混沌中有节律） |
| **戏命石** | 优雅杀戮艺术，烬 | **暴击 · 处决 · 远程** | 计次艺术（每第N次必暴/强化），斩杀低血目标 |
| **降解石** | 依旧优势在我 | **装备 · 献祭 · 衰减** | 降解装备换短期爆发；让敌方随时间降解变弱 |
| **海克石** | 加入光荣进化 | **能量 · 进化 · 装备** | 命潮/蓄能运转轴，装备随战斗进化强化 |
| **金刚石** | 最坚硬，炫目闪光 | **防御 · 经济 · 反伤** | 金刚不坏+纽币生财，挨打反震 |
| **大理石** | 大力士，深红纹理 | **生命 · 力量 · 灼烧** | 大体型高生命，力量碾压，岩火dot |
| **陶玉石** | 温润如肌肤 | **群伤 · 迅捷 · 传导** | 温润传导：效果在敌我间扩散，多段快速 |

### 与原表的对照说明
- **保留**：阴阳(循环/增益)、科目(献祭/增益)、卡厄(随机/循环)、海克(能量/装备)、金刚(防御/经济)、大理石(生命/灼烧) 的主干
- **戏命**："火伤"移交大理石（原设大理石本就带火伤），戏命收敛为烬的本体——**暴击/处决/远程**，狙击流归此
- **降解**："纽币"移交金刚石（一颗石头管钱就够），降解专注**装备×献祭×衰减**——"优势在我"=短期爆发+敌方降解
- **陶玉**："循环"让位给阴阳/卡厄（循环是它们的核心），陶玉得**传导**（温润意象的机制化）
- **新增覆盖**：暴击（戏命）、能量运转（海克）、位移/速度（陶玉迅捷）、经济（金刚石）——此前无石头认领

## 二、联动网：关键词不是孤岛

每个关键词至少被**两颗石头**共享，形成天然的"双石构筑"接口：

```
        增益 ── 阴阳石 ═══════ 科目石 ── 献祭 ══ 降解石
        循环 ── 阴阳石 ═══════ 卡厄石              ║
        随机 ── 卡厄石 ══════ 戏命石(处决随机性)  装备 ══ 海克石
        灼烧 ── 大理石 ══════ 戏命石(原火伤脉络)   能量
        防御 ── 金刚石 ══════ 大理石(生命向)       ║
        传导 ── 陶玉石 ══════ 阴阳石(增减益扩散)  进化(需装备)
```

- **联动意义（双石共鸣，已确认成立）**：一颗石头入饰品格定流派后，第二颗石头（卡牌注入/事件/Boss）与之共享关键词时产生**共鸣加成**——这是"三选一"构筑深度的上游
- 示例共鸣对：
  - 阴阳×科目（增益网）：献祭获得的增益额外+25%
  - 降解×海克（装备网）：降解装备时额外返还进化能量
  - 大理石×戏命（杀戮网）：灼烧目标被处决时引爆剩余dot

## 三、系统覆盖校验（无遗漏）

| 游戏系统 | 认领石头 |
|---------|---------|
| 普攻/暴击输出 | 戏命石 |
| 技能/变异输出 | 卡厄石 |
| 持续dot | 大理石（灼烧）、陶玉石（传导扩散） |
| 攻速/位移/多段 | 陶玉石（迅捷） |
| 防御/承伤 | 金刚石、大理石（生命） |
| 能量运转（命潮/蓄能） | 海克石 |
| 增益/减益 | 阴阳石、科目石 |
| 成长/滚雪球 | 科目石、海克石（进化） |
| 装备互动 | 降解石、海克石 |
| 经济（纽币） | 金刚石、降解石（变卖装备） |
| 随机/骰子 | 卡厄石 |
| 回复/循环 | 阴阳石 |

## 四、辐射挂点（下游系统怎么接）

| 下游系统 | 接法 |
|---------|------|
| **流派（饰品格）** | 石头入饰品格→携带者获得流派被动，九流派语言=本表机制方向（原"九灵魂模板"并入此处） |
| **卡牌注入** | 三级分支卡的源流附魔沿用九源流；源流与石头的对应：嗜血→科目、壁垒→金刚、灼烧→大理石、剧毒→降解、连锁→陶玉、疾风→陶玉、狙击→戏命、混沌→卡厄、霜冻→阴阳（海克无源流——它管能量与装备，不走伤害词） |
| **九域主题** | 每域统治者/地皮/事件围绕该域石头的3关键词设计（领域重设时套用） |
| **装备** | 六散件与石头无强制绑定；海克/降解两石提供装备互动玩法 |
| **Boss** | Boss机制=该域石头关键词的敌方镜像（如科目石Boss=献祭小怪滚雪球） |
