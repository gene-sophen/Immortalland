# 《三乂川》战斗系统设定 v1.0

> 本文档是"全卡牌化"改动后的战斗系统整合版，与旧版（战斗.md）的差异：删除自动普攻层、伤害公式改为系数模型、回合结构重排、新增布阵阶段与阵亡规则。
> 标注 🔶 的为待拍板项。

---

## 一、战场

### 1.1 棋盘结构

六边形网格，共 7 行 24 格，从下到上按 3-4-3-4-3-4-3 排布：

```
        ◇ ◇ ◇        敌方区 3
       ◇ ◇ ◇ ◇       敌方区 4
        ◇ ◇ ◇        敌方区 3
       ◇ ◇ ◇ ◇       中间连接带 4（争夺区）
        ◇ ◇ ◇        我方区 3
       ◇ ◇ ◇ ◇       我方区 4
        ◇ ◇ ◇        我方区 3
```

- **我方区**（10格）：布阵与调度的主要活动范围
- **敌方区**（10格）：敌方单位站位
- **中间带**（4格）：近战交锋的必经之路，领域机制常在此做文章

### 1.2 地皮

| 地皮类型 | 效果 | 来源 |
|----------|------|------|
| 普通地皮 | 无效果 | 默认 |
| 障碍 | 不可停留、不可穿越（阻挡近战路径与直线射击） | 随机场地 / 陷坑牌 / 荒脊岭机制 |
| 增益地皮 | 停留的单位攻击+2、每回合开始护盾+2 | 随机场地 / 沃土牌 / 皮安城机制 |
| 火焰地皮 | 停留的单位每回合末受2点火焰伤害 | 火尽山机制 / 地形牌 |
| 毒沼 | 踏入者+2层中毒 | 纳西妲招牌牌 |
| 特殊地皮 | 由领域机制定义 | 九域各自规则 |

规则：同一格同时只能存在一种地皮效果，新效果覆盖旧效果。

### 1.3 布阵阶段 🔶（新增）

- 每场战斗开始前，展示敌方阵容与站位（不含意图），玩家在我方区10格内**自由摆放3名英雄**
- 此时第一次三选一的手牌已知（身份牌固有），摆放是有信息决策
- 布阵无时间限制，确认后进入第1回合

## 二、单位与属性

### 2.1 英雄属性（6项）

| 属性 | 作用 |
|------|------|
| **攻击** | 攻击牌的系数基数（伤害=底值+系数×攻击） |
| **防御** | 防御/治疗牌的系数基数 🔶 |
| **生命** | 归零即阵亡 |
| **嘲讽** | 敌方索敌的权重 |
| **移动力** | 调度阶段可移动的格数 |
| **等级** | 1-9级，每级攻+2/防+1/血+5；3/6/9级触发源流三选一与伙伴解锁 |

各职业基准值（1级）：

| 职业 | 攻 | 防 | 血 | 嘲讽 | 移动 |
|------|----|----|----|------|------|
| 战士 | 10 | 8 | 45 | 100 | 2 |
| 骑士 | 8 | 12 | 50 | 120 | 1 |
| 法师 | 12 | 5 | 30 | 60 | 2 |
| 猎人 | 11 | 6 | 32 | 70 | 3 |
| 刺客 | 13 | 5 | 28 | 50 | 3 |
| 牧师 | 7 | 9 | 35 | 80 | 2 |
| 主角 | 10 | 8 | 40 | 80 | 2 |

### 2.2 状态效果词库

| 状态 | 类型 | 效果 | 叠加规则 |
|------|------|------|----------|
| 灼烧 | 减益 | 回合末每层2点伤害，持续2回合 | 叠层，刷新时间 |
| 中毒 | 减益 | 回合末每层1点伤害，持续3回合 | 叠层上限9层 |
| 护盾 | 增益 | 吸收伤害 | 数值累加，持续至下一次敌方行动阶段结束 🔶 |
| 迟缓 | 减益 | 移动−1、攻击−15% | 不可叠，1回合 |
| 禁足 | 减益 | 无法移动 | 不可叠，1回合 |
| 嘲讽↑ | 增益 | 嘲讽权重翻倍 | 不可叠，1回合 |
| 标记 | 减益 | 受到的攻击牌伤害+20% | 不可叠，1回合 |
| 蓄力 | 增益 | 下一次攻击牌+50% | 不可叠，消耗型 |

## 三、回合结构（五段式）

```
① 信息揭示 → ② 出牌阶段 → ③ 调度阶段 → ④ 敌方行动 → ⑤ 回合结算
```

### 3.1 信息揭示

- 敌方全体本回合意图**直接投影在棋盘上**：将被攻击的格子标红+伤害数值、技能范围标注、移动箭头
- 同时显示我方各英雄当前状态（血/盾/状态层数）
- 过明氹领域：此阶段被跳过（意图不可侦测）

### 3.2 出牌阶段（核心操作段）

- **站位锁定**：本阶段内英雄不可移动，所有射程/衰减按当前站位判定
- **连环三选一**：从牌组抽3张 → 选择【打出1张（付费）/ 全部弃掉（免费）/ 刷新重抽（1费）】→ 循环，直至费用耗尽或主动结束
- **见9张兜底**：费用耗尽后仍可免费"全弃"过牌，直到本回合累计见过9张 🔶
- **打出即结算**：卡牌效果在打出的瞬间生效（用锁定站位判定），不延迟到后续阶段
- **施放者绑定**：攻击牌须指定一名存活英雄为施放者，伤害=底值+系数×其攻击，射程/衰减从其站位计算；职业牌/招牌牌自动绑定对应英雄
- 费用：每回合上限3点，阶段开始恢复至上限（不累计）

### 3.3 调度阶段

- 每名存活英雄可按移动力免费移动（可不走、可走部分格数）
- 不可进入障碍格、地皮阻挡格、其他单位所在格；可穿过友方单位 🔶
- 移动的三大目的：脱离敌方意图红格 / 调整嘲讽几何（谁挨着谁）/ 为下回合的牌面射程落位
- 本阶段结束后站位再次锁定

### 3.4 敌方行动

结算顺序：敌方增益类意图 → 敌方移动类意图 → 敌方攻击/技能意图（从左到右、从上到下）→ 双方持续伤害（灼烧/中毒）结算

### 3.5 回合结算

- 检查胜负（见4.8）
- 地皮效果结算（增益/火焰）
- 状态持续时间−1
- 费用恢复、进入下一回合

## 四、战斗规则

### 4.1 射程与距离衰减 🔶

攻击牌分两类，牌面标注：

| 类别 | 射程 | 衰减 |
|------|------|------|
| 近战牌 | 1格（部分牌2格） | 无衰减 |
| 远程牌 | 3格 | 伤害×（1−0.1×（距离−1）），距离1时全额 |

- 狙击源流/狙击弓装备：射程+1或无视衰减
- 直线类技能（贯矢等）需路径无遮挡

### 4.2 伤害结算管线

```
基础值 = 底值 + 系数 × 施放者攻击
  → +加法增益（鼓舞、蓄力）
  → ×乘法增益（源流效果、装备效果、标记易伤）
  → ×距离衰减（远程牌）
  → −目标护盾（护盾优先吸收）
  → 剩余扣生命
```

- 暴击不存在于基础系统，仅特定装备/源流提供（如完美谢幕）
- 持续伤害（灼烧/毒）不吃任何增减益、**无视护盾**直接扣血 🔶

### 4.3 敌方索敌

- 敌方攻击意图的指向：按我方英雄嘲讽权重随机抽取，**与敌方相邻的英雄权重×1.5**
- 意图在信息揭示阶段即确定并公示，不因我方后续移动改变目标（移动可以改变的是：谁进入其射程、谁在红格内）

### 4.4 阵亡与复活 🔶

| 对象 | 规则 |
|------|------|
| 伙伴阵亡 | 本场战斗中退场；其职业牌/招牌牌/基础牌**即刻退化为0级垃圾牌**；战斗结束后复活，生命=50%上限 |
| 主角阵亡 | 本场战斗失败 → 本局游戏结束（肉鸽规则） |
| 敌方全灭 | 战斗胜利 |

### 4.5 胜负判定

- 胜利：敌方全灭（含召唤物，召唤物无主时自动消亡）
- 失败：主角阵亡
- 伙伴全灭但主角存活：战斗继续（主角仍可独自作战）

## 五、敌方设计框架

### 5.1 意图类型（图标化）

| 意图 | 图标方向 | 说明 |
|------|----------|------|
| 攻击 | 剑+数值 | 指向嘲讽抽取的目标，或指向固定格 |
| 范围攻击 | 剑+网格 | 红格范围+伤害 |
| 移动 | 箭头 | 位移方向 |
| 增益/减益 | 上/下箭头 | 加buff或上debuff |
| 召唤 | 五角星 | 生成单位 |
| 蓄力 | 沙漏 | 下回合释放大技能（给玩家应对窗口） |

### 5.2 敌方档位

| 档位 | 血 | 攻 | 行为模式 |
|------|----|----|----------|
| 杂兵 | 18-30 | 6-9 | 固定意图循环（2-3种轮换） |
| 精英 | 50-80 | 10-14 | 意图循环+1个词缀（灼烧/护盾/狂暴/召唤等） |
| Boss | 130-220 | 12-18 | 2个主动技能+阶段转换+领域机制放大 |

领域递进系数：第二领域×1.5，第三领域×2.2，最终Boss×2.8 🔶（原型实测后校准）

### 5.3 领域机制对战斗的改写（九域）

| 领域 | 战斗内效果 |
|------|-----------|
| 镜晶境 | 敌方物理伤害会对攻击者本体造成相同伤害（反伤） |
| 荒脊岭 | 随机若干格为障碍 |
| 火尽山 | 随机若干格为火焰地皮，每2回合蔓延1格 |
| 皮安城 | 随机若干格为增益地皮 |
| 松三原 | 双方源神石被动效果翻倍 |
| 过明氹 | 跳过信息揭示阶段 |
| 啼亡堆 | 所有直接伤害的50%转化为等值持续伤害 |
| 潮王原 | 第三势力"潮汐单位"每3回合出现，攻击当前优势方 |
| 平安京 | 每第3回合的调度阶段跳过（全员无法移动） |

## 六、战后结算

- **经验**：普通战斗全队+1，精英+2，Boss战全员直接+1级
- **纽币**：普通8-12 / 精英15-20 / Boss 30-40
- **卡牌奖励**：三选一（公共池70% / 在职职业池25% / 稀有池5%），可跳过
- **阵亡伙伴**：复活，生命=50%上限
- **地皮/状态**：全部清除，护盾清零

## 七、表现与操作（竖屏）

```
┌─────────────┐
│  敌方区      │  上半屏：棋盘（占屏约55%）
│  中间带      │  意图直接画在格子上
│  我方区      │
├─────────────┤
│ 英雄状态栏×3 │  血条/护盾/状态图标/攻/防
├─────────────┤
│  三选一卡位  │  下半屏：3张卡横排，点选放大
│ [弃][刷新1费]│  费用水晶 ×3  牌组/弃牌堆计数
└─────────────┘
```

- 单手操作：点选卡牌→点选施放者→点选目标格，全程拇指可达
- 出牌阶段/调度阶段的切换为大按钮"结束出牌，进入调度"
- 敌方行动阶段可2倍速/跳过
