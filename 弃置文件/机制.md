## 核心玩法机制

### 三选一系统（核心决策机制）

> 游戏的核心操作，贯穿始终。

| 三选一类型 | 出现时机 | 内容 |
|------------|----------|------|
| **路径三选一** | 每个节点 | 从3条路径中选择1条（战斗/冒险/事件/营地/商店/未知） |
| **卡牌三选一** | 战斗中每轮 | 从3张牌中选择1张使用，其余弃掉 |
| **源流三选一** | 卡牌升级时 | 从3种随机源流中选择1种注入 |
| **事件三选一** | 事件节点 | 从3种应对方式中选择1种 |
| **同伴三选一** | Boss战后 | 从3位美少女中选择1位加入 |


### 骰子系统

| 骰子面数 | 级别 | 概率 | 玩法对应 |
|----------|------|------|----------|
| 3面 | 一级 | 50% | 普通难度/普通奖励 |
| 2面 | 二级 | 33.3% | 稀有难度/稀有奖励 |
| 1面 | 三级 | 16.7% | 传说难度/传说奖励 |

| 随机场景 | 骰子作用 |
|----------|----------|
| 路径稀有度 | 决定该路径的等级（一/二/三级） |
| 事件结果 | 决定成功/失败/大成功 |
| 战利品品质 | 决定掉落品质的保底与上限 |
| 刷新内容 | 决定刷新出的三选一内容池 |

### 九域设计

| 领域名称 | 领域机制 |
|--------|------------|
| 镜晶境 | 物理伤害会对本体造成相同伤害 |
| 荒脊岭 | 部分地皮无法行走 |
| 火尽山 | 部分地皮会受到火焰伤害 |
| 皮安城 | 部分地皮存在增益buff |
| 松三原 | 增强源神石效果 |
| 过明氹 | 地方的行动无法被提前侦测 |
| 啼亡堆 | 所有生物收到的伤害转化为持续伤害 |
| 潮王原 | 存在第三种势力，会协助弱势方 |
| 平安京 | 存在时间机制，一定回合无法移动 |

### 六种路径类型
| 类型 | 内容 | 奖励倾向 |
|------|------|----------|
| 战斗 | 与敌人战斗 | 经验、卡牌、源神石 |
| 事件 | 随机遭遇、抉择 | 多种可能（好/坏） |
| 冒险 | 探索、解谜、挑战 | 特殊事件、稀有奖励 |
| 营地 | 休息、恢复 | 回血、卡牌升级、降级 |
| 商店 | 购买物品 | 卡牌、装备、特殊物品 |
| 未知 | 随机（以上任何一种） | 惊喜或惊吓 |

**每层结构**：每领域8处路径节点 + 第9处Boss = 3 * 9 = 27 个关卡

### 剧情与游戏进程对照

| 阶段 | 游戏内容 |
|------|----------|
| **开局** | 确定初始身份与队伍构成 |
| **第一领域** | 熟悉基础机制，完成基础构建 |
| **第一领域Boss战后** | 队伍扩充至3人 |
| **第二领域** | 难度提升，逐渐完成体系构筑 |
| **第二领域Boss战后** | 队伍重组，获得源流石 |
| **第三领域** | 最高难度，体系优化与最终完成 |
| **最终Boss战后** | 击败最终统治者，通关结局 |


### 货币系统

> 货币叫做“纽币”，是大陆交易的基础货币。

| 用途 | 说明 |
|------|------|
| 商店购买 | 购买卡牌、装备、特殊物品 |
| 升级/降级卡牌 | 花费纽币升级/降级卡牌 |
| 事件支付 | 部分事件需要支付纽币换取更好结果 |


### 构筑系统（核心策略循环）

**身份+伙伴+源流+卡牌+装备**

| 层 | 内容 | 获取方式 | 作用 |
|----|------|----------|------|
| **身份** | 9种 | 开局选择 | 决定基础牌组与战斗策略 |
| **伙伴** | 9种 | 进行到一定阶段时选择 | 附带独特机制的技能 |
| **源流** | 9种 | 升级时三选一 | 决定力量属性与附加效果 |
| **卡牌** | 通用牌+专属牌 | 三选一获取/升级 | 战斗中的具体执行手段 |
| **装备** | 基础件→合成件→传说 | 散件合成/掉落 | 提供被动增幅与额外效果 |
